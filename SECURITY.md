# Security Policy

gemsbang is developed in the open at [geml-spec/gemsbang](https://github.com/geml-spec/gemsbang). Until 1.0, only
the latest version on `main` is supported, and fixes land there.

## Reporting a vulnerability

Report privately via **GitHub Security Advisories**: on the
[repository page](https://github.com/geml-spec/gemsbang), *Security → Report a vulnerability*. This reaches the
maintainer directly and keeps the report confidential until a fix is released.

Please do not open a public issue for a security report.
