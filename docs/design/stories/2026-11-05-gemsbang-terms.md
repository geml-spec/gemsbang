# GemsBang 用词（2026-11-05 定）

本人 2026-11-05：「这里面的用词都太口水话了，什么把人拉进来，底子，拉人，产品经理在用词这块太不专业了」。

这张表逐条过了侧栏、状态带、登录页里人读得到的中文（`src/core/avatar/words.ts`），把口语的叫法换成 IM 产品的规范用语。参照的是微信、飞书和 Telegram 中文版。本人 2026-11-05 定了第一节的六个词（「要改几个：1. 个人信息 2. OK 3. 托管 4. OK 5. OK 6. OK」），其余照建议；0.5.44 一次改完侧栏、网页、邮件和画板。

规则：

- 同一个东西只有一个叫法，页名、键上的字和提示里都用它（2026-11-04 的「一物一名」）。
- 动作用规范的动词：邀请、添加、发起、编辑、完成、取消、删除、撤销、重置，不用拉、叫、改、好了、算了、换、撤、干。
- 状态用规范的说法：待确认、执行中、已完成、失败、已过期，不用等你定、在干、干完了、没干成。
- 「身份」是本人 2026-11-03 定的，不动；「GemsBang」是产品名，不动。

## 一、核心词（本人定）

| 原来 | 定 | 没选的 | 参照 |
|---|---|---|---|
| 底子（关于我的事，每条给哪些身份用） | **个人信息** | 记忆 | ChatGPT、Claude 中文版叫「记忆」 |
| agent | **智能体** | 保留 agent | 豆包、飞书、扣子叫「智能体」 |
| 演（谁来演、现在没有会话在演它） | **托管**（托管会话、暂无会话托管） | 代理 | 飞书的「代理人」 |
| 被叫到（被 @、被私聊、被提到名字） | **提及** | 提醒 | Slack、飞书叫「提及」 |
| 静音 | **消息免打扰** | 保留静音 | 微信「消息免打扰」，Telegram「静音」 |
| 拉人（草图，还没上线） | **邀请** | 添加联系人 | 微信「添加朋友」，Telegram「邀请」 |
