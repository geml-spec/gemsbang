## 1. 角色

| 角色 | 是谁 | 在哪用 | 要的是什么 |
|---|---|---|---|
| **分身主人**（John） | 整天在 Claude Code 里的人；有「John」「Lily 爸爸」两个分身 | 桌面侧栏、输入框上方一行（状态带）、偶尔群网页 | 不切应用就把各个群的事办了；分身只在要他出面时来找他；别人的话动不了他的电脑 |

| **别人的 agent**（李四的 Claude Code） | 李四把一句提示词贴给它 | 李四的会话、gemsbang 的工具 | 读懂说明、问过李四再进群；进群后只在李四点头后说话 |
| **群主**（建群的分身主人） | 建了群的人，v1 只能是用 Claude Code 的人（网页上不能建群） | 侧栏的叫人页 | 把人叫进来；需要时管住谁能进 |

## 2. 旅程与故事

### 旅程一 · 第一次打开、登录

#### S1 在侧栏里用邮箱登录
作为分身主人，我想在侧栏里填邮箱和验证码就登进去，以便不离开 Claude Code，也不让 Claude 看到验证码。
- Given 没登录，When 打开侧栏，Then 只有一格邮箱，回车发码；没有填服务器这一步。
- Given 码已发，Then 写明发到哪个邮箱、发件人是 gemsbang.com；码填在侧栏的格里，不进对话。
- Given 码错了或过期，Then 原地说一句，能重发、能换邮箱。

对照
- 微信：手机号 + 短信验证码或密码；电脑版要手机扫码确认。
- WhatsApp：手机号 + 6 位短信码，没有密码；桌面版只能用手机扫码关联。
- Telegram：手机号 + 验证码，码优先发到已登录的 Telegram 里；桌面版也能扫码登录。

不同：内测用邮箱，因为还没有手机 App 可扫；码只在插件自己的格里填（硬规则：模型拿不到）。
现状：**做了**（`panel:125-142`）。小差：画板的「52 秒后可以重发」没做，现在随时能重发（`panel:140`）。

#### S2 老用户在另一台电脑登录：东西都回来
作为已有号的分身主人，我想在新电脑上登进去就看到我的分身、聊天和需要你，以便换电脑不用重来。
- Given 已有号，When 填对验证码，Then 直接到首页，不再问名字。
- Then 别的设备的「登录的设备」里多出这一台。
- Then 在这台电脑上开的会话归哪个分身，见 S21。

对照
- 微信：电脑版要手机扫码，聊天记录不全同步。
- WhatsApp：关联设备后同步最近的聊天。
- Telegram：云端同步全部聊天；其他设备收到一条「新登录」的服务消息。

不同：没有。照 Telegram，只是登录后开的会话要归一个分身（S21）。
现状：**做了但不对**。登进去以后东西都回来（`register:601`），但新开的会话哪个分身都不归：每个分身都写着「这个会话还没替它」（`panel:432-434`，`words:192`），直到本人一个个去按。

### 旅程二 · 第一个分身

#### S3 新人起名，就是第一个分身
作为第一次来的人，我想只回答「大家怎么叫你」，以便马上有一个能用的号。
- Given 新号刚验证完，Then 只有一格名字，回车就进首页。
- Then 这个名字就是第一个分身；不从邮箱取任何字。
- Given 已经有号，Then 永远不出这一步。

对照
- 微信：注册时填昵称和头像。
- WhatsApp：验证后填资料里的名字，头像可选。
- Telegram：注册时填名（必填）、姓（可选）。

不同：三家起的是「人」的名字，这里起的是第一个分身的名字。以后进别的群，可以用另一个名字长出另一个分身。
现状：**做了**（`panel:145-152`；建好后这个会话接上它，`ops:369-374`）。起名下面那段说明（`words:169`）留不留，见 Q16。

### 旅程三 · 第一个群、叫人

#### S4 建群：只问群名
作为分身主人，我想只填一个群名就建好群，以便马上去叫人。
- Given 只有一个分身，When 点「建群」，Then 只有一格「群名」，回车就建，群主就是这个分身。
- Given 有几个分身，Then 有一个默认分身（Q1），只显示一行「以 John 建 · 换」；除非按了「换」，不出「新的分身」，也不出给新分身起名的格（Q2）。
- Given 建好了，Then 直接进这个空群，群里第一眼就是「叫人」。
- 建群页不收进群链接（用链接进群是另一件事，见 S9）。

对照
- 微信：「+」→ 发起群聊 → 从通讯录勾人 → 就建好了；群名不用填，默认是成员名连起来，以后再改。
- WhatsApp：新建群组 → 选成员 → 填群名（必填），头像可选。
- Telegram：New Group → 选成员 → 填群名（必填），头像可选。

不同：没有通讯录，所以「选成员」这一步整个没有，只剩群名。多出来的「以哪个分身」是默认值，不该是一道题。
现状：**做了但不对**，问得太多（`panel:479-492`）：
- 每次都要选「用哪个分身建」，选项里有「新的分身」，选了还要给新分身起名，最后还有一格「贴进群链接」。
- 更糟的是默认选的就是「新的分身」（`register:63`，建完又重置回去，`register:603`）。不先点一下「John」就直接回车，会长出一个随机名的新分身（`ops:449-452` → `relay/avatars.ts:661-668`、`519-521`），John 在自己建的群里变成了「云朵 36」。
- 建好后进群这一点是对的（`ops:458`）。

#### S5 叫人：拿到链接，和给 agent 的那一句
作为群主（或准转链接的成员），我想拿到进群链接和给 agent 的那句提示词，以便发到微信给人，或者发给别人的 agent。
- Given 在群里，When 点「叫人」，Then 看到完整的链接，和一整句「读 gemsbang.com/i/<码>.md ，照着做：用我的身份进『群名』。」，都能用鼠标整段选中。
- Then 桌面侧栏里不放一按就会失败的按钮（Claude Code 不给插件写剪贴板）。另给什么路，见 Q5。
- Then 写明链接还有几天有效。

对照
- 微信：群二维码（7 天有效），或从通讯录拉人；「面对面建群」不加好友，几个人输同一组四位数字就进同一个群，是三家里最接近「没有通讯录」的做法。
- WhatsApp：群信息 → 通过链接邀请：发送、复制、二维码、重置链接。
- Telegram：群信息 → 邀请链接：复制、分享、二维码；可以另开带期限、人数上限、要审核的链接，随时撤。

不同：多一句给 agent 的提示词。桌面侧栏写不了剪贴板，三家都靠的「复制」在这里用不了，只能让人选中文字，或者让手机扫码。
现状：**做了**（0.5.21，草图 P4）：桌面上链接和那句话是能选中的字，链接旁边一个二维码（`src/core/qr.ts`，macOS 自带的识别器读过），下面「选中后按 ⌘C；手机微信扫一扫，在手机上转。」（Windows 上写 Ctrl+C）；终端里留着「复制链接」「复制这句」。「存二维码」没做：桌面侧栏存不了文件。

#### S6 群主管进群：要我同意、换链接
作为群主，我想打开「进群要我同意」，或者换一个链接，以便链接传出去以后还管得住谁进来。
- Given 开了「进群要我同意」，When 有人点链接，Then 群主收到一张「答应事情」卡：「X」想进「群名」，同意 / 不同意；没点之前那人不在群里。
- When 换一个链接，Then 旧的立刻失效；拿旧链接的人看到「这个链接已经失效，找拉你的人要个新的」。
- Then 「换一个链接」在叫人页的链接下面，「进群要我同意」在群信息里，各放一处（草图 P4c，2026-11-03，本人）。

对照
- 微信：群聊邀请确认，群主或管理员确认后才进。
- WhatsApp：审核新成员。
- Telegram：邀请链接可以设成「需要管理员批准」。

不同：申请不另开一种通知，就是群主的一张「需要你」卡。
现状：**做了**（开关和换链接：`panel:411-415`；申请：`words:303-305`；服务端：`relay/avatar-api.ts:173-183`）。「群里每个人都能转」这个开关要去掉（Q6）。

### 旅程四 · 用链接进群

#### S7 网页上的人点链接进群
作为网页上的人，我想在微信里点开链接，填邮箱和验证码、起个名就进群，以便不装任何东西就能参与。
- Given 点开 `/i/<码>`，Then 看到群名、几个成员名和人数，以及群主是谁。
- When 填邮箱和验证码，Then 进到起名：按场合给建议（「__ 妈妈」，空着的地方填孩子的名字），也能自己写，跳过才给随机名。
- When 按「进群」，Then 到群网页，顶上写「你进来了，在这里叫『陈晨妈妈』」，马上能看、能说。

对照
- 微信：点群邀请卡片或扫群码 → 看到群名和成员头像 →「加入群聊」，一下就进。
- WhatsApp：点链接 → App 里预览群名、头像、人数 →「加入群组」；没装 App 先去装。
- Telegram：点 t.me 链接 → 预览 →「加入群组」；网页上引导装 App 或开网页版。

不同：三家都是一下就进，因为对方早有号。这里对方多半没有号，也不装 App，所以要在网页上一次走完四屏。
现状：**做了**（`pages:96-160`，对应画板 `JoinPhone` ②–④）。

#### S8 网页上的人能回来，有事时知道
作为网页上的人，我想关了网页以后还能回到我的群，有人叫我时能知道，以便这个群不是一次性的。
- Given 在 gemsbang.com 用邮箱登录，Then 落在「我的群」列表上，点一个就进去。
- Given 有人 @ 我或回了我的话，Then 我能收到提醒（走什么、多久一次，见 Q8），点开直接到那个群。

对照
- 微信、WhatsApp、Telegram：都有 App 常驻，靠推送提醒。
- Telegram 网页版：登录以后就是会话列表。
- WhatsApp 网页版：要手机关联。

不同：网页上的人没有 App，提醒只能走邮件或网页推送。上一份 review 第 1、9 条说的「零回流」到今天还在。
现状：**做了**（0.5.27，草图 P12b、P12c；Q8 定了 (a)）：gemsbang.com 首页就是「我的群」，没登录先填邮箱和验证码，登完也落在这里；每个群写最后一句和时间，点一个进群网页。有人 @ 她的分身或回了她的话，发一封邮件：标题「三年二班家长里，Lily 爸爸 @ 了你」，正文是那句话和群网页的链接；同一个群三小时最多一封；装了插件的人不发（侧栏里有）。群网页上「有事时提醒我」去掉了，换成「退出群」。为了发提醒，用邮箱登录时服务会记下这个邮箱（只在服务自己那份 `reaches/<id>.geml` 里，不进任何人的收件箱；本人 2026-11-03 定了「可以这样存」）；手机号仍然只存哈希。「我的群」还没有未读数。

#### S9 已有号的人用链接进一个群：用哪个分身
作为分身主人，我想进新群时，有默认就按一下，没有默认才挑，以便不会把工作的我带进家长群。
- Given 拉我的人认识我的某个分身，Then 问一句「用『John』进『前端周会』？」：好 / 换个分身 / 不要，三个键一样大。
- Given 拉我的人和我没有共同场合，Then 没有默认，挑一个已有的，或「新的」再起名（同 S7 的起名，建议里多一个默认名，不预选，Q9）。
- Given 链接是在侧栏里贴的、在 Claude Code 对话里贴的，或者在网页上点开的，Then 三处问法一样，选的结果一样。

对照
- 微信：只有一个身份，但能在每个群设「我在本群的昵称」，这是三家里最像分身的东西。
- WhatsApp：一个号一个身份；2023 起一个 App 能登两个号。
- Telegram：一个 App 能登几个号，来回切，每个号一份列表。

不同：几个分身一个列表，进群前要定用哪个；一旦定了，别人推不出几个分身是同一个人（硬规则第 4 条）。
现状：**做了**（网页：`pages:116-125`；侧栏和对话里：`register:393-463`；贴链接的格：`panel:358`）。用链接进群的入口放在哪，见 Q4。

#### S10 别人的 agent 用一句提示词进群
作为别人的 agent，我想读到进群说明后先问主人，主人点头才进，以便我从不替主人做他没答应的事。
- Given 说明来自 gemsbang.com，而且是主人在对话里亲手贴的那一句，Then 插件弹自己的框；不是亲手贴的就不弹，只在侧栏留一行「有一份进群说明，没照做」。
- Given 主人还没有号，Then 在框里填邮箱和验证码，模型看不到。
- Given 已有号，Then 框里写明来自哪里、群主是谁、链接还有几天，按 S9 选分身。
- Then 进群以后，这个 agent 只在主人对「被叫到」点了「回」，或者那个聊天设成自动回以后才说话（S14）。

对照
- 微信、WhatsApp：没有 agent 进群这回事；企业微信的群机器人是管理员用 webhook 加的。
- Telegram：机器人由群管理员拉进群，默认只看得到 @ 它的话和命令。

不同：进来的不是机器人，是主人本人的分身；进不进由主人定，群主拉不了。
现状：**做了**（`register:398-401` 认亲手贴的；侧栏那一行：`panel:336`；框：`register:404-456`）。

### 旅程五 · 每天用

#### S11 首页就是聊天列表
作为分身主人，我想一打开侧栏就看到要我出面的事和我的聊天，以便一眼知道今天要做什么。
- Given 登录了，When 打开侧栏，Then 首页就是聊天列表，不另加「收件箱」之类的页名（本人：「这不就是首页嘛，不加了」）。
- Then 顶上是 docs/brand 里那张「Gems'Bang」宽图，右边是版本号；不画成小图标加字（本人：「顶上哪个logo+文字应该改成那个带品牌的宽图」，2026-11-03）。侧栏代码已经这样画（`register:704`），是草图 v1 画错了。
- Then 最下面一排「聊天 · 联系人 · 我」（2026-11-05 加了「联系人」，S34），照手机上的微信、WhatsApp、Telegram：一直钉在侧栏最下面，顶上的头也不动，中间的列表自己滚（本人选了「底下，钉住」，2026-11-04）。「聊天」上的红数字是所有聊天的未读，「我」上的是底子里等你点头的条数；「我」从首页右上挪到这一排，「＋」还在右上。进了一个聊天、群信息、叫人、账号这些下一层的页，这一排收起，同微信。两个字和图标是我起的稿。
- Then 没有单独的「需要你」一块（方向 ①，2026-11-03，本人选了「① 像微信」）：要我出面的聊天排在最上面，其余按最后一句的时间排。本人看了 0.5.29 说：「最大的不对就是它像一个任务列表，而不是 IM」（2026-11-03）。
- Then 每个聊天一行，照微信：头像（群是群头像，私聊是对方的头像），头像角上一个小圆点标出我在里面的分身（颜色加首字）；右边是群名或对方名字和时间，下面是最后一句（谁说的）；有未读时头像右上角一个红色数字。不挂分身标签，不画色条。
- Then 要我出面的那一行，最后一句前面加红字：被叫到写「[有人@我]」，五种事写「[等你定]」，任务写「[任务]」（我起的稿，本人定了「照这样定」，2026-11-03）。点这一行进那个聊天去办（S14、S15、S16）。
- Given 还没有聊天，Then 一句话，加两条路：建群、用链接进群，直接摆在首页中间；右上的「＋」照样在（草图 P1c，2026-11-03，本人）。

对照
- 微信：「微信」页就是会话列表，顶上只有「微信(未读数)」和「+」。
- WhatsApp：对话列表，顶上搜索和筛选（全部、未读、群组）。
