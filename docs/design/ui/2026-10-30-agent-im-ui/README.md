# 大模型 IM 界面示意（2026-10-30）

一个人和 agent 一起待着的 IM 在 Claude Code desktop 里长什么样。画板按一个人真实走过的路径排，不按规格章节排；功能怎么分、规格怎么改，由这些画面倒推。沿用 [2026-10-13 的样式令牌](../2026-10-13-gemflow-ui/StyleTokens.dc.html)：字体、配色、看板头部和标签页都和上一版一致，「消息」页进看板时不像另一个产品。标志换了：不再用 G 标，改成社交软件那一路的徽章，蓝圆白气泡里一颗宝石、右上角一个红点当 bang（`Brand.dc.html`），字样也从 Gemworks 改成 Gemsbang。样图里的主人叫 John，他的 agent 叫小评。

- 画布（可直接在页面上改）：https://claude.ai/artifact/6gEbzuTY9mRptrdQQNYGtR
- 源文件在 `project/`：`canvas.json` 是索引（每块画板在画布上的位置、大小、标题，以及每一排的标题注记），每个 `*.dc.html` 是一块画板，自包含。改版时改这里的文件，再用 Artifact 工具发布回同一个画布，`root` 指向本目录（文件已经在 `project/` 下）；或者在页面上改完再把源文件拉回来。
- 对应的规格：`docs/design/specs/2026-10-30-agent-im-design.md`（主文档）、`docs/design/specs/2026-10-30-agent-im-transport-design.md`（底座）。两份规格已按这版画面改过一遍（2026-10-30）；再冲突时，先改规格。

## 这一版定下的

- **标志是社交徽章**：蓝圆（#42b4f4 到 #0a74c0）白气泡，气泡里一颗宝石，右上角红点（#ef3b3f）是 bang，意思是「需要我」；远看是蓝圆白芯，和 Telegram、Messenger 排在一起不违和；圆形本身就是头像，手机和网页上不再套底色；应用图标用圆角方加斜向渐变（#1e9be8 到 #7a4dff）。
- **私信就是会话本身。** 输入框不变，对自己的 agent 说话就是在会话里说话；群里说话走看板「消息」页的输入框，发出去的是本人身份。
- **看板第六页「消息」放在最前，带未读计数**；其余五页顺序不变，默认打开页不变。
- **发言者只靠头像和名字行区分**：人是圆头像，agent 是圆角方头像叠一个主人的小徽章，名字行写「代 谁」。不用气泡颜色区分人和 agent；颜色留给证据绿、拒绝暗红、等批准琥珀、产物蓝，和上一版一致。
- **四种来源各有样式**：本人亲打无标记；agent 起草本人发出，名字行一个「小评起草」的小字，可一键去掉；agent 自己说的带徽章；转述主人的话是一段引用，标「本人原话」。
- **「已核实」只贴在宿主观察到的事实上**，意见另标「意见」；「回到那一轮」只有主人看得见。
- **@ 在句首是叫它干活，在句中是提及**；发送者看到排队中（前面几条）、已读入、已回应三档；离线显示「已留言」加过期时间；跳数超限的变成普通消息，宿主发一条系统消息说明。
- **存根是一个虚线框**，写明来自谁的私有范围、哪一轮，带「申请看」；不写内容的任何影子。
- **委托书先过目再发**：agent 起草，人只看七行；状态带在等别人放行时只说「待放行 · 等谁」。
- **任务卡的进度条是主路径的七个状态**，当前状态加粗，要改 / 争议 / 关闭进入时作为分支标在旁边；验收标准每条带验法标签；接单方名字旁一个「API · 可接单」的绿徽章，订阅登录的会话不显示这一栏。
- **交付卡先给预览和清单，再给验收对照**；机器验法的结果写「重跑」，审读的写意见等人勾；差异用 diff 的红绿；意见锚在文件行或视频的秒。
- **agent 主页像公众号**：四个动作按钮，三个数字，信誉写明记在谁和哪套配置上。
- **访客网页两栏**：左作品右对话；访客头像是灰色的「客」；不在公开范围的问题，agent 明说不讲。
- **手机上只有收件箱**：每条一个小卡、几个按钮；群内容不进手机。
- **状态带每种时候一行**：动词用颜色（放行和定是琥珀，验收是绿，卡住和断了是红），正文一句，动作按钮在行尾，「还有 N 件」和「看板」固定在最右；什么都不需要人时只说在哪。
- **桌面面板约一千一百个元素的上限**：消息页只渲染最近一屏，往上折叠成「还有 N 条更早的」。

## 下一版画板要改的

- 访客问答的额度改成积分：钱包页的「访客问答每天 ¥2.00 · 已用 ¥0.40」和账本里的「−¥0.40」、主页「访客能做什么」的「每个访客每天 ¥1.20」、访客私信头部的「今天还可用 ¥1.20 的额度」。规格已定平台上只有积分一种单位（主文档 §15 第 16 条）。
- 主页的「请它评」只在主人开了接单模式时显示；起草出的委托书上写对方的时段（主文档 §15 第 17 条）。
