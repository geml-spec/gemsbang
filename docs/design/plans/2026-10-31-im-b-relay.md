# IM B — The Relay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `gemworks relay`: the relay of transport spec §2 as a subcommand of the one binary — documents on disk as GEML hash chains, every block stamped by the token that wrote it, one queue per agent fed by plan A's delivery rules, presence with a heartbeat, the 「需要我」 inbox, grants and stubs, HTTPS-shaped read and write, WebSocket subscriptions — so plan C's daemon has something to connect to and plan E's guest page something to ask.

**Architecture:** Seven Node-side modules under `src/relay/` (they may use `node:fs`, `node:http`, `node:crypto`; nothing under `src/core/` changes). `store.ts` owns the files: one document per `<root>/<owner>/<doc>`, appended under `host-fs.ts`'s `withLock`, every block built inside the lock from the document as it stands so numbered blocks cannot collide and a client's repeated id is answered, not duplicated. `tokens.ts` keeps sha256 hashes of tokens under the owner `_relay`. `access.ts` is the one reading rule (owner, public home pages, venue members, the queue's agent, a per-block grant) and builds plan A's `Access` for embeds. `relay.ts` is the relay's state and verbs over those three, calling `core/im/*` for stamping (`stamp`), delivery (`deliver`), queues (`enqueue`, `readQueue`), venues (`setAnnounce`, `contextSegment`), density, needs. `api.ts` routes an already-parsed request to the relay's verbs and answers JSON or GEML; `ws.ts` is a minimal RFC 6455 server (text frames, ping, close; no fragmentation) because the package depends on nothing but the parser; `server.ts` is `node:http` around both. v1 is one relay: an embed naming another relay resolves to nothing, and `--federation closed` (the default) refuses to store one.

**Tech Stack:** TypeScript 5 (`strict`, `noUncheckedIndexedAccess`, `nodenext`: every relative import ends in `.js`), Node ≥ 22 (`node:http`, `node:crypto`, the global `fetch` and `WebSocket` in the tests), `node:test` over `dist/`, `@geml/geml` through `core/im/chain.ts`.

## Decisions this plan makes

1. **One binary.** The relay is `gemworks relay [--root dir] [--port N] [--name host] [--host addr] [--federation open|closed]`, documents under `~/.gemworks/relay/` by default; `gemworks relay token <person> [--root dir]` issues a person's token offline (the server need not run; both go through the same locked store). Transport §2.6's "自托管同一个二进制" holds from the first version.
2. **Tokens, not logins.** Email codes (§2.5) need a mail sender and are plan E's or later. A person's token is issued at the command line; an agent's by its owner over `POST /tokens` (scope `agent`, speaker `agent:<name>@<owner>`); a guest's by anyone over `POST /guests` (scope `guest`, `guest:g-<random>`); an inbox-only token (the phone bridge, §7.2) by the person over `POST /tokens {"scope":"inbox"}`. The relay keeps a sha256 of each token under the owner `_relay`, which no person can be named (a name may not begin with `_`).
3. **Every document is one chain.** A venue document is `#venue` (kind, name, members, policy), then `member-N`, `announce-N`, `decision-N`, the host's `sys-N` and the members' messages (ids the client chose), each sealed against the block before it. A queue document is plan A's: items chained among themselves (`enqueue`), markers `read-N` / `answered-N` outside the chain. A person's document holds `#person`, `trust-N`, `request-N` (someone asking to see one block), `grant-N` (a block for one person, or a scope widened), `refuse-N`. An agent's holds `#agent` (with its own `policy` on whose `@` it takes) and `session-N` registrations.
4. **Ids.** A message's block id is the client's (transport §2.5), `^[A-Za-z0-9][A-Za-z0-9_.-]{0,79}$`, not a reserved prefix (`venue`, `member`, `announce`, `decision`, `sys`, `read`, `answered`, `qi`, `grant`, `refuse`, `request`, `trust`, `session`, `token`, `revoke`, `person`, `agent`); a second append with the same id answers the block that is there with `existed: true` and raises nothing again. A queue item's id is `qi-<venue>-<message>`.
5. **The relay stamps.** `speaker` is the token's, `at` the relay's clock, `session` what an agent's request says (the daemon reports it, §2.4), `prev` and `hash` the chain's; the body's claims about any of these are dropped by `stamp`. `hops` is computed from the request's `handling` (the hops of the prompt the agent is answering) by `deliver`. A draft's own faults (`draftFaults`), an agent over the venue's density (`densityAllows`), and an embed naming another relay while federation is closed are refused with a reason.
6. **Delivery happens on append.** A message appended to a venue goes through `deliver` with the venue's agents (each with its owner's relations: trusted from the owner's `trust-N` blocks, members the venue's people; its own policy from `#agent` when set) and roster (people, agents by shown name, 所有人); every prompt becomes an item on that agent's queue, `queues/<agent>.geml` under the agent's owner, with `contextSegment` (the announce and the last five decisions as live embeds) and the message's own parts as its context pack; every system message `deliver` owes is appended as a `host` message `sys-N`.
7. **Reading.** `GET /<owner>/<doc>.geml` answers every block the viewer may read and a stub for every one they may not (`{"id", "stub": {"from", "note": "你看不到", "action": "申请看"}}`), as JSON by default and as a GEML document with `?format=geml` (or `Accept: text/plain`); `?block=<id>` one block, `#announce` meaning the latest `announce-N`. The rule (`access.ts`): the owner reads all of theirs; `people/*` and `agents/*` are public (an agent's home page is like a public account, §4); a venue's blocks are for its members (a person, their agent, a guest in the people list); `queues/<a>.geml` for `agent:<a>@<owner>`; anything else only by a `grant-N` naming that one block for that one person and not run out. A subscriber may subscribe to a document they may read as a whole.
8. **Presence is memory, sessions are records.** `POST /presence` from an agent's token keeps `{session, host, login, presence, task, at}` in the relay's memory, keyed by speaker and session; the first report of a session appends a `session-N` block to the agent's document (the registration of §2.5). An agent's presence is `agentPresence` over its sessions, one silent for three minutes counted asleep. The inbox's 断了 is a session reported alive whose heartbeat is older than three minutes.
9. **The inbox is computed, not stored** (§6.9). `GET /inbox` for a person: 定 for every `ask` in a venue they are in whose `who` is them and that no reply of theirs answers and that has not run out; 放行 for every `request-N` on their document with no `grant-N` or `refuse-N` naming it; 断了 as above. 验收 and 卡住 come with plans F and C. Sorted by `sortNeeds`.
10. **Idempotence and locks.** Every write is one `appendBlock` under the document's lock; the id of a numbered block and the chain's `prev` are read inside the lock; a client's resend is answered from the block already there. Two processes may write one root (the server and `relay token`): both use the same lock.
11. **WebSocket by hand.** `GET /subscribe?token=…` upgrades; the client sends `{"subscribe": "<owner>/<doc>"}` and gets `{"subscribed": …}` or `{"error": …}`; every block appended to a subscribed document is pushed as `{"doc", "block"}`, the block visible or a stub by the same rule as a read; `{"ping": x}` answers `{"pong": x}`. Server frames are unmasked text; client frames must be masked (RFC 6455 §5.1); a fragmented or binary frame closes the connection with 1003. Node's global `WebSocket` (undici) is the client in the tests.
12. **Errors are JSON with a status**: 400 a bad body, 401 no or invalid token, 403 the token may not, 404 no such path or document, 405 the method, 409 already there, 413 a body over 1 MB, 429 density. The CLI's usage line gains `relay`, and `test/cli.test.mjs`'s usage regex with it.

```ts
// Documents on the relay's disk (transport §2.2): `<root>/<owner>/<doc>`,
// each a GEML document of data blocks (core/im/chain.ts) written by append
// under the document's lock, its head a meta block naming it. An append is
// built from the document as it stands — its blocks and the last block's
// hash — inside the lock, so a numbered block cannot collide with another
// writer's; a block whose id is already there is answered as it is and
// nothing is written (transport §2.5: a client that sends again does not
// duplicate). The relay's own records live under the owner `_relay`, which no
// person can be named.
import { existsSync, readdirSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { appendOrCreate, withLock } from "../host-fs.js";
import { readDataBlocks, renderDataBlock, seal, type DataBlock } from "../core/im/chain.js";
import type { JsonValue } from "../core/schema.js";

/** A document's path under its owner: `/`-separated names of letters, digits, `_` and `-`, ending in `.geml`. */
export const DOC = /^(?:[A-Za-z0-9_-]+\/)*[A-Za-z0-9_-]+\.geml$/;
/** An owner, a venue or an agent as a client may name one: letters, digits, `_` and `-`, not beginning with `_` (the relay's own) or `.`, at most 64. */
export const NAME = /^[\p{L}\p{N}][\p{L}\p{N}_-]{0,63}$/u;
export const BLOCK_ID = /^[A-Za-z0-9][A-Za-z0-9_.-]{0,79}$/;
export const RELAY_OWNER = "_relay";

export const docPath = (root: string, owner: string, doc: string): string => join(root, owner, ...doc.split("/"));
export const docHead = (owner: string, doc: string): string => `=== meta\ntitle = "gemworks im ${owner}/${doc}"\n===\n\n`;

/** A document as read: its data blocks, the parse diagnostics, its text, whether it is there at all. */
export interface Doc { blocks: DataBlock[]; diagnostics: string[]; text: string; exists: boolean }

export function readDoc(root: string, owner: string, doc: string): Doc {
  const path = docPath(root, owner, doc);
  if (!existsSync(path)) return { blocks: [], diagnostics: [], text: "", exists: false };
  const text = readFileSync(path, "utf8");
  const { blocks, diagnostics } = readDataBlocks(text);
  return { blocks, diagnostics, text, exists: true };
}

export interface Appended { block: DataBlock; existed: boolean }

/** The hash of the document's last block, for the next one's `prev`; null when there is none or it has no hash. */
export function lastHash(d: Doc): string | null {
  const last = d.blocks[d.blocks.length - 1];
  return last !== undefined && typeof last.value["hash"] === "string" ? last.value["hash"] : null;
}

/**
 * Append one block, its id and its value built from the document as it
 * stands, under the document's lock. `idOf` names the block (a client's id,
 * or the next of a numbered kind, `nextId`); a block of that id already there
 * is answered as it is. `build` gets the document, the last block's hash and
 * the id, and returns the whole value.
 */
export function appendBlock(root: string, owner: string, doc: string, idOf: (d: Doc) => string, build: (d: Doc, prev: string | null, id: string) => Record<string, JsonValue>): Appended {
  const path = docPath(root, owner, doc);
  return withLock(path, () => {
    const d = readDoc(root, owner, doc);
    const id = idOf(d);
    if (!BLOCK_ID.test(id)) throw new Error(`block id ${JSON.stringify(id)} is not one`);
    const existing = d.blocks.find((b) => b.id === id);
    if (existing !== undefined) return { block: existing, existed: true };
    const value = build(d, lastHash(d), id);
    appendOrCreate(path, docHead(owner, doc), renderDataBlock(id, value));
    return { block: { id, value }, existed: false };
  });
}

/** The next id of a numbered kind, `<prefix>-<N>`: one past the blocks of exactly that kind. */
export function nextId(prefix: string): (d: Doc) => string {
  const own = new RegExp(`^${prefix}-\\d+$`);
  return (d) => `${prefix}-${d.blocks.filter((b) => own.test(b.id)).length + 1}`;
}

/** `seal` for a value typed as a record: the chain's two fields added, the record's type kept for the store. */
export const sealed = (value: Record<string, JsonValue>, prev: string | null): Record<string, JsonValue> => seal(value, prev) as Record<string, JsonValue>;

/** A block sealed on the document's chain (`prev` the last block's hash, `hash` over the rest, `id` inside), under the id given. */
export function appendSealed(root: string, owner: string, doc: string, id: string, value: Record<string, JsonValue>): Appended {
  return appendBlock(root, owner, doc, () => id, (_d, prev) => sealed({ ...value, id }, prev));
}

/** The documents under `<owner>/<dir>/`, as doc paths, sorted. */
export function listDocs(root: string, owner: string, dir: string): string[] {
  const at = join(root, owner, dir);
  if (!existsSync(at)) return [];
  return readdirSync(at).filter((n) => n.endsWith(".geml")).sort().map((n) => `${dir}/${n}`);
}

/** The owners with documents; the relay's own and hidden folders left out. */
export function listOwners(root: string): string[] {
  if (!existsSync(root)) return [];
  return readdirSync(root, { withFileTypes: true }).filter((e) => e.isDirectory() && !e.name.startsWith("_") && !e.name.startsWith(".")).map((e) => e.name).sort();
}
```

```ts
// Tokens (transport §2.4, §2.5): a person's, an agent's (issued by its
// owner, scoped to that agent), a guest's (made on the guest page), an
// inbox-only one (the phone bridge). The relay keeps only a sha256 of each,
// under its own owner `_relay`, one block per token and one per revocation;
// the token itself is shown once, to whoever asked for it. A request's
// speaker is its token's — a person's token speaks as `person:<id>`, an
// agent's as `agent:<name>@<owner>` — whatever the body claims.
import { createHash, randomBytes } from "node:crypto";
import { appendSealed, readDoc, RELAY_OWNER } from "./store.js";

export type Scope = "person" | "agent" | "guest" | "inbox";
const SCOPES: ReadonlySet<string> = new Set(["person", "agent", "guest", "inbox"]);
export interface TokenRecord { id: string; speaker: string; scope: Scope; at: string; by: string }
const TOKENS = "tokens.geml";

export const hashToken = (token: string): string => "sha256:" + createHash("sha256").update(token, "utf8").digest("hex");
const rand = (): string => randomBytes(6).toString("hex");

export function issueToken(root: string, o: { speaker: string; scope: Scope; by: string; at: string }): { token: string; record: TokenRecord } {
  const token = `gwx_${randomBytes(24).toString("hex")}`;
  const id = `token-${rand()}`;
  appendSealed(root, RELAY_OWNER, TOKENS, id, { token: hashToken(token), speaker: o.speaker, scope: o.scope, at: o.at, by: o.by });
  return { token, record: { id, speaker: o.speaker, scope: o.scope, at: o.at, by: o.by } };
}

/** The record a token stands for, or nothing: unknown, malformed, or revoked. */
export function verifyToken(root: string, token: string): TokenRecord | undefined {
  if (!token.startsWith("gwx_")) return undefined;
  const h = hashToken(token);
  const d = readDoc(root, RELAY_OWNER, TOKENS);
  const revoked = new Set(d.blocks.filter((b) => b.id.startsWith("revoke-")).map((b) => b.value["token"]));
  for (const b of d.blocks) {
    if (!b.id.startsWith("token-") || b.value["token"] !== h || revoked.has(b.id)) continue;
    const { speaker, scope, at, by } = b.value;
    if (typeof speaker !== "string" || typeof scope !== "string" || !SCOPES.has(scope)) return undefined;
    return { id: b.id, speaker, scope: scope as Scope, at: typeof at === "string" ? at : "", by: typeof by === "string" ? by : "" };
  }
  return undefined;
}

/** Revoke a token by its record's id; false when there is no such token. */
export function revokeToken(root: string, id: string, at: string): boolean {
  if (!readDoc(root, RELAY_OWNER, TOKENS).blocks.some((b) => b.id === id)) return false;
  appendSealed(root, RELAY_OWNER, TOKENS, `revoke-${rand()}`, { token: id, at });
  return true;
}
```

```ts
// Who may read a block (§5.1, §7.3): the owner reads everything of theirs
// (their agents as them); a person's and an agent's home pages are public;
// a venue's blocks are its members' (a member's agent reads as the member);
// an agent's queue is the agent's and its owner's; anything else — a session
// record, a journal, a card's private range — only by a grant naming that
// one block for that one person, until the grant runs out. An embed resolves
// by the same rule (core/im/embed.ts): content for a reader, a stub for
// anyone else, nothing for an address this relay does not hold.
import { parseAddress } from "../core/im/address.js";
import type { DataBlock } from "../core/im/chain.js";
import type { Access } from "../core/im/embed.js";
import { parseSpeaker, personBehind } from "../core/im/identity.js";
import { canonical } from "../core/snapshot.js";

export interface BlockGrant { person: string; block: string; until?: string }

/** What the rule needs to know, answered by the relay. */
export interface World {
  /** The venue's members as speakers, or undefined when the document is no venue. */
  membersOf(owner: string, doc: string): string[] | undefined;
  grantsOf(owner: string): BlockGrant[];
  now: string;
}

/** A document's first segment: `venues`, `people`, `queues`…; the whole name when it has no folder. */
export const kindOf = (doc: string): string => (doc.includes("/") ? doc.slice(0, doc.indexOf("/")) : doc);

export function canRead(o: { relay: string; owner: string; doc: string; block?: string; viewer: string }, w: World): boolean {
  const v = parseSpeaker(o.viewer);
  if (v === undefined || v.kind === "host") return false;
  const person = personBehind(v);
  if (person === o.owner) return true;
  const kind = kindOf(o.doc);
  if (kind === "people" || kind === "agents") return true;
  const members = w.membersOf(o.owner, o.doc);
  if (members !== undefined) return members.includes(o.viewer) || (person !== undefined && members.includes(`person:${person}`));
  if (kind === "queues") return o.viewer === `agent:${o.doc.slice("queues/".length, -".geml".length)}@${o.owner}`;
  if (o.block === undefined || person === undefined) return false;
  const address = `https://${o.relay}/${o.owner}/${o.doc}#${o.block}`;
  return w.grantsOf(o.owner).some((g) => g.person === person && g.block === address && (g.until === undefined || g.until > w.now));
}

/** A block's text as an embed shows it: a message's or an announce's text, else its canonical JSON. */
export const textOf = (b: DataBlock): string => (typeof b.value["text"] === "string" ? b.value["text"] : canonical(b.value));

/** The embed resolver for a viewer on this relay: `find` reads one block of a document the relay holds. */
export function accessFor(relay: string, w: World, find: (owner: string, doc: string, block: string) => DataBlock | undefined): Access {
  return (e, viewer) => {
    const a = parseAddress(e.src);
    if (a === undefined || a.relay !== relay || a.block === undefined) return undefined;
    const b = find(a.owner, a.doc, a.block);
    if (b === undefined) return undefined;
    const session = typeof b.value["session"] === "string" ? b.value["session"] : undefined;
    const turn = typeof b.value["turn"] === "string" ? b.value["turn"] : undefined;
    const extra = { ...(session !== undefined ? { session } : {}), ...(turn !== undefined ? { turn } : {}) };
    if (!canRead({ relay, owner: a.owner, doc: a.doc, block: a.block, viewer }, w)) return { denied: true, owner: a.owner, ...extra };
    return { text: textOf(b), hash: typeof b.value["hash"] === "string" ? b.value["hash"] : "", owner: a.owner, ...extra };
  };
}
```

```ts
  const out: Embed[] = [];

    const s = parseSpeaker(speaker);
    if (s === undefined) return;
    if (s.kind === "person") { if (!venue.people.includes(s.id)) venue.people.push(s.id); }
    else if (s.kind === "guest") { if (!venue.people.includes(speaker)) venue.people.push(speaker); }
    else if (s.kind === "agent" && !agentSpeakers.has(s.name)) { agentSpeakers.set(s.name, speaker); venue.agents.push(s.name); }
  };
  for (const p of strings(meta["people"])) join(p.includes(":") ? p : `person:${p}`);
  for (const a of strings(meta["agents"])) join(a);
  for (const b of d.blocks) {
    if (/^member-\d+$/.test(b.id)) { const s = str(b.value["speaker"]); if (s !== undefined) join(s); }
    else if (/^announce-\d+$/.test(b.id)) { const text = str(b.value["text"]); if (text !== undefined) venue.announce = { text, version: num(b.value["version"]) ?? 1, at: str(b.value["at"]) ?? "", by: str(b.value["by"]) ?? "" }; }
    else if (/^decision-\d+$/.test(b.id)) { const m = str(b.value["message"]); if (m !== undefined && !venue.decisions.includes(m)) venue.decisions.push(m); }
  }
  return { venue, agentSpeakers, messages: readMessages(d.text).messages, doc: d };
}

export class Relay {
  readonly root: string;
  readonly name: string;
  readonly federation: Federation;
  readonly version: string;
  private readonly clock: () => string;
  private readonly sessions = new Map<string, SessionPresence>();
  private readonly listeners = new Set<(p: Pushed) => void>();

  constructor(o: RelayOptions) {
    this.root = o.root;
    this.name = o.name;
    this.federation = o.federation ?? "closed";
    this.version = o.version ?? "unknown";
    this.clock = o.now ?? (() => new Date().toISOString().replace(/\.\d{3}Z$/, "Z"));
  }

  now(): string { return this.clock(); }
  /** Hear of every block appended; the function given back stops it. */
  onAppend(fn: (p: Pushed) => void): () => void { this.listeners.add(fn); return () => { this.listeners.delete(fn); }; }
  private emit(owner: string, doc: string, block: DataBlock): void { for (const fn of this.listeners) fn({ owner, doc, block }); }
  verify(token: string): TokenRecord | undefined { return verifyToken(this.root, token); }
  address(owner: string, doc: string, block?: string): string { return `https://${this.name}/${owner}/${doc}${block === undefined ? "" : `#${block}`}`; }

  // --- identities ---

  /** A person's token, their home page written if it was not. */
  issuePerson(id: string): Result<Issued> {
    if (!NAME.test(id)) return fail(400, "名字不合法");
    appendSealed(this.root, id, `people/${id}.geml`, "person", { name: id, at: this.now() });
    return { ok: true, ...issueToken(this.root, { speaker: `person:${id}`, scope: "person", by: "cli", at: this.now() }) };
  }

  /** An agent's token, issued by its owner; the agent's home page written with its policy on whose `@` it takes. */
  issueAgent(by: TokenRecord, name: string, policy?: unknown): Result<Issued> {
    const s = parseSpeaker(by.speaker);
    if (by.scope !== "person" || s?.kind !== "person") return fail(403, "只有本人的令牌能签发 agent 的令牌");
    if (!NAME.test(name)) return fail(400, "agent 名字不合法");
    const value: Record<string, JsonValue> = { name, owner: s.id, at: this.now() };
    const p = obj(policy);
    if (p !== undefined) {
      const promptFrom = str(p["promptFrom"]);
      if (promptFrom === undefined || !PROMPT_FROM.has(promptFrom)) return fail(400, "策略不合法");
      value["policy"] = { promptFrom, allow: strings(p["allow"]) };
    }
    const doc = `agents/${name}.geml`;
    const a = appendSealed(this.root, s.id, doc, "agent", value);
    if (!a.existed) this.emit(s.id, doc, a.block);
    return { ok: true, ...issueToken(this.root, { speaker: `agent:${name}@${s.id}`, scope: "agent", by: by.speaker, at: this.now() }) };
  }

  issueGuest(): Result<Issued> {
    return { ok: true, ...issueToken(this.root, { speaker: `guest:g-${rand()}`, scope: "guest", by: "guest", at: this.now() }) };
  }

  /** An inbox-only token of the person (the phone bridge). */
  issueInbox(by: TokenRecord): Result<Issued> {
    if (by.scope !== "person") return fail(403, "只有本人的令牌能签发收件箱令牌");
    return { ok: true, ...issueToken(this.root, { speaker: by.speaker, scope: "inbox", by: by.speaker, at: this.now() }) };
  }

  // --- the world the reading rule asks about ---

  world(): World {
    return {
      membersOf: (owner, doc) => {
        const m = /^venues\/([^/]+)\.geml$/.exec(doc);
        const vd = m === null ? undefined : this.venueOf(owner, m[1]!);
        return vd === undefined ? undefined : [...vd.venue.people.map((p) => (p.includes(":") ? p : `person:${p}`)), ...vd.agentSpeakers.values()];
      },
      grantsOf: (owner) => this.blockGrantsOf(owner),
      now: this.now(),
    };
  }

  /** One block of a document; `announce` is the latest `announce-N`. */
  find(owner: string, doc: string, block: string): DataBlock | undefined {
    const d = readDoc(this.root, owner, doc);
    if (block === "announce") { const all = d.blocks.filter((b) => /^announce-\d+$/.test(b.id)); return all[all.length - 1]; }
    return d.blocks.find((b) => b.id === block);
  }

  access(): Access { return accessFor(this.name, this.world(), (o, d, b) => this.find(o, d, b)); }

  // --- reading ---

  stubOf(owner: string, b: DataBlock): Stub {
    const stub: Stub = { from: owner, note: "你看不到", action: "申请看" };
    const session = str(b.value["session"]); if (session !== undefined) stub.session = session;
    const turn = str(b.value["turn"]); if (turn !== undefined) stub.turn = turn;
    return stub;
  }

  visible(owner: string, doc: string, b: DataBlock, viewer: string, w: World = this.world()): Visible {
    return canRead({ relay: this.name, owner, doc, block: b.id, viewer }, w) ? { id: b.id, value: b.value } : { id: b.id, stub: this.stubOf(owner, b) };
  }

  /** The document, or one block of it, as the viewer may see it (§5.1): a stub for each block they may not read; nothing at all when they may read none of it. */
  read(owner: string, doc: string, viewer: string, block?: string): Result<{ blocks: Visible[] }> {
    if (!NAME.test(owner) || !DOC.test(doc)) return fail(404, "没有这份文档");
    const d = readDoc(this.root, owner, doc);
    if (!d.exists) return fail(404, "没有这份文档");
    const w = this.world();
    const wanted = block === undefined ? d.blocks : [this.find(owner, doc, block)].filter((b): b is DataBlock => b !== undefined);
    if (block !== undefined && wanted.length === 0) return fail(404, "没有这个块");
    const blocks = wanted.map((b) => this.visible(owner, doc, b, viewer, w));
    if (blocks.length > 0 && blocks.every((b) => b.stub !== undefined) && !canRead({ relay: this.name, owner, doc, viewer }, w)) return fail(403, "无权读这份文档");
    return { ok: true, blocks };
  }

  /** Whether the viewer may follow the document as a whole (a subscription). */
  mayFollow(owner: string, doc: string, viewer: string): boolean {
    return NAME.test(owner) && DOC.test(doc) && canRead({ relay: this.name, owner, doc, viewer }, this.world());
  }

  /** The blocks as a GEML document: a stub as a data block that says so. */
  renderVisible(blocks: readonly Visible[]): string {
    return blocks.map((b) => renderDataBlock(b.id, (b.value !== undefined ? b.value : { stub: true, ...b.stub }) as unknown as JsonValue)).join("");
  }

  // --- venues ---

  venueOf(owner: string, id: string): VenueDoc | undefined {
    if (!NAME.test(owner) || !NAME.test(id)) return undefined;
    const d = readDoc(this.root, owner, `venues/${id}.geml`);
    return d.exists ? foldVenue(owner, id, d, this.name) : undefined;
  }

  /** Whether the speaker is in the venue: a person by id, a guest as `guest:<id>` among the people, an agent as itself, the host always. */
  isMember(vd: VenueDoc, s: Speaker): boolean {
    switch (s.kind) {
      case "person": return vd.venue.people.includes(s.id);
      case "guest": return vd.venue.people.includes(`guest:${s.id}`);
      case "agent": return vd.agentSpeakers.get(s.name) === formatSpeaker(s);
      case "host": return true;
    }
  }

  private ownerOnly(by: TokenRecord, owner: string): Fail | undefined {
    return by.scope === "person" && by.speaker === `person:${owner}` ? undefined : fail(403, "只有场所的主人能这么做");
  }

  /** A venue made by a person, under their name, themself first among its people (§6.2). */
  createVenue(by: TokenRecord, body: unknown): Result<{ venue: Venue }> {
    const s = parseSpeaker(by.speaker);
    if (by.scope !== "person" || s?.kind !== "person") return fail(403, "只有本人的令牌能建场所");
    const b = obj(body);
    if (b === undefined) return fail(400, "要一个 JSON 对象");
    const id = str(b["id"]), kind = str(b["kind"]);
    if (id === undefined || !NAME.test(id)) return fail(400, "场所 id 不合法");
    if (kind === undefined || !(kind in VENUE_WORDS)) return fail(400, "场所种类不合法");
    const people = strings(b["people"]), agents = strings(b["agents"]);
    for (const p of people) if (!(NAME.test(p) || parseSpeaker(p)?.kind === "guest")) return fail(400, `成员 ${p} 不合法`);
    for (const a of agents) if (parseSpeaker(a)?.kind !== "agent") return fail(400, `agent ${a} 不合法`);
    if (!people.includes(s.id)) people.unshift(s.id);
    const value: Record<string, JsonValue> = { kind, name: str(b["name"]) ?? id, people, agents, policy: policyOf(b["policy"]) as unknown as JsonValue, at: this.now() };
    const host = kind === "guest-dm" && agents[0] !== undefined ? parseSpeaker(agents[0]) : undefined;
    if (host?.kind === "agent") value["host"] = host.name;
    for (const k of ["anchor", "parent"] as const) { const v = str(b[k]); if (v !== undefined) value[k] = v; }
    const doc = `venues/${id}.geml`;
    if (readDoc(this.root, s.id, doc).exists) return fail(409, "场所已存在");
    const a = appendSealed(this.root, s.id, doc, "venue", value);
    this.emit(s.id, doc, a.block);
    return { ok: true, venue: this.venueOf(s.id, id)!.venue };
  }

  addMember(by: TokenRecord, owner: string, id: string, speaker: string): Result<{ venue: Venue }> {
    const denied = this.ownerOnly(by, owner);
    if (denied !== undefined) return denied;
    const vd = this.venueOf(owner, id);
    if (vd === undefined) return fail(404, "没有这个场所");
    const s = parseSpeaker(speaker);
    if (s === undefined || s.kind === "host") return fail(400, "成员不合法");
    if (s.kind === "agent" && vd.agentSpeakers.has(s.name) && vd.agentSpeakers.get(s.name) !== speaker) return fail(409, `已有一个叫 ${s.name} 的 agent`);
    if (this.isMember(vd, s)) return { ok: true, venue: vd.venue };
    const doc = `venues/${id}.geml`;
    const a = appendBlock(this.root, owner, doc, nextId("member"), (_d, prev, bid) => sealed({ id: bid, speaker, at: this.now(), by: by.speaker }, prev));
    this.emit(owner, doc, a.block);
    return { ok: true, venue: this.venueOf(owner, id)!.venue };
  }

  /** The announce replaced (§6.8): one more version, and a system message in the venue. */
  setAnnounce(by: TokenRecord, owner: string, id: string, text: string): Result<{ venue: Venue; system: Message }> {
    const denied = this.ownerOnly(by, owner);
    if (denied !== undefined) return denied;
    const vd = this.venueOf(owner, id);
    if (vd === undefined) return fail(404, "没有这个场所");
    const r = announce(vd.venue, text, by.speaker, this.now());
    if ("fault" in r) return fail(400, r.fault);
    const doc = `venues/${id}.geml`;
    const next = r.venue.announce!;
    const a = appendBlock(this.root, owner, doc, nextId("announce"), (_d, prev, bid) => sealed({ id: bid, text: next.text, version: next.version, at: next.at, by: next.by }, prev));
    this.emit(owner, doc, a.block);
    const system = this.appendSystem(owner, id, r.system);
    return { ok: true, venue: this.venueOf(owner, id)!.venue, system };
  }

  /** A message marked 决策 by any member (§6.8), once. */
  markDecision(by: TokenRecord, owner: string, id: string, messageId: string): Result<{ venue: Venue }> {
    const vd = this.venueOf(owner, id);
    if (vd === undefined) return fail(404, "没有这个场所");
    const s = parseSpeaker(by.speaker);
    if (s === undefined || by.scope === "inbox" || !this.isMember(vd, s)) return fail(403, "不是这个场所的成员");
    if (!vd.messages.some((m) => m.id === messageId)) return fail(404, "没有这条消息");
    const doc = `venues/${id}.geml`;
    const address = this.address(owner, doc, messageId);
    if (vd.venue.decisions.includes(address)) return { ok: true, venue: vd.venue };
    const a = appendBlock(this.root, owner, doc, nextId("decision"), (_d, prev, bid) => sealed({ id: bid, message: address, at: this.now(), by: by.speaker }, prev));
    this.emit(owner, doc, a.block);
    return { ok: true, venue: this.venueOf(owner, id)!.venue };
  }

  /** A system message from the host (§6.3), `sys-N`. */
  private appendSystem(owner: string, id: string, text: string): Message {
    const doc = `venues/${id}.geml`;
    const a = appendBlock(this.root, owner, doc, nextId("sys"), (_d, prev, bid) => stamp({ venue: id, kind: "system", text }, { id: bid, speaker: { kind: "host" }, at: this.now(), prev }) as unknown as Record<string, JsonValue>);
    this.emit(owner, doc, a.block);
    return toMessage(a.block)!;
  }

  /**
   * A member's message, stamped by their token (rule 1) and delivered (§6.5):
   * the prompts it raises go on the agents' queues, the system messages it
   * owes into the venue. The same id again answers the message that is there.
   */
  appendMessage(by: TokenRecord, owner: string, id: string, body: unknown): Result<{ message: Message; existed: boolean; delivery: Delivery }> {
    const vd = this.venueOf(owner, id);
    if (vd === undefined) return fail(404, "没有这个场所");
    const s = parseSpeaker(by.speaker);
    if (s === undefined) return fail(401, "令牌无效");
    if (by.scope === "inbox") return fail(403, "收件箱令牌不能发言");
    if (!this.isMember(vd, s)) return fail(403, "不是这个场所的成员");
    const b = obj(body);
    if (b === undefined) return fail(400, "要一个 JSON 对象");
    const mid = str(b["id"]);
    if (mid === undefined || !BLOCK_ID.test(mid) || RESERVED.test(mid)) return fail(400, "消息 id 不合法");
    const kind = str(b["kind"]) ?? "chat";
    if (!(kind in KIND_WORDS)) return fail(400, "消息种类不合法");
    const parts = embedsOf(b["parts"]), evidence = embedsOf(b["evidence"]);
    if (typeof parts === "string") return fail(400, `parts：${parts}`);
    if (typeof evidence === "string") return fail(400, `evidence：${evidence}`);
    if (this.federation === "closed") {
      const foreign = [...parts, ...evidence].find((e) => parseAddress(e.src)?.relay !== this.name);
      if (foreign !== undefined) return fail(400, `引用了别的中继：${foreign.src}（联邦开关关着）`);
    }
    const draft: Draft = { venue: id, kind: kind as MessageKind, text: str(b["text"]) ?? "", parts, evidence };
    const source = str(b["source"]);
    if (source !== undefined) { if (!SOURCES.has(source)) return fail(400, "来源不合法"); draft.source = source as Source; }
    for (const k of ["opinion", "turn", "card", "thread", "replyTo"] as const) { const v = str(b[k]); if (v !== undefined) draft[k] = v; }
    const ask = obj(b["ask"]);
    if (ask !== undefined) {
      const a: Ask = { question: str(ask["question"]) ?? "", options: strings(ask["options"]), who: str(ask["who"]) ?? "" };
      const expires = str(ask["expires"]); if (expires !== undefined) a.expires = expires;
      const fallback = str(ask["fallback"]); if (fallback !== undefined) a.fallback = fallback;
      draft.ask = a;
    }
    const faults = draftFaults(draft, s);
    if (faults.length > 0) return fail(400, faults.join("；"));
    if (s.kind === "agent") {
      const d = densityAllows(vd.messages.slice(-200).map((m) => ({ speaker: m.speaker, at: m.at })), by.speaker, this.now(), vd.venue.policy.density);
      if (!d.ok) return fail(429, d.reason);
    }
    const session = s.kind === "agent" ? str(b["session"]) : undefined;
    const handling = s.kind === "agent" ? num(b["handling"]) : undefined;
    const expires = str(b["expires"]);
    const doc = `venues/${id}.geml`;
    const a = appendBlock(this.root, owner, doc, () => mid, (_d, prev, bid) => stamp(draft, { id: bid, speaker: s, at: this.now(), prev, ...(session !== undefined ? { session } : {}) }) as unknown as Record<string, JsonValue>);
    const message = toMessage(a.block);
    if (message === undefined) return fail(409, "这个 id 已被别的块占用");
    if (a.existed) return { ok: true, message, existed: true, delivery: NOTHING };
    this.emit(owner, doc, a.block);
    const delivery = deliver(message, this.deliveryInput(vd, handling));
    for (const p of delivery.prompts) this.enqueueFor(vd, message, p, expires);
    for (const text of delivery.system) this.appendSystem(owner, id, text);
    return { ok: true, message, existed: false, delivery };
  }

  /** The agent's own policy on whose `@` it takes, from its home page; none means the venue's. */
  private agentPolicy(owner: string, name: string): { promptFrom: PromptFrom; allow: string[] } | undefined {
    const p = obj(readDoc(this.root, owner, `agents/${name}.geml`).blocks.find((b) => b.id === "agent")?.value["policy"]);
    const promptFrom = p === undefined ? undefined : str(p["promptFrom"]);
    return promptFrom !== undefined && PROMPT_FROM.has(promptFrom) ? { promptFrom: promptFrom as PromptFrom, allow: strings(p!["allow"]) } : undefined;
  }

  private deliveryInput(vd: VenueDoc, handling: number | undefined): DeliveryInput {
    const agents: AgentInVenue[] = [...vd.agentSpeakers].map(([name, speaker]) => {
      const a = parseSpeaker(speaker) as Extract<Speaker, { kind: "agent" }>;
      const policy = this.agentPolicy(a.owner, a.name);
      return { name, speaker, relations: { owner: a.owner, trusted: this.trustedOf(a.owner), members: vd.venue.people }, ...(policy !== undefined ? { policy } : {}) };
    });
    const roster: RosterEntry[] = [
      ...vd.venue.people.filter((p) => !p.includes(":")).map((name): RosterEntry => ({ name, kind: "person" })),
      ...vd.venue.agents.map((name): RosterEntry => ({ name, kind: "agent" })),
      { name: "所有人", kind: "everyone" },
    ];
    return { venue: vd.venue, agents, roster, ...(handling !== undefined ? { handling } : {}) };
  }

  /** One prompt onto the agent's queue (§6.5), with the venue's context pack (rule 3) and the message's own parts. */
  private enqueueFor(vd: VenueDoc, m: Message, p: PromptTo, expires: string | undefined): void {
    const speaker = vd.agentSpeakers.get(p.agent);
    const a = speaker === undefined ? undefined : parseSpeaker(speaker);
    if (a === undefined || a.kind !== "agent") return;
    const doc = `queues/${a.name}.geml`;
    const id = `qi-${vd.venue.id}-${m.id}`;
    const r = appendBlock(this.root, a.owner, doc, () => id, (d) => {
      const { queue } = readQueue(d.text);
      const draft: ItemDraft = { id, prompt: m.text, sender: m.speaker, senderName: shownName(m.speaker), level: p.level, venue: vd.venue.id, venueKind: vd.venue.kind, venueName: vd.venue.name, message: `${vd.venue.address}#${m.id}`, at: m.at, hops: p.hops, context: [...contextSegment(vd.venue), ...m.parts] };
      if (expires !== undefined) draft.expires = expires;
      return enqueue(queue, draft).item as unknown as Record<string, JsonValue>;
    });
    if (!r.existed) this.emit(a.owner, doc, r.block);
  }

  // --- queues ---

  private queueAccess(by: TokenRecord, owner: string, agent: string): Fail | undefined {
    return by.speaker === `person:${owner}` || by.speaker === `agent:${agent}@${owner}` ? undefined : fail(403, "只有这个 agent 和它的主人能看队列");
  }

  queueOf(by: TokenRecord, owner: string, agent: string): Result<{ queue: Queue; pending: QueueItem[] }> {
    const denied = this.queueAccess(by, owner, agent);
    if (denied !== undefined) return denied;
    if (!NAME.test(owner) || !NAME.test(agent)) return fail(404, "没有这个 agent");
    const { queue } = readQueue(readDoc(this.root, owner, `queues/${agent}.geml`).text);
    return { ok: true, queue, pending: pending(queue, this.now()) };
  }

  /** The daemon's mark on an item: read in, or answered with the reply's address. */
  mark(by: TokenRecord, owner: string, agent: string, kind: string, item: string, reply?: string): Result<{ marker: Marker }> {
    const denied = this.queueAccess(by, owner, agent);
    if (denied !== undefined) return denied;
    if (kind !== "read" && kind !== "answered") return fail(400, "标记只有 read 和 answered");
    const doc = `queues/${agent}.geml`;
    if (!readQueue(readDoc(this.root, owner, doc).text).queue.items.some((i) => i.id === item)) return fail(404, "队列里没有这一条");
    const a = appendBlock(this.root, owner, doc, nextId(kind), () => ({ kind, item, at: this.now(), ...(reply !== undefined ? { reply } : {}) }));
    this.emit(owner, doc, a.block);
    const marker: Marker = { kind, n: Number(a.block.id.slice(kind.length + 1)), item, at: str(a.block.value["at"]) ?? "" };
    if (reply !== undefined) marker.reply = reply;
    return { ok: true, marker };
  }

  // --- presence ---

  /** A session's presence from its agent's token (transport §3); the session is registered on the agent's page the first time it reports. */
  setPresence(by: TokenRecord, body: unknown): Result<{ presence: Presence }> {
    const s = parseSpeaker(by.speaker);
    if (by.scope !== "agent" || s?.kind !== "agent") return fail(403, "只有 agent 的令牌能报在场");
    const b = obj(body) ?? {};
    const session = str(b["session"]), presence = str(b["presence"]);
    if (session === undefined || !NAME.test(session)) return fail(400, "缺会话 id");
    if (presence === undefined || !PRESENCES.has(presence)) return fail(400, "在场状态不合法");
    const key = `${by.speaker}/${session}`;
    const known = this.sessions.get(key);
    const rec: SessionPresence = { speaker: by.speaker, session, host: str(b["host"]) ?? known?.host ?? "", login: str(b["login"]) ?? known?.login ?? "", presence: presence as Presence, at: this.now() };
    const task = str(b["task"]); if (task !== undefined) rec.task = task;
    this.sessions.set(key, rec);
    if (known === undefined) {
      const doc = `agents/${s.name}.geml`;
      const a = appendBlock(this.root, s.owner, doc, nextId("session"), (_d, prev, bid) => sealed({ id: bid, session, host: rec.host, login: rec.login, at: rec.at }, prev));
      this.emit(s.owner, doc, a.block);
    }
    return { ok: true, presence: rec.presence };
  }

  sessionsOf(speaker: string): SessionPresence[] { return [...this.sessions.values()].filter((r) => r.speaker === speaker); }

  /** The agent's presence (§6.10): its most active session, one silent for three minutes counted asleep. */
  presenceOf(speaker: string): { presence: Presence; at?: string; sessions: SessionPresence[] } {
    const now = Date.parse(this.now());
    const sessions = this.sessionsOf(speaker);
    const presence = agentPresence(sessions.map((r) => ({ presence: now - Date.parse(r.at) > STALE_MS ? "asleep" : r.presence })));
    const at = sessions.map((r) => r.at).sort().pop();
    return { presence, ...(at !== undefined ? { at } : {}), sessions };
  }

  // --- trust, requests, grants ---

  private personDoc(id: string): string { return `people/${id}.geml`; }

  trust(by: TokenRecord, person: string): Result<Record<never, never>> {
    if (by.scope !== "person") return fail(403, "只有本人能标信任");
    if (!NAME.test(person)) return fail(400, "名字不合法");
    const me = by.speaker.slice("person:".length);
    if (this.trustedOf(me).includes(person)) return { ok: true };
    const doc = this.personDoc(me);
    const a = appendBlock(this.root, me, doc, nextId("trust"), (_d, prev, bid) => sealed({ id: bid, person, at: this.now() }, prev));
    this.emit(me, doc, a.block);
    return { ok: true };
  }

  trustedOf(owner: string): string[] {
    return readDoc(this.root, owner, this.personDoc(owner)).blocks.filter((b) => /^trust-\d+$/.test(b.id)).map((b) => str(b.value["person"])).filter((p): p is string => p !== undefined);
  }

  /** Someone asks to see one block of the owner's (§7.3): a request on the owner's page, a 放行 in their inbox. */
  requestGrant(by: TokenRecord, owner: string, block: string, reason?: string): Result<{ id: string }> {
    if (by.scope === "inbox") return fail(403, "收件箱令牌不能申请");
    if (!NAME.test(owner)) return fail(404, "没有这个人");
    const a = parseAddress(block);
    if (a === undefined || a.relay !== this.name || a.owner !== owner || a.block === undefined) return fail(400, "要一个这个中继上、这个主人名下、带块的地址");
    if (!readDoc(this.root, owner, this.personDoc(owner)).exists) return fail(404, "没有这个人");
    const doc = this.personDoc(owner);
    const r = appendBlock(this.root, owner, doc, nextId("request"), (_d, prev, bid) => sealed({ id: bid, from: by.speaker, block, at: this.now(), ...(reason !== undefined ? { reason } : {}) }, prev));
    this.emit(owner, doc, r.block);
    return { ok: true, id: r.block.id };
  }

  /**
   * A grant by the owner (§7.3): one block for one person (允许一次: an hour;
   * 允许此人: seven days unless `until` says otherwise), or a scope widened
   * for them (`widen`: write, run, budget). Every grant is a record.
   */
  grant(by: TokenRecord, body: unknown): Result<{ id: string }> {
    if (by.scope !== "person") return fail(403, "只有本人能放行");
    const me = by.speaker.slice("person:".length);
    const b = obj(body) ?? {};
    const person = str(b["person"]);
    if (person === undefined || !NAME.test(person)) return fail(400, "放给谁？");
    const block = str(b["block"]), widen = obj(b["widen"]);
    if (block === undefined && widen === undefined) return fail(400, "要放一个块，或放宽范围");
    const at = this.now();
    const value: Record<string, JsonValue> = { to: { person }, at };
    if (block !== undefined) {
      const a = parseAddress(block);
      if (a === undefined || a.relay !== this.name || a.owner !== me || a.block === undefined) return fail(403, "只能放自己名下的块");
      value["block"] = block;
    }
    if (widen !== undefined) {
      const w: Record<string, JsonValue> = {};
      if (widen["write"] === true) w["write"] = true;
      const run = str(widen["run"]); if (run !== undefined) { if (!RUNS.has(run)) return fail(400, "run 不合法"); w["run"] = run as Run; }
      const budget = num(widen["budget"]); if (budget !== undefined) w["budget"] = budget;
      value["widen"] = w;
    }
    const until = str(b["until"]);
    value["until"] = until !== undefined ? until : b["once"] === true ? new Date(Date.parse(at) + ONE_HOUR_MS).toISOString().replace(/\.\d{3}Z$/, "Z") : grantUntil(at);
    const request = str(b["request"]); if (request !== undefined) value["request"] = request;
    const doc = this.personDoc(me);
    const g = appendBlock(this.root, me, doc, nextId("grant"), (_d, prev, bid) => sealed({ id: bid, ...value }, prev));
    this.emit(me, doc, g.block);
    return { ok: true, id: g.block.id };
  }

  refuse(by: TokenRecord, request: string): Result<Record<never, never>> {
    if (by.scope !== "person") return fail(403, "只有本人能拒绝");
    const me = by.speaker.slice("person:".length);
    const doc = this.personDoc(me);
    if (!readDoc(this.root, me, doc).blocks.some((b) => b.id === request)) return fail(404, "没有这个申请");
    const r = appendBlock(this.root, me, doc, nextId("refuse"), (_d, prev, bid) => sealed({ id: bid, request, at: this.now() }, prev));
    this.emit(me, doc, r.block);
    return { ok: true };
  }

  private grantBlocks(owner: string): DataBlock[] {
    return readDoc(this.root, owner, this.personDoc(owner)).blocks.filter((b) => /^grant-\d+$/.test(b.id));
  }

  blockGrantsOf(owner: string): BlockGrant[] {
    const out: BlockGrant[] = [];
    for (const b of this.grantBlocks(owner)) {
      const person = str(obj(b.value["to"])?.["person"]), block = str(b.value["block"]);
      if (person === undefined || block === undefined) continue;
      const g: BlockGrant = { person, block };
      const until = str(b.value["until"]); if (until !== undefined) g.until = until;
      out.push(g);
    }
    return out;
  }

  /** The grants that widen a tool scope (core/im/sender.ts `scopeFor`), for the owner's daemon. */
  scopeGrantsOf(owner: string): Grant[] {
    const out: Grant[] = [];
    for (const b of this.grantBlocks(owner)) {
      const person = str(obj(b.value["to"])?.["person"]), widen = obj(b.value["widen"]);
      if (person === undefined || widen === undefined) continue;
      const g: Grant = { to: { person }, widen: widen as Grant["widen"], at: str(b.value["at"]) ?? "" };
      const until = str(b.value["until"]); if (until !== undefined) g.until = until;
      out.push(g);
    }
    return out;
  }

  // --- the inbox ---

  /** Every venue the person is in, across owners. */
  venuesOf(person: string): VenueDoc[] {
    const out: VenueDoc[] = [];
    for (const owner of listOwners(this.root)) for (const doc of listDocs(this.root, owner, "venues")) {
      const vd = this.venueOf(owner, doc.slice("venues/".length, -".geml".length));
      if (vd !== undefined && vd.venue.people.includes(person)) out.push(vd);
    }
    return out;
  }

  /** The person's 「需要我」 (§6.9), computed: 定, 放行, 断了 here; 验收 and 卡住 come from the cards and the daemon. */
  inbox(person: string): Need[] {
    const out: Need[] = [];
    const me = `person:${person}`;
    const now = this.now();
    for (const vd of this.venuesOf(person)) {
      for (const m of vd.messages) {
        if (m.kind !== "ask" || m.ask === undefined || (m.ask.who !== me && m.ask.who !== person)) continue;
        if (m.ask.expires !== undefined && m.ask.expires <= now) continue;
        if (vd.messages.some((r) => r.replyTo === m.id && r.speaker === me)) continue;
        out.push({ kind: "decide", key: `${vd.venue.address}#${m.id}`, text: `${VENUE_WORDS[vd.venue.kind]}「${vd.venue.name}」· ${shownName(m.speaker)} 问：${m.ask.question}`, actions: defaultActions("decide", { options: m.ask.options }), since: m.at, venue: vd.venue.id, level: 0 });
      }
    }
    const pd = readDoc(this.root, person, this.personDoc(person));
    const answered = new Set(pd.blocks.filter((b) => /^(grant|refuse)-\d+$/.test(b.id)).map((b) => str(b.value["request"])));
    for (const b of pd.blocks) {
      if (!/^request-\d+$/.test(b.id) || answered.has(b.id)) continue;
      const from = str(b.value["from"]) ?? "", block = str(b.value["block"]) ?? "", reason = str(b.value["reason"]);
      out.push({ kind: "grant", key: this.address(person, this.personDoc(person), b.id), text: `${shownName(from)} 申请看 ${block}${reason === undefined ? "" : `：${reason}`}`, actions: defaultActions("grant", {}), since: str(b.value["at"]) ?? "", level: 0 });
    }
    const t = Date.parse(now);
    for (const r of this.sessions.values()) {
      const a = parseSpeaker(r.speaker);
      if (a?.kind !== "agent" || a.owner !== person || r.presence === "asleep") continue;
      const age = t - Date.parse(r.at);
      if (age > STALE_MS) out.push({ kind: "offline", key: `offline:${r.speaker}/${r.session}`, text: `你电脑上的守护进程 ${Math.floor(age / 60_000)} 分钟没心跳（${a.name} · ${r.session}）`, actions: defaultActions("offline", {}), since: r.at, level: 0 });
    }
    return sortNeeds(out);
  }
}
```

```ts
// The relay's HTTP surface (transport §2.5), as a function from a parsed
// request to a status and a body, so it is tested without a socket and
// served by server.ts. Every answer is JSON (`{"error": …}` on a failure)
// except a document asked for as GEML. The token names the speaker; the
// body never does. Statuses: 400 a bad body, 401 no or an invalid token,
// 403 the token may not, 404 nothing there, 405 the method, 409 already
// there, 429 density.
import type { Relay, Result } from "./relay.js";
import type { TokenRecord } from "./tokens.js";

export interface ApiRequest {
  method: string;
  path: string;
  query: Record<string, string>;
  token?: string;
  /** The body parsed as JSON, when there was one. */
  body?: unknown;
  /** The client asked for text (`Accept: text/plain`). */
  geml?: boolean;
}
export interface ApiResponse { status: number; body: string; type: string }

export const JSON_TYPE = "application/json; charset=utf-8";
export const GEML_TYPE = "text/plain; charset=utf-8";

const json = (status: number, value: unknown): ApiResponse => ({ status, body: JSON.stringify(value), type: JSON_TYPE });
const fail = (status: number, reason: string): ApiResponse => json(status, { error: reason });
const str = (v: unknown): string | undefined => (typeof v === "string" ? v : undefined);
const obj = (v: unknown): Record<string, unknown> => (typeof v === "object" && v !== null && !Array.isArray(v) ? (v as Record<string, unknown>) : {});

/** A verb's result as an answer: its fields without `ok`, or the failure's status and reason. */
function answer<T extends object>(r: Result<T>, status = 200, pick?: (t: T) => unknown): ApiResponse {
  if (!r.ok) return fail(r.status, r.reason);
  const { ok: _ok, ...rest } = r;
  return json(status, pick === undefined ? rest : pick(rest as T));
}

const scopeOf = (by: TokenRecord): "person" | "other" => (by.scope === "person" || by.scope === "inbox" ? "person" : "other");

export function route(r: ApiRequest, relay: Relay): ApiResponse {
  const parts = r.path.split("/").filter((p) => p !== "").map((p) => { try { return decodeURIComponent(p); } catch { return p; } });
  const m = r.method.toUpperCase();
  const [a, b, c, d] = parts;
  if (parts.length === 0) return m === "GET" ? json(200, { name: relay.name, version: relay.version, federation: relay.federation }) : fail(405, "只有 GET");
  if (a === "guests" && parts.length === 1) return m === "POST" ? answer(relay.issueGuest(), 201, (x) => ({ token: x.token, speaker: x.record.speaker })) : fail(405, "只有 POST");
  const by = r.token === undefined ? undefined : relay.verify(r.token);
  if (r.token === undefined) return fail(401, "要令牌");
  if (by === undefined) return fail(401, "令牌无效");
  const body = obj(r.body);
```

```ts
// The least of RFC 6455 the relay's subscriptions need (transport §2.5),
// written here because the package depends on nothing but the parser: the
// accept key, text frames with the three length forms, the masking a client
// must apply and a server must not, ping answered with pong, close with a
// code. No fragmentation, no binary, no extensions: a frame of either closes
// the connection with 1003 (unsupported data).
import { createHash } from "node:crypto";
import type { IncomingMessage } from "node:http";
import type { Duplex } from "node:stream";

const GUID = "258EAFA5-E914-47DA-95CA-C5AB0DC85B11";

export const acceptKey = (key: string): string => createHash("sha1").update(key + GUID).digest("base64");

export const TEXT = 0x1, CLOSE = 0x8, PING = 0x9, PONG = 0xa;

/** A server frame: final, unmasked, the payload's length in the shortest form that holds it. */
export function encodeFrame(text: string | Buffer, opcode = TEXT): Buffer {
  const data = typeof text === "string" ? Buffer.from(text, "utf8") : text;
  const len = data.length;
  let head: Buffer;
  if (len < 126) head = Buffer.from([0x80 | opcode, len]);
  else if (len < 65536) { head = Buffer.alloc(4); head[0] = 0x80 | opcode; head[1] = 126; head.writeUInt16BE(len, 2); }
  else { head = Buffer.alloc(10); head[0] = 0x80 | opcode; head[1] = 127; head.writeBigUInt64BE(BigInt(len), 2); }
  return Buffer.concat([head, data]);
}

export interface Frame { fin: boolean; opcode: number; payload: Buffer }

/** The frame at the front of the buffer and what follows it, or undefined while it is not whole yet. */
export function decodeFrame(buf: Buffer): { frame: Frame; rest: Buffer } | undefined {
  if (buf.length < 2) return undefined;
  const b0 = buf[0]!, b1 = buf[1]!;
  const fin = (b0 & 0x80) !== 0, opcode = b0 & 0x0f, isMasked = (b1 & 0x80) !== 0;
  let len = b1 & 0x7f, at = 2;
  if (len === 126) { if (buf.length < 4) return undefined; len = buf.readUInt16BE(2); at = 4; }
  else if (len === 127) {
    if (buf.length < 10) return undefined;
    const big = buf.readBigUInt64BE(2);
    if (big > BigInt(Number.MAX_SAFE_INTEGER)) throw new Error("frame too long");
    len = Number(big); at = 10;
  }
  const maskLen = isMasked ? 4 : 0;
  if (buf.length < at + maskLen + len) return undefined;
  const mask = isMasked ? buf.subarray(at, at + 4) : undefined;
  at += maskLen;
  const payload = Buffer.from(buf.subarray(at, at + len));
  if (mask !== undefined) for (let i = 0; i < payload.length; i++) payload[i] = payload[i]! ^ mask[i % 4]!;
  return { frame: { fin, opcode, payload }, rest: buf.subarray(at + len) };
}

/** One upgraded connection: text out with `send`, text in through `onMessage`, the close code through `onClose`. */
export class WsConnection {
  private buffer: Buffer = Buffer.alloc(0);
  private messageHandlers: ((text: string) => void)[] = [];
  private closeHandlers: ((code: number) => void)[] = [];
  private closed = false;

  constructor(private readonly socket: Duplex, head: Buffer) {
    socket.on("data", (chunk: Buffer) => this.feed(chunk));
    socket.on("close", () => this.finish(1006));
    socket.on("error", () => this.finish(1006));
    if (head.length > 0) this.feed(head);
  }

  onMessage(fn: (text: string) => void): void { this.messageHandlers.push(fn); }
  onClose(fn: (code: number) => void): void { this.closeHandlers.push(fn); }

  send(text: string): void { if (!this.closed) this.socket.write(encodeFrame(text)); }

  /** Close with a code (1000 by default): a close frame, then the socket. */
  close(code = 1000): void {
    if (this.closed) return;
    const payload = Buffer.alloc(2);
    payload.writeUInt16BE(code);
    try { this.socket.write(encodeFrame(payload, CLOSE)); } catch { /* the socket is already gone */ }
    this.socket.end();
    this.finish(code);
  }

  private finish(code: number): void {
    if (this.closed) return;
    this.closed = true;
    for (const fn of this.closeHandlers) fn(code);
  }

  private feed(chunk: Buffer): void {
    this.buffer = Buffer.concat([this.buffer, chunk]);
    for (;;) {
      let got: ReturnType<typeof decodeFrame>;
      try { got = decodeFrame(this.buffer); } catch { this.close(1009); return; }
      if (got === undefined) return;
      this.buffer = got.rest;
      const { frame } = got;
      if (!frame.fin || frame.opcode === 0x0 || frame.opcode === 0x2) { this.close(1003); return; }
      if (frame.opcode === PING) { if (!this.closed) this.socket.write(encodeFrame(frame.payload, PONG)); continue; }
      if (frame.opcode === PONG) continue;
      if (frame.opcode === CLOSE) { this.close(frame.payload.length >= 2 ? frame.payload.readUInt16BE(0) : 1000); return; }
      if (frame.opcode === TEXT) { const text = frame.payload.toString("utf8"); for (const fn of this.messageHandlers) fn(text); continue; }
      this.close(1003);
      return;
    }
  }
}

/** Accept an upgrade request as a WebSocket, or answer 400 and give nothing back. */
export function upgrade(req: IncomingMessage, socket: Duplex, head: Buffer): WsConnection | undefined {
  const key = req.headers["sec-websocket-key"];
  const version = req.headers["sec-websocket-version"];
  if (typeof key !== "string" || version !== "13" || !/websocket/i.test(String(req.headers["upgrade"] ?? ""))) {
    socket.write("HTTP/1.1 400 Bad Request\r\nConnection: close\r\n\r\n");
    socket.destroy();
    return undefined;
  }
  socket.write(`HTTP/1.1 101 Switching Protocols\r\nUpgrade: websocket\r\nConnection: Upgrade\r\nSec-WebSocket-Accept: ${acceptKey(key)}\r\n\r\n`);
  return new WsConnection(socket, head);
}
```

```ts
// `node:http` around the relay (transport §2.5): JSON requests routed by
// api.ts, a body of at most a megabyte, the token from the Authorization
// header or the query, and `GET /subscribe` upgraded to a WebSocket whose
// client names the documents it follows — each pushed as its blocks land,
// visible or a stub by the same rule as a read.
import { createServer, type IncomingMessage, type ServerResponse } from "node:http";
import type { AddressInfo } from "node:net";
import { canRead } from "./access.js";
import { JSON_TYPE, route, type ApiRequest } from "./api.js";
import { Relay, type RelayOptions } from "./relay.js";
import { upgrade, type WsConnection } from "./ws.js";

export interface RelayServer { port: number; url: string; relay: Relay; close(): Promise<void> }

/** A request body may be this long: a message, a card, never a package's bytes (§2.1). */
export const BODY_LIMIT = 1_048_576;

/** The body, or undefined when it ran over the limit (read to its end all the same, so the answer reaches the client). */
function readBody(req: IncomingMessage): Promise<string | undefined> {
  return new Promise((done, failed) => {
    const chunks: Buffer[] = [];
    let size = 0;
    req.on("data", (c: Buffer) => { size += c.length; if (size <= BODY_LIMIT) chunks.push(c); });
    req.on("end", () => done(size > BODY_LIMIT ? undefined : Buffer.concat(chunks).toString("utf8")));
    req.on("error", failed);
  });
}

function tokenOf(req: IncomingMessage, url: URL): string | undefined {
  const auth = req.headers["authorization"];
  const m = typeof auth === "string" ? /^Bearer\s+(\S+)$/i.exec(auth) : null;
  return m?.[1] ?? url.searchParams.get("token") ?? undefined;
}

function reply(res: ServerResponse, status: number, body: string, type: string): void {
  res.writeHead(status, { "content-type": type, "content-length": Buffer.byteLength(body) });
  res.end(body);
}

export function startRelay(o: RelayOptions & { port?: number; host?: string }): Promise<RelayServer> {
  const relay = new Relay(o);
  const host = o.host ?? "127.0.0.1";
  const subscribers = new Map<WsConnection, { speaker: string; docs: Set<string> }>();
  const off = relay.onAppend(({ owner, doc, block }) => {
    const key = `${owner}/${doc}`;
    const w = relay.world();
    for (const [conn, s] of subscribers) {
      if (!s.docs.has(key)) continue;
      const visible = canRead({ relay: relay.name, owner, doc, block: block.id, viewer: s.speaker }, w) ? { id: block.id, value: block.value } : { id: block.id, stub: relay.stubOf(owner, block) };
      conn.send(JSON.stringify({ doc: key, block: visible }));
    }
  });

  const server = createServer((req, res) => {
    void (async () => {
      try {
        const url = new URL(req.url ?? "/", "http://relay");
        const text = await readBody(req);
        if (text === undefined) { reply(res, 413, JSON.stringify({ error: "正文超过 1 MB" }), JSON_TYPE); return; }
        let body: unknown;
        if (text !== "") {
          try { body = JSON.parse(text); } catch { reply(res, 400, JSON.stringify({ error: "正文不是 JSON" }), JSON_TYPE); return; }
        }
        const token = tokenOf(req, url);
        const r: ApiRequest = { method: req.method ?? "GET", path: url.pathname, query: Object.fromEntries(url.searchParams), ...(token !== undefined ? { token } : {}), ...(body !== undefined ? { body } : {}), ...(/text\/plain/.test(String(req.headers["accept"] ?? "")) ? { geml: true } : {}) };
        const out = route(r, relay);
        reply(res, out.status, out.body, out.type);
      } catch (e) {
        reply(res, 500, JSON.stringify({ error: e instanceof Error ? e.message : String(e) }), JSON_TYPE);
      }
    })();
  });

  server.on("upgrade", (req, socket, head) => {
    const url = new URL(req.url ?? "/", "http://relay");
    if (url.pathname !== "/subscribe") { socket.write("HTTP/1.1 404 Not Found\r\nConnection: close\r\n\r\n"); socket.destroy(); return; }
    const token = tokenOf(req, url);
    const by = token === undefined ? undefined : relay.verify(token);
    if (by === undefined) { socket.write("HTTP/1.1 401 Unauthorized\r\nConnection: close\r\n\r\n"); socket.destroy(); return; }
    const conn = upgrade(req, socket, head);
    if (conn === undefined) return;
    const sub = { speaker: by.speaker, docs: new Set<string>() };
    subscribers.set(conn, sub);
    conn.onMessage((text) => {
      let msg: unknown;
      try { msg = JSON.parse(text); } catch { conn.send(JSON.stringify({ error: "JSON 不合法" })); return; }
      const m = typeof msg === "object" && msg !== null ? (msg as Record<string, unknown>) : {};
      if (typeof m["subscribe"] === "string") {
        const key = m["subscribe"];
        const slash = key.indexOf("/");
        const owner = slash === -1 ? "" : key.slice(0, slash), doc = slash === -1 ? "" : key.slice(slash + 1);
        if (owner !== "" && doc !== "" && relay.mayFollow(owner, doc, by.speaker)) { sub.docs.add(key); conn.send(JSON.stringify({ subscribed: key })); }
        else conn.send(JSON.stringify({ error: "无权或没有这份文档" }));
      } else if (m["ping"] !== undefined) conn.send(JSON.stringify({ pong: m["ping"] }));
      else conn.send(JSON.stringify({ error: "不认识这条消息" }));
    });
    conn.onClose(() => { subscribers.delete(conn); });
  });

  return new Promise((done, failed) => {
    server.once("error", failed);
    server.listen(o.port ?? 0, host, () => {
      const port = (server.address() as AddressInfo).port;
      done({
        port, url: `http://${host}:${port}`, relay,
        close: () => new Promise((closed) => {
          off();
          for (const c of subscribers.keys()) c.close();
          server.closeAllConnections();
          server.close(() => closed());
        }),
      });
    });
  });
}
```
