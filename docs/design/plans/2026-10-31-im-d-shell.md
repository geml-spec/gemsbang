# IM D — The Claude Code Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Claude Code plugin becomes an agent's body (transport §4, main §12): a 「消息」 page first on the board with its unread count, the venue list, a thread with the four kinds of speaker, drafts the owner sends, and a box that speaks as the person; the band's 「需要我」 row before everything else; five `im_*` tools the model speaks through; a queue item delivered between turns with its envelope, the tool scope of its level laid over every call of that turn, and the final answer sent back (or held as a draft); the session's presence reported with every change.

**Architecture:** Nothing here reaches the relay: the hooks module (no Node) asks the bundled CLI through the bridge, and the bridge reads and writes the daemon's home (plan C's `deliver.ts`, and a new `view.ts` that folds the mirrors into what the page shows). Everything the page and the band draw is computed by a pure module, `src/hosts/claude-code/im.ts`, from the bridge's answers, tested with `node:test`; the hooks module only lays rows out with the kinds it already draws (`heading`, `section`, `card`, `entry`, `note`, `text`, `buttons`, `input`) and runs the presses. A turn that a queue item started is marked in the plugin's state (`imTurn`): the generic `tool.call` hook refuses what the item's scope does not allow, and `turn.complete` sends the answer back and asks for the next item. The daemon's outbox gains two kinds (`grant`, `refuse`) so a 放行 pressed on the band reaches the relay.

**Tech Stack:** TypeScript 5, Node ≥ 22, `node:test` over `dist/` for everything pure and for the bridge; `claude plugin test` (`tests/hooks.test.ts`, the scripted bridge) for the hooks module. The board's pane cannot be drawn under this machine's older CLI (the known 23 failures), so the new hooks tests drive the tools, the delivery turn and the band, never the pane; the page's rows are tested as data in `node:test`.

**Spec:** transport §4 (the mapping: prompt.submit, tool.call, the turn's end, the band, the board's 消息 page, the six tools — `im_card` comes with plan F), §4.1 (each call one line in the session), §5 (Claude Code: prompts between turns, auto reply, the envelope over the fast path), §3 (投递, 会话登记); main §5 rules 3, 5, 6, 8, 9, §6.2 (the venue list's rows), §6.5 (回群前先给我看, the sender's status line), §6.9 (the band's row, mutes later), §6.10 (presence), §7.2 (the scope matrix), §12's table.

## Decisions this plan makes

1. **Which agent a session is.** `connect.json` lists the person's agents; the session is the one the setting `im.agent` names, else the first. The settings dialog gets a row of the agents to pick from. A session with no agent has the page and the band but delivers nothing and speaks only as the person.
2. **Delivery between turns** (§6.5, rule 8). When the main loop is idle — after the status is read at the start, after every `turn.complete` of the main loop, and on the minute's refresh — the module asks the bridge for the next item (`im-next` with `take`, which also marks it read in: the host is about to submit it). It keeps the item, its scope and its 回群前先给我看 as `imTurn` and submits the delivered text with `$.prompt.submit` (not `asUser`: the envelope says who speaks, and the transcript names the plugin). At that turn's end the final answer goes back through `im-answer` as the agent — a draft when the venue wants the owner to see it first — and `imTurn` clears. An aborted turn clears it too, with nothing sent (the item stays read in; the relay still lists it).
3. **The scope over the fast path** (§7.2, rule 5). While `imTurn` is set, every `tool.call` is classed (write, run, else read) and judged by plan A's `decide`; a refusal is a deny with one Chinese line naming the sender, their level, the scope, and that nothing ran — and that more needs the owner's 放行. `sandbox` is refused too, saying this version has no guest room yet (plan F). The deny counts on `imTurn.refused`; the band's 卡住 for a turn refused repeatedly comes with the phone bridge's plan.
4. **Presence** (§6.10, transport §3). `thinking` on a prompt, `tool` on the first tool call of a turn, `waiting` when the reply asked a question, `idle` at a turn's end, `asleep` at the session's end — each reported once, when it changes, through `im-presence`; the daemon posts them with its heartbeat. The login kind is `api` when `ANTHROPIC_API_KEY` is set, else `subscription`.
5. **The 消息 page** (§6.2, transport §4): first among the tabs, its label carrying the unread count; the board still opens on the work items. Its rows: the connection line (who, which relay, 在线 or 断了, a refresh); 需要我 as cards with their buttons; drafts waiting (就这么发 / 改一下 as a field / 不发); the venues as two-line entries (kind and name; the status line and the unread) that open a thread; in a thread the announce, then the last fifty messages as `note` rows (the text; under it the speaker as rule 6 draws them — an agent with 代 its owner, 起草 and 本人原话 tagged — the time, the kind when not chat, 决策 when marked, and the sender's status line for the person's own calls to their agents), parts and evidence as dim lines under the message (text, 你看不到, or 没镜像到本机), an ask's options as buttons that answer it, and the box at the end that speaks as the person. The board header gains one line: the agent, 代 whom, its presence, 在线 or 断了 (the day's spend is not reported by this host yet).
6. **The band** (§6.9). When the inbox holds anything, its first item leads the band — the verb in its colour (放行 and 定 amber, 验收 green, 卡住 and 断了 red), the sentence, its buttons, 还有 N 件 — before the workflow's own items and the reply's asks. 断了 is also raised locally when the daemon's state file says the relay is gone. Nothing of the IM shows when the inbox is empty: the band keeps its other lines.
7. **The five tools** (§4.1): `im_say` (a chat into a venue), `im_ask` (an ask: question, options, who, expiry), `im_report` (a report with evidence embeds and an opinion), `im_read` (a venue's recent messages, or one embed, from the mirror), `im_forward` (a message or block into another venue as an embed, with a note). Each is one bridge call and answers one line: `im_read · 群「前端周会」· 最近 12 条`. They sign as the session's agent; a session with no agent is told so. `im_card` is plan F's.
8. **Unread** is per venue, the last message id the page showed, kept in the plugin's state (`imSeen`): opening a thread marks it seen; the count is messages after it, system messages left out.
9. **The bridge's ops**: `im-status` (the page's and the band's data, from the mirrors, with `seen` for the counts), `im-venue` (one thread), `im-say`, `im-next`, `im-answer`, `im-draft`, `im-presence`, `im-need` (a need's button: an ask answered as a reply, a 放行 as a grant or a refusal through the outbox, 重试 nothing — the daemon tries by itself), `im-read`, `im-forward`. The home is `GEMWORKS_IM_HOME` or `~/.gemworks/im`, as the daemon's.

// connection, the inbox, the venues with their unread, the drafts waiting,

/** Every venue mirrored under the relay, across owners. */
function mirroredVenues(home: string, c: Config): { owner: string; vd: VenueDoc }[] {
  const relayDir = join(home, c.relay.name.replace(/:/g, "_"));
  if (!existsSync(relayDir)) return [];
  const out: { owner: string; vd: VenueDoc }[] = [];
  for (const owner of readdirSync(relayDir, { withFileTypes: true }).filter((e) => e.isDirectory()).map((e) => e.name).sort()) {
    const dir = join(relayDir, owner, "venues");
    if (!existsSync(dir)) continue;
    for (const n of readdirSync(dir).filter((f) => f.endsWith(".geml")).sort()) {
      const id = n.slice(0, -".geml".length);

      const vd = foldVenue(owner, id, { blocks: m.blocks, diagnostics: [], text: m.text, exists: true }, c.relay.name);
      if (vd !== undefined) out.push({ owner, vd });

  }

}

/** The page's and the band's data. `seen`: per venue (`owner/id`), the last message id the page showed; the unread are those after it. */
export function statusView(home: string, seen: Readonly<Record<string, string>> = {}, now: string = new Date().toISOString()): ImStatus {
  const c = readConfig(home);
  if (c === undefined) return { ...EMPTY, needs: [], venues: [], drafts: [], presence: {}, agents: [] };
  const state = readState(home);
  const needs: Need[] = [...readInbox(home, c.relay.name, c.person)];
  if (state !== undefined && !state.connected) needs.push({ kind: "offline", key: "offline:relay", text: `连不上中继 ${c.relay.name}${state.error === undefined ? "" : `：${state.error}`}`, actions: defaultActions("offline", {}), since: state.at, level: 0 });
  const venues: (VenueRow & { at: string })[] = [];
  for (const { owner, vd } of mirroredVenues(home, c)) {
    const shown = vd.messages.filter((m) => m.kind !== "system");
    const mark = seen[`${owner}/${vd.venue.id}`];
    const at = mark === undefined ? -1 : shown.findIndex((m) => m.id === mark);
    const unread = at === -1 ? shown.length : shown.length - (at + 1);
    const row = listRow(vd.venue, { unread });
    const newest = shown[shown.length - 1];
    const r: VenueRow & { at: string } = { owner, id: vd.venue.id, kind: vd.venue.kind, kindWord: row.kind, name: vd.venue.name, status: row.status, unread, at: newest?.at ?? "" };
    if (newest !== undefined) r.last = newest.id;
    venues.push(r);
  }
  venues.sort((a, b) => (a.at < b.at ? 1 : a.at > b.at ? -1 : a.name < b.name ? -1 : 1));
  const presence: Record<string, Presence> = {};
  for (const name of Object.keys(c.agents)) presence[name] = presenceOf(home, name);
  const drafts: DraftRow[] = listDrafts(home).map((d) => ({ id: d.id, agent: d.agent, venueName: d.venueName, text: typeof d.body["text"] === "string" ? d.body["text"] : "", at: d.at }));
  const out: ImStatus = { configured: true, person: c.person, relay: c.relay.name, agents: Object.keys(c.agents), needs: sortNeeds(needs), venues: venues.map(({ at: _at, ...v }) => v), drafts, presence };
  if (state !== undefined) { out.connected = state.connected; out.at = state.at; if (state.error !== undefined) out.error = state.error; }
  void now;
  return out;
}

/** One venue as the page shows it: the last `limit` messages, each speaker drawn as rule 6 says. */
export function threadView(home: string, owner: string, id: string, limit = 50, now?: string): Thread | undefined {
  const c = readConfig(home);
  if (c === undefined) return undefined;
  const m = readMirror(home, c.relay.name, owner, `venues/${id}.geml`);
  if (!m.exists) return undefined;
  const vd = foldVenue(owner, id, { blocks: m.blocks, diagnostics: [], text: m.text, exists: true }, c.relay.name);
  if (vd === undefined) return undefined;
  const access = localAccess(home, c);
  const part = (e: Embed): Part => {
    const r = resolveEmbed(e, `person:${c.person}`, access);
    const p: Part = { src: e.src };
    if (r.text !== undefined) p.text = r.text;
    else if (r.stub !== undefined) p.stub = `你看不到：来自 ${r.stub.from} 的私有范围 · ${r.stub.action}`;
    return p;
  };
  const queues = new Map<string, Queue>();
  for (const a of Object.keys(c.agents)) queues.set(a, readQueue(readMirror(home, c.relay.name, c.person, `queues/${a}.geml`).text).queue);
  const me = `person:${c.person}`;
  const messages: ThreadMessage[] = vd.messages.slice(-limit).map((msg) => {
    const s = parseSpeaker(msg.speaker);
    const t: ThreadMessage = {
      id: msg.id, speaker: msg.speaker, label: s?.kind === "agent" ? agentLabel(s.name, s.owner) : shownName(msg.speaker), kind: msg.kind, kindWord: KIND_WORDS[msg.kind],
      text: msg.text, at: msg.at, source: msg.source, parts: msg.parts.map(part), evidence: msg.evidence.map(part), decision: vd.venue.decisions.includes(`${vd.venue.address}#${msg.id}`),
    };
    if (msg.source === "drafted") t.sourceTag = "起草";
    if (msg.source === "quoted") t.sourceTag = QUOTED_TAG;
    if (msg.replyTo !== undefined) t.replyTo = msg.replyTo;
    if (msg.ask !== undefined) t.ask = msg.ask;
    if (msg.opinion !== undefined) t.opinion = msg.opinion;
    if (msg.speaker === me && now !== undefined) {
      for (const [a, q] of queues) {
        const line = senderStatus(q, `qi-${id}-${msg.id}`, now, { alive: isAlive(presenceOf(home, a)), doing: presenceWord(presenceOf(home, a)) });
        if (line !== undefined) { t.status = `${a}：${line}`; break; }
      }
    }
    return t;
  });
  const th: Thread = { owner, id, kind: vd.venue.kind, kindWord: VENUE_WORDS[vd.venue.kind], name: vd.venue.name, people: vd.venue.people, agents: vd.venue.agents, draftFirst: vd.venue.policy.draftFirst, messages, total: vd.messages.length };
  if (vd.venue.announce !== undefined) th.announce = vd.venue.announce.text;
  return th;
}

const PRESENCE_WORDS: Readonly<Record<Presence, string>> = { thinking: "思考", tool: "跑工具", waiting: "等主人", idle: "空闲", asleep: "睡着" };
const presenceWord = (p: Presence): string | undefined => (p === "asleep" ? undefined : PRESENCE_WORDS[p]);

const lineOf = (m: ThreadMessage): string => `[${m.at.slice(11, 16)}] ${m.label}（${m.kindWord}）：${m.text.split("\n").join(" ")}`;
const partLine = (p: Part): string => `  ↳ ${p.src}：${p.text !== undefined ? p.text.split("\n").join(" ") : p.stub !== undefined ? p.stub : "没镜像到本机"}`;

/** What `im_read` answers (rule 3's read tool): a venue's last lines, or one block by its address. */
export function readForTool(home: string, o: { owner?: string; venue?: string; src?: string; limit?: number }): string {
  if (o.src !== undefined) {
    const c = readConfig(home);
    if (c === undefined) return "没有 connect.json：先 gemworks connect setup";
    if (parseAddress(o.src) === undefined) return `不是地址：${o.src}`;
    const r = resolveEmbed({ src: o.src }, `person:${c.person}`, localAccess(home, c));
    if (r.text !== undefined) return r.text;
    if (r.stub !== undefined) return `你看不到：来自 ${r.stub.from} 的私有范围 · ${r.stub.action}`;
    return `没镜像到本机：${o.src}（让主人在看板上看，或等守护进程同步）`;
  }
  if (o.owner === undefined || o.venue === undefined) return "要一个场所（owner/id），或一个块的地址（src）";
  const th = threadView(home, o.owner, o.venue, o.limit ?? 12);
  if (th === undefined) return `没有这个场所的镜像：${o.owner}/${o.venue}`;
  const lines = [`${th.kindWord}「${th.name}」· 最近 ${th.messages.length} 条（共 ${th.total} 条）`];
  for (const m of th.messages) { lines.push(lineOf(m)); for (const p of [...m.evidence, ...m.parts]) lines.push(partLine(p)); }
  return lines.join("\n");
}

export interface ImBandRow { verb: string; tone: Tone; text: string; actions: Pressable[]; more: number }

/** The band's row (§6.9): the first need in the band's order, its buttons as presses (自己写 included: the hooks module opens the thread with the box answering the ask), how many more wait; nothing when none. */
export function imBand(status: ImStatus | null): ImBandRow | undefined {
  if (status === null || !status.configured) return undefined;
  const row = bandRow(status.needs);
  const need = sortNeeds(status.needs)[0];
  if (row === undefined || need === undefined) return undefined;
  const tone: Tone = row.tone === "red" ? "error" : row.tone === "amber" ? "warning" : "success";
  return { verb: row.verb, tone, text: row.text, more: row.more, actions: row.actions.map((label, i) => needPress(need, label, i, `im-need-${i}`)) };
}

}

    }
  }

function threadRows(th: Thread, replyTo: string | null, columns: number, t: T): BoardRow[] {
  const rows: BoardRow[] = [{ kind: "heading", key: "im-thread", text: `${th.kindWord}「${th.name}」`, sub: `${th.people.length} 人 · ${th.agents.length} 个 agent${th.draftFirst ? ` · ${t("回群前先给我看")}` : ""}`, action: { key: "im-back", label: t("返回"), action: { op: "im-close" } } }];
  if (th.announce !== undefined) rows.push(text(truncate(`${t("公告")}：${th.announce}`, columns)));
  if (th.total > th.messages.length) rows.push(text(t("还有 {0} 条更早的", th.total - th.messages.length)));
  for (const m of th.messages) {
    const tags = [m.label, hhmm(m.at)];
    if (m.sourceTag !== undefined) tags.push(m.sourceTag);
    if (m.kind !== "chat") tags.push(m.kindWord);
    if (m.decision) tags.push(t("决策"));
    if (m.status !== undefined) tags.push(m.status);
    const body = m.kind === "system" ? `（${m.text}）` : m.text;
    rows.push({ kind: "note", key: `im-m-${m.id}`, lines: wrapCells(body, Math.max(10, columns - 4), 6), tag: tags.join(" · "), action: { op: "im-reply", message: replyTo === m.id ? null : m.id } });
    for (const p of [...m.evidence, ...m.parts]) rows.push(text(truncate(`  ↳ ${p.src}：${p.text !== undefined ? p.text.split("\n")[0] ?? "" : p.stub !== undefined ? p.stub : t("没镜像到本机")}`, columns)));
    if (m.opinion !== undefined) rows.push(text(truncate(`  ${t("意见")}：${m.opinion}`, columns)));
    if (m.kind === "ask" && m.ask !== undefined) rows.push({ kind: "buttons", items: m.ask.options.map((opt, i): Pressable => ({ key: `im-ask-${m.id}-${i}`, label: opt, action: opt === WRITE_IN ? { op: "im-reply", message: m.id } : { op: "im-say", text: opt, replyTo: m.id } })) });
  }
  rows.push({ kind: "input", key: "im-say", placeholder: replyTo !== null ? t("回复 {0}…", replyTo) : t("以本人身份发到这里"), field: "im-say", target: venueKey(th.owner, th.id) });
  return rows;
}

/** The IM for an answer that carries it (status, refresh, attention): nothing when the daemon's home is not set up. */
function imOf(req: BridgeRequest): { im?: ImStatus } {

/** The agent an IM request signs as: the one named, else the first the home lists. */
function imAgentOf(home: string, named: string | undefined): string | undefined {
  const agents = Object.keys(readConfig(home)?.agents ?? {});
  return named !== undefined && named !== "" ? named : agents[0];

/** A need's button (§6.9) acted on: an ask answered as a reply, a request granted or refused, 重试 left to the daemon. */
function answerNeed(home: string, key: string, action: string, text: string | undefined, now: string): { ok: true } | { ok: false; reason: string } {
  if (key.startsWith("offline:")) return { ok: true };
  const a = parseAddress(key);
  const c = readConfig(home);
  if (a === undefined || a.block === undefined || c === undefined) return { ok: false, reason: `不认识这件事：${key}` };
  const venue = /^venues\/([^/]+)\.geml$/.exec(a.doc);
  if (venue !== null) {
    const reply = action === "自己写" ? text?.trim() ?? "" : action;
    if (reply === "") return { ok: false, reason: "自己写：缺正文" };
    say(home, { as: "person", owner: a.owner, venue: venue[1]!, text: reply, replyTo: a.block }, now);
    return { ok: true };
  }
  if (/^people\/[^/]+\.geml$/.test(a.doc)) {
    const request = readMirror(home, c.relay.name, a.owner, a.doc).blocks.find((b) => b.id === a.block);
    const from = typeof request?.value["from"] === "string" ? request.value["from"] : undefined, block = typeof request?.value["block"] === "string" ? request.value["block"] : undefined;
    const person = from?.replace(/^person:/, "").replace(/^agent:[^@]+@/, "");
    if (person === undefined || block === undefined) return { ok: false, reason: `没镜像到这个申请：${key}` };
    const which = action === "允许一次" ? "allow-once" : action === "允许此人" ? "allow-person" : action === "拒绝" ? "refuse" : undefined;
    if (which === undefined) return { ok: false, reason: `放行没有这个答复：${action}` };
    answerGrant(home, { request: a.block, person, block, action: which }, now);
    return { ok: true };
  }
  return { ok: false, reason: `不认识这件事：${key}` };
}

function answerIm(req: BridgeRequest & ImOp): BridgeResponse {

  const no = (reason: string): BridgeResponse => ({ v: 1, ok: false, error: `gemworks: ${reason}`, shell: shell() });
  try {
    switch (req.op) {
      case "im-status": return yes(imOf(req));
      case "im-venue": {
        const thread = threadView(home, req.owner, req.id, req.limit ?? 50, now);
        return thread === undefined ? no(`没有这个场所的镜像：${req.owner}/${req.id}`) : yes({ thread });
      }
      case "im-say": {
        const as = req.as === undefined || req.as === "person" ? "person" : `agent:${req.as.replace(/^agent:/, "")}`;
        const e = say(home, { as, owner: req.owner, venue: req.venue, text: req.text, ...(req.kind !== undefined ? { kind: req.kind } : {}), ...(req.ask !== undefined ? { ask: req.ask } : {}), ...(req.evidence !== undefined ? { evidence: req.evidence } : {}), ...(req.parts !== undefined ? { parts: req.parts } : {}), ...(req.opinion !== undefined ? { opinion: req.opinion } : {}), ...(req.turn !== undefined ? { turn: req.turn } : {}), ...(req.replyTo !== undefined ? { replyTo: req.replyTo } : {}), ...(req.session !== undefined ? { session: req.session } : {}) }, now);
        return yes({ text: `排入待发 ${e.id}` });
      }
      case "im-next": {
        const d = nextPrompt(home, req.agent, now);
        if (d === undefined) return yes();
        if (req.take === true) markRead(home, req.agent, d.item, now);
        return yes({ delivered: d });
      }
      case "im-answer": {
        const answered = imAnswer(home, req.agent, req.item, req.text, now, { ...(req.kind !== undefined ? { kind: req.kind } : {}), ...(req.evidence !== undefined ? { evidence: req.evidence } : {}), ...(req.session !== undefined ? { session: req.session } : {}) });
        return yes({ answered });
      }
      case "im-draft": {
        if (!req.send) return dropDraft(home, req.id, now) ? yes() : no(`没有这份草稿：${req.id}`);

async function keepIm($: EngineInterface, res: BridgeResponse | undefined): Promise<void> {
  if (res === undefined || !res.ok || res.im === undefined) return

/** Which agent this session is (decision 1): the setting, else the first the daemon lists; none when it lists none. */
async function imAgentOf($: EngineInterface): Promise<string | undefined> {
  const im = await readIm($)
  if (im === null || !im.configured) return undefined
  const chosen = (await readSettings($)).im.agent
  return chosen !== '' && im.agents.includes(chosen) ? chosen : im.agents[0]
}

async function serveIm($: EngineInterface, name: ImToolName, event: unknown): Promise<ToolCallResult> {
  const args = toolArgs(event as Record<string, unknown>)
  const t = await words($)
  const agent = await imAgentOf($)
  if (agent === undefined) return { result: `${name}: ${t('本会话没有 agent：在设置里选一个')}` }
  const session = await $.session.id().catch(() => '')
  const venueOf = (v: unknown): { owner: string; id: string } | undefined => { const m = typeof v === 'string' ? /^([^/#\s]+)\/([^/#\s]+)$/.exec(v) : null; return m === null ? undefined : { owner: m[1] as string, id: m[2] as string } }

  const str = (k: string): string | undefined => (typeof args[k] === 'string' ? args[k] as string : undefined)
  const embeds = (k: string): { src: string; rev?: number; hash?: string }[] | undefined => (Array.isArray(args[k]) ?   const through = async (op: BridgeOp): Promise<{ ok: true; res: Extract<BridgeResponse, { ok: true }> } | { ok: false; text: string }> => {
    const res = await bridge($, op)
    if (res === undefined) return { ok: false, text: `${name}: gemworks is unavailable: ${(await read($, problemAtom)) ?? ''}` }
    if (!res.ok) return { ok: false, text: `${name}: ${res.error.replace(/^gemworks: /, '')}` }
    return { ok: true, res }
  }
  if (name === 'im_read') {
    const v = venueOf(args['venue'])
    const src = str('src')
    const limit = typeof args['limit'] === 'number' ? args['limit'] as number : undefined
    const r = await through({ op: 'im-read', ...(v !== undefined ? { owner: v.owner, venue: v.id } : {}), ...(src !== undefined ? { src } : {}), ...(limit !== undefined ? { limit } : {}) })
    if (!r.ok) return { result: r.text }
    const where = v !== undefined ? await labelOf(v) : src ?? t('场所')
    return { result: `${toolLine(name, where, v !== undefined ? `最近 ${limit ?? 12} 条` : src !== undefined ? '读了一块' : '列出场所')}\n${r.res.text ?? ''}` }
  }
  if (name === 'im_forward') {
    const to = venueOf(args['to'])
    const from = str('from')
    if (to === undefined || from === undefined) return { result: `${name}: from is an address or owner/venue#message, to is owner/id` }
    const note = str('note')
    const r = await through({ op: 'im-forward', from, to: `${to.owner}/${to.id}`, ...(note !== undefined ? { note } : {}), as: agent, ...(session !== '' ? { session } : {}) })
    return { result: r.ok ? toolLine(name, await labelOf(to), `已排入待发：${from}`) : r.text }
  }
  const v = venueOf(args['venue'])
  if (v === undefined) return { result: `${name}: venue is owner/id (im_read lists them)` }
  const kind = name === 'im_ask' ? 'ask' : name === 'im_report' ? 'report' : 'chat'
  const text = name === 'im_ask' ? str('question') ?? '' : str('text') ?? ''
  const ask = name === 'im_ask' ? { question: str('question') ?? '', options: Array.isArray(args['options']) ? (args['options'] as unknown[]).filter((x): x is string => typeof x === 'string') : [], who: str('who') ?? '', ...(str('expires') !== undefined ? { expires: str('expires') as string } : {}) } : undefined
  const evidence = embeds('evidence'), parts = embeds('parts'), opinion = str('opinion'), turn = str('turn'), replyTo = str('replyTo')
  const r = await through({ op: 'im-say', owner: v.owner, venue: v.id, text, as: agent, kind, ...(ask !== undefined ? { ask } : {}), ...(evidence !== undefined ? { evidence } : {}), ...(parts !== undefined ? { parts } : {}), ...(opinion !== undefined ? { opinion } : {}), ...(turn !== undefined ? { turn } : {}), ...(replyTo !== undefined ? { replyTo } : {}), ...(session !== '' ? { session } : {}) })
  if (!r.ok) return { result: r.text }
  const what = name === 'im_ask' ? `问 ${ask?.who ?? ''}：${text}` : name === 'im_report' ? `汇报${(evidence ?? []).length > 0 ? `，带证据 ${(evidence ?? []).length} 条` : ''}` : '已排入待发'
  return { result: toolLine(name, await labelOf(v), what) }
}
