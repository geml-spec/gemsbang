# Gemsbang Plan S: 需要你, and the Push Outlet

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Avatars ask their person, and the answer comes back. An avatar brings its person five kinds of thing and nothing else — a promise asked of them (答应事情), money (花钱), taking a side (表态), their computer (借电脑), something gone wrong (出错) — as a card that says which avatar, which kind, from which chat, what it checked, **the words it would send**, and options that are short forms of those words, plus 自己写. A card waits twelve hours unless the asker says sooner; past that the avatar says in the chat 「这件事要本人回，我先不替答」 and the card stays a day marked 已过期. Meanwhile the avatar may say a waiting line in the chat — a template per language, the person's own if they set one — that names nobody and gives away no machine. The person answers in the pane, on the line above the prompt, on the group's web page, or from any push channel; the chosen words go into the chat as the avatar, stamped `by: person`. Errors come first, then the soonest to expire; two cards show whole and more fold behind 还有 N 件; an avatar or a chat can be muted. A newcomer at a group whose owner lets people in by hand becomes the owner's 答应事情. A borrow's card can stop asking for its asker or its chat (plan U uses that). The relay gets its push outlet: an adapter interface, and a file channel to test it.

**Architecture:** A pure module, `src/core/avatar/needs.ts` (the kinds, their default options, an ask's faults, expiry, order, folding, the words an answer sends), and the outlet, `src/relay/push.ts` (`PushAdapter`: `deliver` a card, `collect` the answers; `fileAdapter`, a document out and a document in). `AvatarRelay` gains 需要你: a card lives in the asking avatar's own `needs.geml` (with its answers and expiries), the relay keeps `_relay/needs-open.geml` so its sweep need not walk every avatar, and a person's channels are `push-N` blocks in their own record. The relay's say for its own lines (answers, waiting lines, the expired line) is one method, `sayAs`. The owner's answer to a newcomer, by its card or by its request, is one method, `settleRequest`. The HTTP routes, the server's sweep every thirty seconds, the group's page's cards; the client lists the cards in its mirror, answers, mutes (on this machine), sets the template, and `im_ask` asks as the session's avatar with its own token; the pane leads the inbox with 需要你, shows a chat's cards to the person alone, and the band shows the first card with its options.

**Tech Stack:** TypeScript (`src/core/avatar`, `src/relay`, `src/gemsbang`, `src/hosts/claude-code`), the hooks module in TSX, `node:test` over `dist/`, `claude plugin test` for the module.

**Before this plan:** gemsbang 0.5.3 on `main` (`a3ff165`), plan R (`docs/design/plans/2026-11-01-im-r-panel.md`). The spec is `docs/design/specs/2026-11-01-gemsbang-design.md` (§7.3 is this plan's, with §6.1's approval and §3 rules 20, 25, 27); the transport spec `docs/design/specs/2026-10-30-agent-im-transport-design.md` (§7.2). The screens are the canvas's `GbInbox`, `GbChat`, `GbAsk`.

## What the spec decided, and what this plan does about each

- **Five kinds, no strangers (§3 rule 20, §7.3).** `kind` is `promise`, `pay`, `stance`, `borrow` or `error`; anything else is refused. A borrow's options are 现在干 · 排着 · 不干, an error's 看原因 · 重试, money's 付 · 不付 (in the person's language) unless the asker gives its own; a promise and a stance have the asker's options and 自己写.
- **The words it would send are on the card (§3 rule 25).** `draft` and each option's `text` are the words; an option without words (a borrow's, an error's) sends nothing. An answer sends the chosen words, or the person's own, into the chat as the avatar, `by: person`, replying to the line the card came from. The person behind the avatar is never named.
- **Twelve hours, then the avatar says so (§7.3).** The sweep marks a card expired, the avatar says 「这件事要本人回，我先不替答」 in the chat (`by: agent`), and an answer after that is refused (`need.gone`); the pane keeps the card a day, dim, 已过期, with no options.
- **The waiting line is a template (§3 rule 25).** `placeholder: true` on an ask says it at once, `by: agent`; the words are the person's own template for that avatar (`templates.geml`), else 「我看一下，晚点回。」 in their language.
- **Order, folding, muting (§7.1, §3 rule 27).** Errors first, then the soonest to expire, the expired last; two whole, more behind 还有 N 件; muted cards (by avatar or by chat, kept on this machine) are counted apart as 静音的 N 件 and never reach the line above the prompt.
- **The owner's door (§6.1, §3 rule 28).** With the approval on, a newcomer's request is also a 答应事情 card for the owner avatar — 「乐乐 妈妈」想进「三年二班家长」, 同意 · 不同意 — and answering either the card or the request settles both.
- **A borrow's standing yes (§3 rule 21).** 现在干 may carry 这个人以后不用问 (the avatar whose words asked, `from`) or 这个群以后不用问; `borrowAllowed` says whether the next one may skip the card. Plan U acts on it.
- **The push outlet first, channels later (§7.3, transport §7.2, §12 item 3).** The relay delivers a card to each channel its person turned on (`/me/push`), and takes an answer back from a channel as the person's own press — only for that person's avatar, and only on a channel they turned on. v1's one channel is the file channel; web push, text, Telegram and WeChat are each one more adapter.
- **Everywhere the person is (§7.2, §3 rule 27).** The pane, the band (the first card's options, 还有 N 件), and the group's web page (the cards of that chat, with 自己写) all answer through the same route.
- **Not in this plan:** hosted agents and paying (T), the borrow itself (U), a real push channel.

// 需要你 (spec §7.3): what an avatar brings to its person, and nothing else —
// five kinds: a promise asked of them (答应事情, a newcomer at a group they
// let in by hand among them), money (花钱), taking a side (表态), their
// computer (借电脑), something gone wrong (出错). A card says which avatar,
// which kind, from which chat, what it checked, the words it would send, the
// options — each a short form of those words — and when it stops waiting:
// twelve hours unless the asker says sooner. Errors come first, then the
// soonest to expire; two are shown whole, more fold. Pure.
import { say, type Lang } from "./words.js";

export const NEED_KINDS = ["promise", "pay", "stance", "borrow", "error"] as const;
export type NeedKind = (typeof NEED_KINDS)[number];
export const NEED_TTL_MS = 12 * 3_600_000;
export const NEED_MAX_MS = 7 * 86_400_000;
export const SUMMARY_MAX = 400, OPTION_MAX = 24, DRAFT_MAX = 4000;

/** An option: its short label, and the words it sends when it is the answer (a borrow's or an error's send none). */
export interface NeedOption { label: string; text?: string }
export type NeedState = "open" | "answered" | "expired";
export interface Need {
  id: string; avatar: string; kind: NeedKind; summary: string; options: NeedOption[]; expires: string; at: string; state: NeedState;
  venue?: { owner: string; id: string }; message?: string; checked?: string; draft?: string;
  /** A newcomer waiting at a group of the owner's (spec §6.1): the answer lets them in or not. */
  request?: string;
  /** The avatar whose words started it (a borrow's asker, spec §7.4). */
  from?: string;
  answer?: { choice: number | "own"; text?: string; at: string };
}

export const isKind = (v: unknown): v is NeedKind => typeof v === "string" && (NEED_KINDS as readonly string[]).includes(v);

/** The options a kind has when the asker gives none: a borrow's three, an error's two, money's two. */
export function defaultOptions(kind: NeedKind, lang: Lang): NeedOption[] {
  if (kind === "borrow") return [{ label: say("need.borrow.now", lang) }, { label: say("need.borrow.queue", lang) }, { label: say("need.borrow.no", lang) }];
  if (kind === "error") return [{ label: say("need.error.why", lang) }, { label: say("need.error.retry", lang) }];
  if (kind === "pay") return [{ label: say("need.pay.yes", lang) }, { label: say("need.pay.no", lang) }];
  return [];
}

const obj = (v: unknown): Record<string, unknown> => (typeof v === "object" && v !== null && !Array.isArray(v) ? (v as Record<string, unknown>) : {});

/** What is wrong with an ask, as a code and its parameters; undefined when nothing is. */
export function needFault(body: unknown, now: string): { code: string; params?: Record<string, string | number> } | undefined {
  const o = obj(body);
  if (!isKind(o["kind"])) return { code: "need.kind" };
  const summary = o["summary"];
  if (typeof summary !== "string" || summary.trim() === "" || [...summary].length > SUMMARY_MAX) return { code: "need.summary", params: { max: SUMMARY_MAX } };
  if (o["options"] !== undefined) {
    const opts = o["options"];
    if (!Array.isArray(opts) || opts.length < 1 || opts.length > 4 || !opts.every((x) => typeof obj(x)["label"] === "string" && (obj(x)["label"] as string).trim() !== "" && [...(obj(x)["label"] as string)].length <= OPTION_MAX && (obj(x)["text"] === undefined || typeof obj(x)["text"] === "string"))) return { code: "need.options", params: { max: OPTION_MAX } };
  }
  if (o["draft"] !== undefined && (typeof o["draft"] !== "string" || [...(o["draft"] as string)].length > DRAFT_MAX)) return { code: "need.draft", params: { max: DRAFT_MAX } };
  if (o["expires"] !== undefined) {
    const t = typeof o["expires"] === "string" ? Date.parse(o["expires"] as string) : NaN, n = Date.parse(now);
    if (Number.isNaN(t) || t <= n || t - n > NEED_MAX_MS) return { code: "need.expires" };
  }
  return undefined;
}

/** When a card made at `at` stops waiting: the asker's time, else twelve hours on. */
export const expiryOf = (at: string, given?: string): string => given ?? new Date(Date.parse(at) + NEED_TTL_MS).toISOString().replace(/\.\d{3}Z$/, "Z");

/** Errors first, then the soonest to expire; the expired after the open. */
export function orderNeeds<T extends Pick<Need, "kind" | "expires" | "state">>(needs: readonly T[]): T[] {
  const rank = (n: T): number => (n.state === "expired" ? 2 : n.kind === "error" ? 0 : 1);
  return [...needs].sort((a, b) => rank(a) - rank(b) || (a.expires < b.expires ? -1 : a.expires > b.expires ? 1 : 0));
}

/** Two shown whole; more, the first whole and the rest counted (spec §7.1). */
export function foldNeeds<T>(needs: readonly T[], open = false): { shown: T[]; folded: number } {
  if (open || needs.length <= 2) return { shown: [...needs], folded: 0 };
  return { shown: needs.slice(0, 1), folded: needs.length - 1 };
}

/** How long a card still waits, in words: hours, minutes, or 已过期. */
export function expiresIn(expires: string, now: string, lang: Lang): string {
  const left = Date.parse(expires) - Date.parse(now);
  if (Number.isNaN(left) || left <= 0) return say("need.expired", lang);
  if (left >= 3_600_000) return say("need.hours", lang, { count: Math.floor(left / 3_600_000) });
  return say("need.minutes", lang, { count: Math.max(1, Math.ceil(left / 60_000)) });
}

/** The words an answer sends: the person's own, or the option's; none for an option that sends none. */
export function wordsOf(need: Pick<Need, "options" | "draft">, choice: number | "own", text?: string): string | undefined {
  if (choice === "own") return text !== undefined && text.trim() !== "" ? text : undefined;
  const o = need.options[choice];
  return o?.text;
}

// The push outlet (spec §7.3, transport §7.2): a 需要你 card goes out to every
// channel its person turned on, and an answer comes back from any of them as
// if pressed in the pane. A channel is an adapter that does two things —
// deliver a card, collect the answers — so web push, a text, Telegram or a
// WeChat service account each come later as one more. v1 has the file
// adapter: a card is a block in `_relay/push/out.geml`, and an answer is a
// block someone (a test, a bridge) appends to `_relay/push/in.geml`, read
// once.
import type { Need } from "../core/avatar/needs.js";
import type { Lang } from "../core/avatar/words.js";
import { appendBlock, nextId, readDoc, RELAY_OWNER, sealed } from "./store.js";

/** A card as it goes out: whose, which avatar and chat, in the person's language. */
export interface PushCard { person: string; avatar: string; avatarName: string; group?: string; lang: Lang; need: Need }
/** An answer as it comes back: whose card, and what they chose. */
export interface PushAnswer { person: string; avatar: string; need: string; choice: number | "own"; text?: string }
export interface PushAdapter {
  readonly id: string;
  deliver(card: PushCard): void | Promise<void>;
  /** The answers come in since the last collect, each once. */
  collect(): PushAnswer[] | Promise<PushAnswer[]>;
}

const OUT = "push/out.geml", IN = "push/in.geml";

/** The test channel: cards into a document, answers out of another. */
export function fileAdapter(root: string): PushAdapter {
  return {
    id: "file",
    deliver(card) {
      appendBlock(root, RELAY_OWNER, OUT, nextId("card"), (_d, prev, id) => sealed({ id, person: card.person, avatar: card.avatar, avatarName: card.avatarName, ...(card.group !== undefined ? { group: card.group } : {}), lang: card.lang, need: card.need as unknown as Record<string, never> }, prev));
    },
    collect() {
      const d = readDoc(root, RELAY_OWNER, IN);
      const taken = new Set(d.blocks.filter((b) => /^taken-\d+$/.test(b.id)).map((b) => b.value["answer"]));
      const out: PushAnswer[] = [];
      for (const b of d.blocks) {
        if (!/^answer-\d+$/.test(b.id) || taken.has(b.id)) continue;
        const v = b.value;
        const choice = v["choice"] === "own" ? "own" : typeof v["choice"] === "number" ? v["choice"] : undefined;
        if (typeof v["person"] === "string" && typeof v["avatar"] === "string" && typeof v["need"] === "string" && choice !== undefined) out.push({ person: v["person"], avatar: v["avatar"], need: v["need"], choice, ...(typeof v["text"] === "string" ? { text: v["text"] } : {}) });
        appendBlock(root, RELAY_OWNER, IN, nextId("taken"), (_d, prev, id) => sealed({ id, answer: b.id }, prev));
      }
      return out;
    },
  };
}

/** An answer as a phone would send it through the file channel (tests, and a bridge that has no relay API of its own). */
export function answerByFile(root: string, a: PushAnswer): void {
  appendBlock(root, RELAY_OWNER, IN, nextId("answer"), (_d, prev, id) => sealed({ id, person: a.person, avatar: a.avatar, need: a.need, choice: a.choice, ...(a.text !== undefined ? { text: a.text } : {}) }, prev));
}

/** The cards the file channel has sent, oldest first. */
export const cardsByFile = (root: string): Record<string, unknown>[] => readDoc(root, RELAY_OWNER, OUT).blocks.filter((b) => /^card-\d+$/.test(b.id)).map((b) => b.value);

  private closeOpen(avatar: string, need: string): void {
    appendBlock(this.root, RELAY_OWNER, "needs-open.geml", nextId("closed"), (_d, prev, id) => sealed({ id, avatar, need }, prev));

  /** Whether a borrow may go ahead without asking (spec §7.4): the person said so for the avatar that asked, or for that chat. */
  borrowAllowed(avatar: string, from: string | undefined, venue: { owner: string; id: string } | undefined): boolean {
    const d = readDoc(this.root, avatar, "needs.geml");

      if (n === undefined || n["kind"] !== "borrow") return false;

      if (b.value["allowPerson"] === true && from !== undefined && n["from"] === from) return true;
      return b.value["allowVenue"] === true && venue !== undefined && nv?.["owner"] === venue.owner && nv?.["id"] === venue.id;
    });
  }

  /** The cards past their time, marked expired; in its chat, the avatar says that the person must answer this themself (spec §7.3). The server's minute. */
  sweep(): number {
    const d = readDoc(this.root, RELAY_OWNER, "needs-open.geml");
    const closed = new Set(d.blocks.filter((b) => /^closed-\d+$/.test(b.id)).map((b) => `${str(b.value["avatar"])}/${str(b.value["need"])}`));
    const now = Date.parse(this.now());
    let n = 0;
    for (const b of d.blocks) {
      if (!/^open-\d+$/.test(b.id)) continue;
      const avatar = str(b.value["avatar"]) ?? "", need = str(b.value["need"]) ?? "";
      if (closed.has(`${avatar}/${need}`) || Date.parse(str(b.value["expires"]) ?? "") > now) continue;
      const card = this.needsOfAvatar(avatar).find((x) => x.id === need);
      this.closeOpen(avatar, need);
      if (card === undefined || card.state === "answered") continue;
      const made = appendBlock(this.root, avatar, "needs.geml", nextId("expired"), (_d, prev, id) => sealed({ id, need, at: this.now() }, prev));
      this.emit(avatar, "needs.geml", made.block);
      if (card.venue !== undefined && card.request === undefined) this.sayAs(avatar, card.venue, say("need.expiredLine", this.languageOf(this.ownerOf(avatar) ?? "")), "agent", card.message);
      n++;
    }
    return n;
  }

  /** Answers back from the push channels (spec §7.3), each taken as the person's own press. */
  async collectPush(): Promise<number> {
    let n = 0;
    for (const p of this.push) {
      let answers: Awaited<ReturnType<PushAdapter["collect"]>> = [];
      try { answers = await p.collect(); } catch { continue; }
      for (const a of answers) {
        if (this.ownerOf(a.avatar) !== a.person || !this.pushOf(a.person).includes(p.id)) continue;
        if (this.answerAs(a.avatar, a.need, { choice: a.choice, ...(a.text !== undefined ? { text: a.text } : {}) }).ok) n++;
      }
    }
    return n;
  }

  /** The push channels the person turned on, of those the relay offers. */
  pushOf(person: string): string[] {
    const on = new Set<string>();
    for (const b of readDoc(this.root, RELAY_OWNER, peopleDoc(person)).blocks) {
      if (!/^push-\d+$/.test(b.id)) continue;
      const c = str(b.value["channel"]) ?? "";
      if (b.value["on"] === true) on.add(c); else on.delete(c);
    }
    return [...on].filter((c) => this.push.some((p) => p.id === c));
  }

  /** A channel on or off for the person (spec §7.3, 「有事时提醒我」). */
  setPush(by: TokenRecord, body: unknown): Result<{ channels: string[]; offered: string[] }> {
    const person = this.onlyPerson(by);
    if (typeof person !== "string") return person;
    const o = obj(body) ?? {};
    const channel = str(o["channel"]) ?? "";
    if (!this.push.some((p) => p.id === channel)) return fail(404, "push.unknown", { channel });
    appendBlock(this.root, RELAY_OWNER, peopleDoc(person), nextId("push"), (_d, prev, id) => sealed({ id, channel, on: o["on"] !== false, at: this.now() }, prev));
    return { ok: true, channels: this.pushOf(person), offered: this.push.map((p) => p.id) };
  }

  /** What the avatar says while its person decides (spec §7.3): the person's own template, else the words of their language. */
  placeholderOf(avatar: string): string {
    let text: string | undefined;
    for (const b of readDoc(this.root, avatar, "templates.geml").blocks) if (/^placeholder-\d+$/.test(b.id)) text = str(b.value["text"]);
    return text ?? say("need.placeholder", this.languageOf(this.ownerOf(avatar) ?? ""));
  }

  setPlaceholder(by: TokenRecord, avatar: string, body: unknown): Result<{ text: string }> {

    return { ok: true, text: this.placeholderOf(avatar) };

// one call at a time through the bridge: log the person in by phone, read
// every chat of every avatar again and keep it in the home, open a chat and
// say something in it as the person, make a group, hand out its link, change

// read and say as the avatar this session speaks for, with that avatar's own
// token (so the relay stamps `by: agent`). A relay out of reach leaves the

export interface GbOptions { home: string; now: string; zoneMinutes?: number; fetchImpl?: typeof fetch }
export type Fail = { ok: false; code: string; params?: Record<string, string | number>; reason: string };
/** A 需要你 card as the pane shows it: the avatar's badge, the chat's name, whether the person muted it. */
export type GbNeed = Need & { avatarName: string; group?: string; badge?: Badge; muted: boolean };
/** The pane's whole view: the relay, who is logged in, the avatars, 需要你, the inbox, what is wrong. */
export interface GbView {
  relay: string; trusted: string[]; loggedIn: boolean; lang: Lang; person?: string; defaultName?: string;
  avatars: (Badge & { venues: string[]; mark: boolean; muted: boolean; placeholder?: string })[]; rows: InboxRow[]; unread: number;
  needs: GbNeed[]; muted: { avatars: string[]; venues: string[] };

/** One chat for the pane; `zoneMinutes`, the machine's zone, for the times of its lines. */
export interface GbChat { owner: string; id: string; kind: "group" | "dm"; name: string; count: number; as: Badge | undefined; items: ChatItem[]; earlier: number; isOwner: boolean; rules?: { forward: boolean; approve: boolean }; zoneMinutes?: number }

const obj = (v: unknown): Record<string, unknown> => (typeof v === "object" && v !== null && !Array.isArray(v) ? (v as Record<string, unknown>) : {});
const str = (v: unknown): string | undefined => (typeof v === "string" && v !== "" ? v : undefined);

  private client: Client;
  constructor(private readonly o: GbOptions) {

    return { ok: false, code, ...(params !== undefined ? { params } : {}), reason: say(code, this.lang, params) };
  }

  /** The relay's refusal as it gave it, its words already in the person's language. */
  private refused(a: Answer): Fail {
    const b = obj(a.body);
    const code = str(b["error"]) ?? "server.error";
    const params = obj(b["params"]) as Record<string, string | number>;
    return { ok: false, code, ...(b["params"] !== undefined ? { params } : {}), reason: str(b["reason"]) ?? say(code, this.lang, { detail: `HTTP ${a.status}` }) };
  }

  private http(token?: string): RelayClient { return new RelayClient(this.client.relay, token, this.o.fetchImpl ?? fetch); }

  /** One call to the relay in the person's language; a network failure is `client.unreachable`. */
  private async call(method: string, path: string, body?: unknown, token = this.client.token): Promise<Answer | Fail> {
    if (this.client.relay === "") return this.fail("client.noRelay");
    try {
      return await this.http(token).call(method, `${path}${path.includes("?") ? "&" : "?"}lang=${this.lang}`, body);
    } catch (e) {
      return this.fail("client.unreachable", { detail: e instanceof RelayDown ? e.message.replace(/^连不上中继 [^：]*：/, "") : String(e) });
    }
  }

  private save(): void { writeClient(this.o.home, this.client); }
  private isFail = (x: unknown): x is Fail => (x as Fail).ok === false;

  // --- the view ---

  view(m: Mirror | undefined, offline?: string): GbView {
    const c = this.client;
    const seen = readSeen(this.o.home);
    const box = m === undefined ? { badges: [], rows: [], unread: 0 } : inboxOf(m, seen, this.o.now, { ...(this.o.zoneMinutes !== undefined ? { zoneMinutes: this.o.zoneMinutes } : {}) });
    const marks = m?.marks ?? {};
    const avatars = box.badges.map((b) => ({ ...b, venues: (m?.venues ?? []).filter((v) => v.as === b.id).map((v) => v.name), mark: marks[b.id] ?? true, muted: c.muted.avatars.includes(b.id), ...(m?.placeholders?.[b.id] !== undefined ? { placeholder: m.placeholders[b.id] } : {}) }));
    const needs = orderNeeds(m?.needs ?? []).map((n) => ({ ...n, ...(box.badges.find((b) => b.id === n.avatar) !== undefined ? { badge: box.badges.find((b) => b.id === n.avatar)! } : {}), muted: c.muted.avatars.includes(n.avatar) || (n.venue !== undefined && c.muted.venues.includes(venueKey(n.venue.owner, n.venue.id))) }));
    return {
      relay: c.relay, trusted: [...new Set([...(c.relay !== "" ? [c.relay] : []), ...c.trusted])], loggedIn: c.token !== undefined, lang: this.lang,
      ...(c.person !== undefined ? { person: c.person } : {}), ...(m?.defaultName !== undefined ? { defaultName: m.defaultName } : {}),
      avatars, rows: box.rows, unread: box.unread, needs, muted: c.muted, ...(m !== undefined ? { synced: m.at } : {}), ...(offline !== undefined ? { offline } : {}), notes: c.notes, bodies: c.bodies,
    };
  }

  /** Every chat of every avatar read again and kept; out of reach, the last mirror with why. */
  async sync(): Promise<GbResult> {
    const last = readMirror(this.o.home);
    if (this.client.token === undefined) return { ok: true, view: this.view(undefined) };
    const me = await this.call("GET", "/me");
    if (this.isFail(me)) return me.code === "client.unreachable" ? { ok: true, view: this.view(last, me.reason) } : me;
    if (me.status === 401) { this.logoutLocal(); return { ok: true, view: this.view(undefined) }; }
    if (me.status !== 200) return this.refused(me);
    const meBody = obj(me.body);
    const lang = isLang(meBody["lang"]) ? meBody["lang"] : DEFAULT_LANG;
    if (this.client.lang !== lang) { this.client.lang = lang; this.save(); }
    const list = await this.call("GET", "/venues");
    if (this.isFail(list)) return { ok: true, view: this.view(last, list.reason) };
    if (list.status !== 200) return this.refused(list);
    const venues: MirrorVenue[] = [];
    for (const v of (list.body as Record<string, unknown>[]) ?? []) {
      const owner = str(v["owner"]), id = str(v["id"]), as = str(v["as"]);
      if (owner === undefined || id === undefined || as === undefined) continue;
      const one = await this.call("GET", `/venues/${owner}/${id}?as=${as}`);
      if (this.isFail(one)) return { ok: true, view: this.view(last, one.reason) };
      if (one.status !== 200) continue;
      const b = obj(one.body);
      const blocks = (Array.isArray(b["blocks"]) ? b["blocks"] : []) as MirrorVenue["blocks"];
      const venue = obj(b["venue"]);
      venues.push({ owner, id, kind: v["kind"] === "dm" ? "dm" : "group", name: str(venue["name"]) ?? str(v["name"]) ?? id, members: (Array.isArray(venue["members"]) ? venue["members"] : []) as MirrorVenue["members"], as, ...(b["rules"] !== undefined ? { rules: b["rules"] as MirrorVenue["rules"] } : {}), blocks: blocks.slice(-200) });
    }
    const avatars = (Array.isArray(meBody["avatars"]) ? meBody["avatars"] : []) as Mirror["avatars"];
    const marks: Record<string, boolean> = {};
    for (const a of avatars) {
      const rules = await this.call("GET", `/${a.id}/rules.geml`);
      const blocks = !this.isFail(rules) && rules.status === 200 ? ((obj(rules.body)["blocks"] ?? []) as { value: Record<string, unknown> }[]) : [];
      const latest = [...blocks].reverse().find((x) => typeof x.value["mark"] === "boolean");
      marks[a.id] = latest === undefined ? true : (latest.value["mark"] as boolean);
    }
    const defaultName = str(meBody["defaultName"]);
    const needs = await this.call("GET", "/needs");
    const open = !this.isFail(needs) && needs.status === 200 && Array.isArray(needs.body) ? (needs.body as Mirror["needs"]) : last?.needs ?? [];
    const placeholders: Record<string, string> = {};
    for (const a of avatars) {
      const t = await this.call("GET", `/${a.id}/templates.geml`);
      const blocks = !this.isFail(t) && t.status === 200 ? ((obj(t.body)["blocks"] ?? []) as { value: Record<string, unknown> }[]) : [];
      const latest = [...blocks].reverse().find((x) => "text" in x.value);
      if (typeof latest?.value["text"] === "string") placeholders[a.id] = latest.value["text"];
    }
    const m: Mirror = { at: this.o.now, relay: this.client.relay, person: str(meBody["person"]) ?? "", lang, ...(defaultName !== undefined ? { defaultName } : {}), avatars, venues, marks, needs: open, placeholders };
    writeMirror(this.o.home, m);
    return { ok: true, view: this.view(m) };
  }

  setup(args: Record<string, unknown>): GbResult {
    const origin = relayOrigin(str(args["relay"]) ?? "");

    if (origin !== this.client.relay) this.logoutLocal();
    this.client.relay = origin;
    if (!this.client.trusted.includes(origin)) this.client.trusted.push(origin);
    this.save();
    return { ok: true, view: this.view(undefined) };
  }

    const origin = relayOrigin(str(args["origin"]) ?? "");

    if (!this.client.trusted.includes(origin)) this.client.trusted.push(origin);
    if (this.client.relay === "") this.client.relay = origin;
    this.save();
    return { ok: true, view: this.view(readMirror(this.o.home)) };
  }

  private mirrorVenue(owner: string, id: string): { m: Mirror; v: MirrorVenue } | undefined {
    const m = readMirror(this.o.home);
    const v = m?.venues.find((x) => x.owner === owner && x.id === id);

  private chat(m: Mirror, v: MirrorVenue): GbChat {
    const c = chatOf(v, m);
    return { owner: v.owner, id: v.id, kind: v.kind, name: c.name, count: c.count, as: c.as, items: c.items, earlier: c.earlier, isOwner: v.owner === v.as, ...(v.rules !== undefined ? { rules: v.rules } : {}), ...(this.o.zoneMinutes !== undefined ? { zoneMinutes: this.o.zoneMinutes } : {}) };
  }

  /** One chat read again, kept in the mirror, its last line marked seen. */
  async open(args: Record<string, unknown>): Promise<GbResult> {
    const owner = str(args["owner"]) ?? "", id = str(args["id"]) ?? "";
    const at = this.mirrorVenue(owner, id);
    if (at === undefined) return this.fail("client.noVenue");
    const r = await this.call("GET", `/venues/${owner}/${id}?as=${at.v.as}`);
    if (!this.isFail(r) && r.status === 200) {
      const b = obj(r.body);
      at.v.blocks = ((Array.isArray(b["blocks"]) ? b["blocks"] : []) as MirrorVenue["blocks"]).slice(-200);
      const venue = obj(b["venue"]);
      if (Array.isArray(venue["members"])) at.v.members = venue["members"] as MirrorVenue["members"];
      if (b["rules"] !== undefined) at.v.rules = b["rules"] as MirrorVenue["rules"];
      writeMirror(this.o.home, at.m);
    }
    const said = itemsOf(at.v).filter((i) => i.kind === "message");
    const lastId = said[said.length - 1]?.id;
    if (lastId !== undefined) { const seen = readSeen(this.o.home); seen[venueKey(owner, id)] = lastId; writeSeen(this.o.home, seen); }
    return { ok: true, chat: this.chat(at.m, at.v), view: this.view(at.m, this.isFail(r) ? r.reason : undefined) };
  }

  /** The person says something in a chat as their avatar there (`by: person`). */
  async say(args: Record<string, unknown>): Promise<GbResult> {
    const owner = str(args["owner"]) ?? "", id = str(args["id"]) ?? "";
    const at = this.mirrorVenue(owner, id);
    if (at === undefined) return this.fail("client.noVenue");
    const replyTo = str(args["replyTo"]);
    const r = await this.call("POST", `/venues/${owner}/${id}/messages`, { as: at.v.as, text: args["text"], id: `p-${randomBytes(5).toString("hex")}`, ...(replyTo !== undefined ? { replyTo } : {}) });
    if (this.isFail(r)) return r;
    if (r.status !== 201 && r.status !== 200) return this.refused(r);
    return this.open({ owner, id });
  }

  /** A group made as one of the person's avatars, or as a new one (`avatarName`, empty for a random name). */
  async group(args: Record<string, unknown>): Promise<GbResult> {
    const as = str(args["as"]);

    return this.open({ owner: v["owner"], id: v["id"] });
  }

  /** The avatar's own token, asked for once with the person's (spec §2.4: what an agent says is `by: agent`). */
  private async avatarToken(avatar: string): Promise<string | Fail> {

    return token;
  }

  private venueArg(args: Record<string, unknown>): { owner: string; id: string } | undefined {

  /** im_read: the venues of this session's avatar, or a venue's last lines. */
  async toolRead(args: Record<string, unknown>): Promise<GbResult> {
    const avatar = this.body(args);
    if (this.isFail(avatar)) return avatar;
    const token = await this.avatarToken(avatar);
    if (this.isFail(token)) return token;
    const name = readMirror(this.o.home)?.avatars.find((a) => a.id === avatar)?.name ?? avatar;
    const v = this.venueArg(args);
    if (v === undefined) {
      const r = await this.call("GET", "/venues", undefined, token);
      if (this.isFail(r)) return r;
      if (r.status !== 200) return this.refused(r);
      const lines = ((r.body as Record<string, unknown>[]) ?? []).map((x) => `${String(x["owner"])}/${String(x["id"])} · ${x["kind"] === "dm" ? say("panel.dm", this.lang) : ""}「${String(x["name"])}」`);
      return { ok: true, text: [say("tool.venues", this.lang, { name }), ...lines].join("\n") };
    }
    const r = await this.call("GET", `/venues/${v.owner}/${v.id}`, undefined, token);
    if (this.isFail(r)) return r;
    if (r.status !== 200) return r.status === 403 ? this.fail("body.notHere") : this.refused(r);
    const b = obj(r.body), venue = obj(b["venue"]);
    const mv: MirrorVenue = { owner: v.owner, id: v.id, kind: venue["kind"] === "dm" ? "dm" : "group", name: str(venue["name"]) ?? v.id, members: (venue["members"] ?? []) as MirrorVenue["members"], as: avatar, blocks: (b["blocks"] ?? []) as MirrorVenue["blocks"] };
    const limit = typeof args["limit"] === "number" && args["limit"] > 0 ? Math.min(100, Math.floor(args["limit"])) : 12;
    const said = itemsOf(mv).filter((i): i is Extract<ChatItem, { kind: "message" }> => i.kind === "message").slice(-limit);
    const lines = said.map((i) => `#${i.id} ${i.who}${i.mark ? `（${say("page.group.mark", this.lang)}）` : ""}${i.mine ? `（${say("panel.you", this.lang)}）` : ""}：${i.text}`);
    return { ok: true, text: [say("tool.recent", this.lang, { group: mv.name, count: said.length }), ...lines].join("\n") };
  }

  /** im_ask: a 需要你 card from this session's avatar to its person, about a chat it is in (spec §7.3). */
  async toolAsk(args: Record<string, unknown>): Promise<GbResult> {

  /** im_say: a line in a venue as this session's avatar, `by: agent`. */
  async toolSay(args: Record<string, unknown>): Promise<GbResult> {
    const avatar = this.body(args);
    if (this.isFail(avatar)) return avatar;
    const v = this.venueArg(args);
    if (v === undefined) return this.fail("client.noVenue");
    const token = await this.avatarToken(avatar);
    if (this.isFail(token)) return token;
    const replyTo = str(args["replyTo"]);
    const r = await this.call("POST", `/venues/${v.owner}/${v.id}/messages`, { text: args["text"], id: `m-${randomBytes(5).toString("hex")}`, ...(replyTo !== undefined ? { replyTo } : {}) }, token);
    if (this.isFail(r)) return r;
    if (r.status === 403) return this.fail("body.notHere");
    if (r.status !== 201 && r.status !== 200) return this.refused(r);
    const m = readMirror(this.o.home);
    const group = m?.venues.find((x) => x.owner === v.owner && x.id === v.id)?.name ?? v.id;
    const name = m?.avatars.find((a) => a.id === avatar)?.name ?? avatar;
    return { ok: true, text: say("tool.said", this.lang, { group, name }), sent: String(obj(obj(r.body)["message"])["id"] ?? "") };
  }
}

/** One card's row: in the inbox it says whose and where; in its chat, that only the person sees it and the avatar waits. */
function needRow(n: GbNeed, l: Lang, s: PaneState, where: "inbox" | "chat"): GbRow {

  const head = where === "chat" ? `${say("need.onlyYou", l)} · ${kind} · ${say("need.waiting", l)}` : say("need.from", l, { avatar: n.avatarName, kind, group: n.group ?? "" });
  const allow = s.allow?.[n.id] ?? {};
  const expired = n.state === "expired";
  const toggles = n.kind === "borrow" && !expired ? [
    { key: `allow-person-${n.id}`, label: say("need.borrow.person", l), on: allow.person === true, action: { op: "allow", need: n.id, person: allow.person !== true } as GbAction },
    { key: `allow-venue-${n.id}`, label: say("need.borrow.venue", l), on: allow.venue === true, action: { op: "allow", need: n.id, venue: allow.venue !== true } as GbAction },
  ] : [];
  const options: GbPress[] = expired ? [] : n.options.map((o, i) => ({ key: `answer-${n.id}-${i}`, label: o.label, primary: i === 0, action: { op: "answer", avatar: n.avatar, need: n.id, choice: i, ...(n.kind === "borrow" && i === 0 && allow.person === true ? { allowPerson: true } : {}), ...(n.kind === "borrow" && i === 0 && allow.venue === true ? { allowVenue: true } : {}) } }));

/** 需要你 at the top of the inbox (spec §7.1, §7.3): two whole, more folded behind 还有 N 件; the muted counted apart. */
function needRows(v: GbView, s: PaneState): GbRow[] {

  const loud = v.needs.filter((n) => !n.muted), quiet = v.needs.filter((n) => n.muted);

  const rows: GbRow[] = [{ kind: "section", key: "needs", text: `${say("need.title", l)} ${loud.filter((n) => n.state === "open").length}` }];

  for (const n of fold.shown) rows.push(needRow(n, l, s, "inbox"));

  if (fold.folded > 0) more.push({ key: "needs-more", label: say("need.more", l, { count: fold.folded }), action: { op: "more", what: "needs" } });

/** A time as the chat's lines carry it, HH:MM in the person's zone. */
const hhmm = (at: string, zoneMinutes = 0): string => {
  const t = Date.parse(at);
  if (Number.isNaN(t)) return "";
  const d = new Date(t + zoneMinutes * 60_000);
  return `${String(d.getUTCHours()).padStart(2, "0")}:${String(d.getUTCMinutes()).padStart(2, "0")}`;
};

/** The pane's rows for the page it is on; a chat or 叫人 with no chat open is the inbox. */

  if (s.problem !== null) rows.push(text("problem", s.problem, "error"));
  if (!v.loggedIn) return [...rows, ...loginRows(v, s)];
  if (s.page === "chat" && s.chat !== null) return [...rows, ...chatRows(v, s, s.chat)];
  if (s.page === "invite" && s.chat !== null) return [...rows, ...inviteRows(v, s.chat, s.link)];
  if (s.page === "avatars") return [...rows, ...avatarRows(v, s)];
  if (s.page === "settings") return [...rows, ...settingsRows(v)];
  if (s.page === "new-group") return [...rows, ...newGroupRows(v, s)];
  return [...rows, ...inboxRows(v, s)];
}

/** The band (transport §4): the first thing that needs the person, with its options and how many more; else nothing, unless gemsbang cannot work or nobody is logged in. */
export function gbBand(v: GbView | null, problem: string | null, now?: string): { text: string; tone: Tone; open: string; actions: GbPress[]; more: number } | undefined {
  const l = v?.lang ?? "zh";
  if (problem !== null) return { text: problem, tone: "error", open: say("panel.open", l), actions: [], more: 0 };
  if (v !== null && !v.loggedIn) return { text: say("panel.loginBand", l), tone: "dim", open: say("panel.open", l), actions: [], more: 0 };
  const loud = (v?.needs ?? []).filter((n) => !n.muted && n.state === "open" && (now === undefined || Date.parse(n.expires) > Date.parse(now)));
  const first = loud[0];
  if (first === undefined) return undefined;
  const actions = first.kind === "borrow" ? [] : first.options.slice(0, 3).map((o, i) => ({ key: `band-answer-${i}`, label: o.label, primary: i === 0, action: { op: "answer", avatar: first.avatar, need: first.id, choice: i } as GbAction }));
  return { text: `${say(`need.kind.${first.kind}`, l)} · ${first.summary}`, tone: first.kind === "error" ? "error" : "plain", open: say("panel.open", l), actions, more: loud.length - 1 };
}

/** What a field's Enter does: an action for the hooks module, or nothing for an empty field. */
export type FieldAction = { call: string; args: Record<string, unknown> } | { local: "phone"; phone: string } | { local: "group-avatar"; name: string } | { local: "join"; url: string };

export function fieldAction(field: GbField, typed: string, s: { chat: GbChat | null; phone: string | null; groupAs: string; groupAvatar?: string }, target?: string): FieldAction | undefined {
  const t = typed.trim();
  if (t === "" && field !== "default-name") return undefined;
  switch (field) {
    case "relay": return { call: "setup", args: { relay: t } };
    case "phone": return { local: "phone", phone: t };
    case "code": return s.phone === null ? undefined : { call: "login-verify", args: { phone: s.phone, code: t } };
    case "say": return s.chat === null ? undefined : { call: "say", args: { owner: s.chat.owner, id: s.chat.id, text: typed } };
    case "group": return { call: "group", args: { name: t, ...(s.groupAs !== "new" ? { as: s.groupAs } : s.groupAvatar !== undefined && s.groupAvatar !== "" ? { avatarName: s.groupAvatar } : {}) } };
    case "group-avatar": return { local: "group-avatar", name: t };
    case "join": return { local: "join", url: t };
    case "rename": return target === undefined ? undefined : { call: "rename", args: { avatar: target, name: t } };
    case "default-name": return { call: "default-name", args: { name: t } };
    case "need-own": {
      const m = /^([^/]+)\/([^/]+)$/.exec(target ?? "");
      return m === null ? undefined : { call: "answer", args: { avatar: m[1], need: m[2], choice: "own", text: typed } };
    }
    case "placeholder": return target === undefined ? undefined : { call: "placeholder", args: { avatar: target, text: t } };
    default: return undefined;
  }
}

    answers: {} as Record<string, (args: Record<string, unknown>) => Record<string, unknown>>,
    asked: [] as { question: string; options: string[] }[],
    replies: [] as string[],
    copied: [] as string[],
    toasts: [] as string[],
    opened: [] as string[],
  }
  const shell = { status: null, policy: null, contextKey: null, versions: { gemworks: '0.5.3', parser: '1.12.5' } }
  const answer = (req: Req): Record<string, unknown> => {
    w.sent.push(req)
    const own = w.answers[req.call]
    return { v: 1, ok: true, shell, gb: own !== undefined ? own(req.args) : { ok: true, view: w.view } }
  }
  const ran = (stdout: string, exitCode = 0) => ({ exitCode, stdout, stderr: '', isStdoutTruncated: false, isStderrTruncated: false })
  on('process.run', ($, e) => {
    if (e.argv[1] === '--version') return w.node ? { value: ran('v24.1.0\n') } : { deny: 'spawn node ENOENT' }
    if (e.argv[0] === '/bin/sh') return { value: ran('', 1) }
    if (e.argv[2] === 'hook') {
      if (!w.bridge) return { deny: 'timed out after 15000 ms' }
      return { value: ran(`${JSON.stringify(answer(JSON.parse(e.init?.stdin ?? '{}') as Req))}\n`) }
    }
    return { deny: `unexpected ${e.argv.join(' ')}` }
  })
  on('session.start', ($, e) => ({ cwd: e.cwd }))
  on('fs.read', ($, e) => (e.path.split('\\').join('/').endsWith('/.claude-plugin/plugin.json') ? { value: JSON.stringify({ version: '0.5.3' }) } : { deny: 'ENOENT' }))
  on('tool.register', ($, e) => { w.registered.push(e.name); return { value: { tool: `mcp__gemsbang__${e.name}` } } })
  on('command.register', ($, e) => { w.commands.push(e.name); return { value: { command: e.name } } })
  on('ui.open', ($, e) => { w.opened.push(e.id); return { value: { isPlaced: true } } })
  on('ui.close', () => ({ value: undefined }))
  on('ui.toast', ($, e) => { w.toasts.push(e.text); return { value: undefined } })
  on('ui.copy', ($, e) => { w.copied.push(e.text); return { value: { isCopied: true } } })
  on('session.id', () => ({ value: SESSION }))
  // The host's own line: what a plugin below would draw, here nothing.
  on('ui.render', { component: 'AbovePrompt' }, async ($, e, next) => { try { return await next(e) } catch { const { Box } = $.ui.resolve(e); return h(Box, { key: 'host-line' }) } })
  on('tool.call', { tool: 'AskUserQuestion' }, ($, e) => {
    const q = (e.questions as { question: string; options: { label: string }[] }[])[0]!
    w.asked.push({ question: q.question, options: q.options.map((o) => o.label) })
    const a = w.replies.shift() ?? q.options[0]!.label
    return { result: { questions: e.questions, answers: { [q.question]: a } }, text: a }
  })
  return w
}

type Drawn = { type: string; key?: string; props?: Record<string, unknown>; children?: (Drawn | string)[] }
/** The words a drawing shows, in order; a Button with no children as [label]; an Input as <placeholder>. */
const shown = (el: Drawn | string, out: string[] = []): string[] => {
  if (typeof el === 'string') { if (el.trim() !== '') out.push(el.trim()); return out }
  if (el.type === 'Button' && (el.children ?? []).length === 0) out.push(`[${String(el.props?.label)}]`)
  if (el.type === 'Input') out.push(`<${String(el.props?.placeholder)}>`)
  for (const c of el.children ?? []) shown(c, out)
  return out
}

}

/** Node ≥ 22: on the session's PATH; else where a login shell finds it (Unix) or `where` does (Windows); else where the installers put it; or why there is none. */
async function findNode($: EngineInterface): Promise<{ node: string } | { problem: string }> {
  const major = async (bin: string): Promise<number | undefined> => {
    try {
      const r = await $.process.run([bin, '--version'], { timeoutMs: PROBE_MS })
      return r.exitCode === 0 ? nodeMajor(r.stdout) : undefined
    } catch {
      return undefined
    }
  }
  const candidates: string[] = ['node']
  const offer = (p: string): void => { const q = p.trim(); if (q !== '' && !candidates.includes(q)) candidates.push(q) }
  for (const argv of [['/bin/sh', '-lc', 'command -v node'], ['cmd.exe', '/d', '/c', 'where node']]) {
    try {
      const r = await $.process.run(argv, { timeoutMs: PROBE_MS })
      if (r.exitCode === 0) for (const line of r.stdout.split(/\r?\n/)) offer(line)
    } catch { /* not this OS, or no such shell */ }
  }
  // Each variable is named at its own call: the engine lists what a module reads, so the name must be a literal there.
  try { const v = await $.env.get('ProgramFiles'); if (v) offer(`${v}\\nodejs\\node.exe`) } catch { /* no env */ }
  try { const v = await $.env.get('LOCALAPPDATA'); if (v) { offer(`${v}\\Programs\\nodejs\\node.exe`); offer(`${v}\\Volta\\bin\\node.exe`) } } catch { /* no env */ }
  try { const v = await $.env.get('NVM_SYMLINK'); if (v) offer(`${v}\\node.exe`) } catch { /* no env */ }
  for (const p of ['/opt/homebrew/bin/node', '/usr/local/bin/node', '/usr/bin/node']) offer(p)
  let seen: number | undefined
  for (const bin of candidates) {
    const m = await major(bin)
    if (m === undefined) continue
    if (m >= 22) return { node: bin }
    seen = seen === undefined ? m : Math.max(seen, m)
  }
  return { problem: seen !== undefined ? `gemsbang：Node ${seen} 太旧，需要 Node ≥ 22` : 'gemsbang：找不到 node — 请安装 Node ≥ 22' }
}

/** Since when the bridge has not answered, or undefined while it answers. */
let missedSince: number | undefined
let startTries = 0

/** One `gb` call through the bridge; its view, chat and link kept for the pane. Undefined when the bridge is unavailable; the line then says why. */
async function gb($: EngineInterface, call: string, args: Record<string, unknown> = {}, timeoutMs: number = BRIDGE_TIMEOUT_MS): Promise<GbResult | undefined> {
  const node = await read($, nodeAtom)
  const root = await read($, rootAtom)
  if (node === null || root === null) return undefined
  const request = { v: 1, root, bare: true, op: 'gb', call, args } as BridgeRequest
  let out: { exitCode: number; stdout: string; stderr: string }
  try {
    out = await $.process.run([node, `${$.plugin.root}/dist/gemworks.mjs`, 'hook'], { cwd: root, stdin: encodeRequest(request), timeoutMs })
  } catch (err) {
    const now = await $.clock.now()
    missedSince ??= now
    if (now - missedSince >= QUIET_MS) await setProblem($, `gemsbang：暂时没应答，不拦操作（${reasonOf(err)}）`)
    return undefined
  }
  missedSince = undefined
  const res: BridgeResponse | undefined = decodeResponse(out.stdout)
  if (res === undefined) {
    await setProblem($, unreadableText(out.exitCode, out.stderr, $.plugin.root).replace(/^gemworks：/, 'gemsbang：'))
    return undefined
  }
  if (!res.ok || res.gb === undefined) {
    await setProblem($, `gemsbang：${res.ok ? 'no answer' : res.error.replace(/^gemworks: /, '')}`)
    return undefined
  }
  await setProblem($, null)
  const r = res.gb
  if (r.ok) {
    if (r.view !== undefined && JSON.stringify(r.view) !== JSON.stringify(await read($, viewAtom))) await update($, viewAtom, () => r.view as unknown as GemsbangJson)
    if (r.chat !== undefined) await update($, chatAtom, () => r.chat as unknown as GemsbangJson)
    if (r.link !== undefined) await update($, linkAtom, () => r.link as unknown as GemsbangJson)
  }
  return r
}

/** A start that got no answer tries again by itself: in 5 s, 15 s, 30 s, then every minute, until one comes. */
function scheduleStartRetry($: EngineInterface): void {
  const wait = START_BACKOFF_MS[Math.min(startTries, START_BACKOFF_MS.length - 1)] as number
  startTries += 1
  $.clock.after(wait, () => {
    void (async () => { if ((await read($, rootAtom)) !== null && (await readView($)) === null) await startBridge($) })().catch(() => undefined)
  })
}

/** Node, then the first read of the chats. */
async function startBridge($: EngineInterface): Promise<void> {
  await update($, startedAtAtom, () => null)
  const now = await $.clock.now()
  await update($, startedAtAtom, () => now)
  if ((await read($, nodeAtom)) === null) {
    const found = await findNode($)
    if ('problem' in found) { await setProblem($, found.problem); return }
    await update($, nodeAtom, () => found.node)
  }
  const r = await gb($, 'status', {}, SLOW_TIMEOUT_MS)
  if (r === undefined) { scheduleStartRetry($); return }
  startTries = 0
}

async function retryStart($: EngineInterface): Promise<void> {
  if ((await read($, rootAtom)) === null || (await readView($)) !== null) return
  const last = await read($, startedAtAtom)
  const wait = (await read($, nodeAtom)) === null ? NODE_RETRY_MS : START_RETRY_MS
  if (last !== null && (await $.clock.now()) - last < wait) return
  await startBridge($)
}

/**

  let l = await langNow($)

  const group = i.group.name

  const avatars = i.you?.avatars ?? []

  const name = async (): Promise<Record<string, unknown> | undefined> => {

    const blanks = i.suggestions.filter((s) => s.blank === true).map((s) => `「${s.text}」`)

}

/** One of the three tools: one call, one line back. */
async function serveTool($: EngineInterface, name: ToolName, event: unknown): Promise<ToolCallResult> {
  const args = toolArgs(event as Record<string, unknown>)
  const session = await $.session.id().catch(() => '')
  const unavailable = async (): Promise<ToolCallResult> => ({ result: `${name}: gemsbang is unavailable: ${(await read($, problemAtom)) ?? ''}` })
  if (name === 'im_join') {
    const url = typeof args['url'] === 'string' ? args['url'] : ''
    return { result: `${name}: ${await joinFlow($, url, { session })}` }
  }
  const r = await gb($, name === 'im_say' ? 'tool-say' : name === 'im_ask' ? 'tool-ask' : 'tool-read', { ...args, session })
  if (r === undefined) return unavailable()
  return { result: `${name}: ${r.ok ? r.text ?? '' : r.reason}` }
}

  if (page !== undefined) await update($, pageAtom, () => page)
  const opened = await $.ui.open({ id: GB_PANE_ID, title: PANE_TITLE })
  $.clock.after(0, () => { void reload($).catch(() => undefined) })
  return opened
}

/** A reload: a pane the module before this one left up still answers to that module; it is closed and opened again from this one. */
async function adoptPane($: EngineInterface): Promise<void> {
  try {
    const up = await $.ui.panes()
    if (up.some((p) => p.id === GB_PANE_ID)) { await $.ui.close({ id: GB_PANE_ID }); await $.ui.open({ id: GB_PANE_ID, title: PANE_TITLE }) }
    if (up.some((p) => p.id === 'gemsbang-dialog')) await $.ui.close({ id: 'gemsbang-dialog' })
  } catch { /* no pane to adopt */ }
}

/** A call's refusal as one toast; a good answer's chat opens. */
async function run($: EngineInterface, call: string, args: Record<string, unknown>): Promise<GbResult | undefined> {
  const r = await gb($, call, args, SLOW_TIMEOUT_MS)
  if (r !== undefined && !r.ok) $.ui.toast(r.reason)
  if (r?.ok === true && r.chat !== undefined) await update($, pageAtom, () => 'chat')
  return r
}

/** A press. */
async function act($: EngineInterface, action: GbAction, surface?: string): Promise<void> {
  const l = await langNow($)
  const chat = (await read($, chatAtom)) as unknown as GbChat | null
  switch (action.op) {
    case 'page': {
      await update($, pageAtom, () => action.page)
      if (action.page === 'invite' && chat !== null) { await update($, linkAtom, () => null); await run($, 'link', { owner: chat.owner, id: chat.id }) }
      return
    }
    case 'filter': await update($, filterAtom, () => action.avatar); return
    case 'open': {
      const r = await run($, 'open', { owner: action.owner, id: action.id })
      if (r?.ok === true) await update($, pageAtom, () => 'chat')
      return
    }
    case 'copy': {
      let copied = false
      try { copied = (await $.ui.copy({ text: action.text, ...(surface !== undefined ? { surface: surface as 'terminal' } : {}) })).isCopied } catch { copied = false }
      $.ui.toast(say(copied ? 'panel.copied' : 'panel.copyFailed', l))
      return
    }
    case 'rotate': if (chat !== null) await run($, 'rotate', { owner: chat.owner, id: chat.id }); return
    case 'link-rules': if (chat !== null) await run($, 'link-rules', { owner: chat.owner, id: chat.id, ...(action.forward !== undefined ? { forward: action.forward } : {}), ...(action.approve !== undefined ? { approve: action.approve } : {}) }); return
    case 'mark': await run($, 'mark', { avatar: action.avatar, mark: action.mark }); return
    case 'bind': await run($, 'bind', { session: await $.session.id().catch(() => ''), avatar: action.avatar }); return
    case 'group-as': await update($, groupAsAtom, () => action.as); return
    case 'logout': {
      await run($, 'logout', {})
      await update($, pageAtom, () => 'inbox')
      await update($, chatAtom, () => null)
      return
    }
    case 'refresh': await reload($); return
    case 'answer': {
      await run($, 'answer', { avatar: action.avatar, need: action.need, choice: action.choice, ...(action.allowPerson === true ? { allowPerson: true } : {}), ...(action.allowVenue === true ? { allowVenue: true } : {}) })
      await update($, allowAtom, (was) => { const m = { ...((((was as unknown) as Record<string, unknown>) ?? {})) }; delete m[action.need]; return m as unknown as GemsbangJson })
      if (chat !== null && (await read($, pageAtom)) === 'chat') await gb($, 'open', { owner: chat.owner, id: chat.id })
      return
    }
    case 'allow': {
      await update($, allowAtom, (was) => {
        const m = { ...((((was as unknown) as Record<string, { person?: boolean; venue?: boolean }>) ?? {})) }
        m[action.need] = { ...(m[action.need] ?? {}), ...(action.person !== undefined ? { person: action.person } : {}), ...(action.venue !== undefined ? { venue: action.venue } : {}) }
        return m as unknown as GemsbangJson
      })
      return
    }
    // Each atom named where it is written: the engine lists a module's state by reading its calls.
    case 'more': if (action.what === 'needs') await update($, needsOpenAtom, () => true); else await update($, mutedOpenAtom, () => true); return
    case 'mute': await run($, 'mute', { ...(action.avatar !== undefined ? { avatar: action.avatar } : {}), ...(action.venue !== undefined ? { venue: action.venue } : {}), on: action.on }); return
    case 'resend': {
      const phone = await read($, phoneAtom)
      if (phone !== null) { const r = await run($, 'login-start', { phone }); if (r?.ok === true) $.ui.toast(r.text ?? '') }
      return
    }
    default: return
  }
}

/** Enter in a field: its one call, or what the pane keeps until the next. */
async function submit($: EngineInterface, field: GbField, value: string, target?: string): Promise<void> {
  const [chat, phone, groupAs, groupAvatar] = await Promise.all([read($, chatAtom), read($, phoneAtom), read($, groupAsAtom), read($, groupAvatarAtom)])
  const a = fieldAction(field, value, { chat: chat as unknown as GbChat | null, phone, groupAs, ...(groupAvatar !== null ? { groupAvatar } : {}) }, target)
  if (a === undefined) return
  if ('local' in a) {
    if (a.local === 'phone') { const r = await run($, 'login-start', { phone: a.phone }); if (r?.ok === true) await update($, phoneAtom, () => a.phone) }
    else if (a.local === 'group-avatar') await update($, groupAvatarAtom, () => a.name)
    else $.ui.toast(await joinFlow($, a.url, undefined))
    return
  }
  const r = await run($, a.call, a.args)
  if (r?.ok !== true) return
  if (a.call === 'login-verify' || a.call === 'setup') await update($, phoneAtom, () => null)
  if (a.call === 'group') { await update($, groupAvatarAtom, () => null); await update($, groupAsAtom, () => 'new') }
}

const keep = (p: Promise<void>, $: EngineInterface): void => { void p.catch((err: unknown) => $.ui.toast(`gemsbang：${reasonOf(err)}`)) }

/** The elements, loosely typed: the pane is drawn on every surface, and only some have Input, Select or Svg. */
type Els = { Box: any; Text: any; Button: any; Input?: any; Select?: any; Svg?: any }

function elementsOf($: EngineInterface, e: Parameters<EngineInterface['ui']['resolve']>[0]): Els {
  const els = $.ui.resolve(e) as unknown as Els
  return (e as { surface?: string }).surface === 'terminal' ? { ...els, Svg: undefined } : els
}

const toneOf = (tone: Tone): Record<string, unknown> => (tone === 'dim' ? { dimColor: true } : tone === 'error' ? { color: 'error' } : tone === 'success' ? { color: 'success' } : {})

function drawRow($: EngineInterface, els: Els, row: GbRow, columns: number): unknown {
  const { Box, Text, Button, Input, Select } = els
  const press = (a: GbAction) => (p?: { surface?: string }) => keep(act($, a, p?.surface), $)
  const badge = (b: { color: string; initial: string }, key: string): unknown => <Text key={key} color={b.color} bold>{b.initial}</Text>
  switch (row.kind) {
    case 'head': return (
      <Box key={row.key} gap={1} alignItems="center">
        {row.back !== undefined && <Button key={`${row.key}-back`} plain dimColor label="‹" onPress={press(row.back)} />}
        <Text bold>{row.title}</Text>
        {row.sub !== undefined && <Box flexShrink={1} minWidth={0}><Text dimColor wrap="truncate-end">{row.sub}</Text></Box>}
        <Box flexGrow={1} />
        {row.actions.map((b) => <Button key={b.key} plain label={b.label} onPress={press(b.action)} />)}
      </Box>
    )
    case 'chips': return (
      <Box key={row.key} gap={1} flexWrap="wrap">
        {row.items.map((c) => (
          <Button key={c.key} plain onPress={press(c.action)}>
            <Text>{c.badge !== undefined && <Text color={c.badge.color} bold>{`${c.badge.initial} `}</Text>}<Text {...(c.on ? { bold: true, underline: true } : { dimColor: true })}>{c.label}</Text></Text>
          </Button>
        ))}
      </Box>
    )
    case 'chat': {
      // A Button holds words only: the name line is one, the last line another, the time and the unread beside them.
      const r = row.row
      const second = r.last !== undefined ? truncate(`${r.last.who}：${r.last.text}`, Math.max(8, columns - 8)) : ''
      return (
        <Box key={row.key} flexDirection="column" paddingX={1}>
          <Box gap={1}>
            <Button key={`${row.key}-go`} plain onPress={press(row.action)}>
              <Text><Text color={r.as.color} bold>{`${r.as.initial} `}</Text><Text bold>{truncate(r.name, Math.max(8, columns - 24))}</Text><Text dimColor>{` · ${r.as.name}`}</Text></Text>
            </Button>
            <Box flexGrow={1} />
            <Text dimColor>{r.time}</Text>
          </Box>
          {second !== '' && (
            <Box gap={1}>
              <Box flexShrink={1} minWidth={0}><Button key={`${row.key}-last`} plain dimColor label={second} onPress={press(row.action)} /></Box>
              <Box flexGrow={1} />
              {r.unread > 0 && <Text color={r.as.color} bold>{String(r.unread)}</Text>}
            </Box>
          )}
        </Box>
      )
    }
    case 'message': {
      const i = row.item
      return (
        <Box key={row.key} flexDirection="column" paddingX={1}>
          <Box gap={1}>
            {row.badge !== undefined && badge(row.badge, `${row.key}-badge`)}
            <Text bold>{i.who}</Text>
            {row.tag !== undefined && <Text color={GEMSBANG_BLUE}>{row.tag}</Text>}
            <Text dimColor>{row.time}</Text>
          </Box>
          <Text wrap="wrap">{i.text}</Text>
        </Box>
      )
    }
    case 'text': return <Text key={row.key} wrap="wrap" {...toneOf(row.tone)}>{row.text}</Text>
    case 'section': return (
      <Box key={row.key} gap={1} marginTop={1}>
        {row.badge !== undefined && badge(row.badge, `${row.key}-badge`)}
        <Text bold dimColor={row.badge === undefined}>{row.text}</Text>
        {row.note !== undefined && <Text dimColor>{row.note}</Text>}
      </Box>
    )
    case 'input': {
      if (Input === undefined) return <Text key={row.key} dimColor>{row.placeholder}</Text>
      return <Input key={row.key} placeholder={row.placeholder} {...(row.label !== undefined ? { label: row.label } : {})} onSubmit={(value: string) => keep(submit($, row.field, value, row.target), $)} />
    }
    case 'select': {
      if (Select === undefined) return <Text key={row.key} dimColor>{`${row.label}：${row.options.find((o) => o.value === row.value)?.label ?? row.value}`}</Text>
      return <Select key={row.key} label={row.label} options={row.options} value={row.value} onSelect={(value: string) => keep(run($, 'lang', { lang: value }).then(() => undefined), $)} />
    }
    case 'buttons': return (
      <Box key={row.key} gap={2} flexWrap="wrap">
        {row.items.map((b) => <Button key={b.key} label={b.label} {...(b.primary ? { variant: 'primary' } : {})} onPress={press(b.action)} />)}
      </Box>
    )
    case 'toggle': return <Button key={row.key} plain label={`${row.on ? '☑' : '☐'} ${row.label}`} onPress={press(row.action)} />
    case 'copy': return (
      <Box key={row.key} flexDirection="column">
        <Text wrap="wrap">{row.text}</Text>
        <Box><Button key={`${row.key}-button`} label={row.label} onPress={press({ op: 'copy', text: row.text })} /></Box>
      </Box>
    )
    case 'need': return (
      <Box key={row.key} flexDirection="column" borderStyle="round" borderColor={row.tone === 'error' ? 'error' : 'warning'} paddingX={1}>
        <Box gap={1}>
          {row.badge !== undefined && badge(row.badge, `${row.key}-badge`)}
          <Box flexShrink={1} minWidth={0}><Text dimColor wrap="truncate-end">{row.head}</Text></Box>
          <Box flexGrow={1} />
          <Text dimColor>{row.expires}</Text>
        </Box>
        <Text wrap="wrap" {...toneOf(row.tone)}>{row.summary}</Text>
        {row.checked !== undefined && <Text dimColor wrap="wrap">{row.checked}</Text>}
        {row.willSay !== undefined && <Text wrap="wrap">{row.willSay}</Text>}
        {row.toggles.map((t) => <Button key={t.key} plain label={`${t.on ? '☑' : '☐'} ${t.label}`} onPress={press(t.action)} />)}
        {row.options.length > 0 && <Box gap={1} flexWrap="wrap">{row.options.map((b) => <Button key={b.key} label={b.label} {...(b.primary ? { variant: 'primary' } : {})} onPress={press(b.action)} />)}</Box>}
        {row.own !== undefined && (Input !== undefined
          ? <Input key={`${row.key}-own`} placeholder={row.own.placeholder} onSubmit={(value: string) => keep(submit($, 'need-own', value, row.own?.target), $)} />
          : <Text dimColor>{row.own.placeholder}</Text>)}
      </Box>
    )
    default: return null
  }
}

function safeRow($: EngineInterface, els: Els, row: GbRow, columns: number): unknown {
  try {
    return drawRow($, els, row, columns)
  } catch (err) {
    return <els.Text key={`failed-${row.key}`} color="error">{`gemsbang：${reasonOf(err)}`}</els.Text>
  }
}
