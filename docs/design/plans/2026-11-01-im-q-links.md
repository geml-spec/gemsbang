# Gemsbang Plan Q: A Group, One Link

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** People and agents come into groups by a link, and the relay is served. A group has one current link, `/i/<code>`, good for seven days; members pass it on unless the owner turned that off, the owner can swap it (the old one stops at once) and can choose to let each newcomer in by hand. A person who opens the link in WeChat sees the group, types a phone number and a code, picks which avatar goes in (by default the one the inviter knows) or names a new one from the names offered for the occasion, and lands on the group's web page, `/g/<group>`, where they read and talk. An agent reads `/i/<code>.md` and joins with its person's yes: the code its person typed into the plugin's own box, or the device token of an agent its person attached before. Every page and every refusal speaks the request's language. `gemworks relay serve` runs it all.

**Architecture:** Three pure modules join `src/core/avatar/`: the link's rules (`links.ts`), the names offered on joining (`naming.ts`) and which avatar joins a second group (`pick.ts`); `words.ts` gains the new refusals, the pages' words, the agent's instructions and `pickLang` for `Accept-Language`. `AvatarRelay` gains links and joining: a link lives under the relay's own folder (`_relay/links/<code>.geml`, and `_relay/links/<group>.geml` for the group's codes in order), the owner's link rules in the group itself (`link-rules-N` blocks its members read), the requests waiting for the owner in the owner avatar's `requests.geml`. Two small refactors make the way in reuse what plan P built: checking a login code apart from issuing a person's token (`checkCode`, which now also stops a number after five wrong codes), growing an avatar apart from the token that asks (`grow`); and `createGroup` may grow a new avatar for a person who came in by no link. Over it: `avatar-api.ts` (the routes, as a function from a request to a response), `avatar-pages.ts` (three static pages, their words injected, filled by the relay's JSON with DOM calls) and `avatar-server.ts` (`node:http` and the WebSocket subscriptions, each pushed block shown as its follower may read it). The older relay and its `gemworks relay` stay as they are.

**Tech Stack:** TypeScript (`src/core/avatar`, `src/relay`, `src/cli.ts`), `node:test` over `dist/`, the global `fetch` and `WebSocket` of Node 22+ in the server's tests.

**Before this plan:** gemsbang 0.5.1 on `main` (`f09d3c6`), plan P (`docs/design/plans/2026-11-01-im-p-avatars.md`). The spec is `docs/design/specs/2026-11-01-gemsbang-design.md` (§6 is this plan's); the transport spec is `docs/design/specs/2026-10-30-agent-im-transport-design.md` (§2.5, §7.1).

## What the spec decided, and what this plan does about each

- **One link per group (§6.1).** The current code is the last one made for the group; a member who asks for it gets it, made afresh when there is none or it is past its seven days. Codes are eight letters from an alphabet with no 0/o or 1/l/i. The owner's swap makes a new one; the old answers `link.gone` («这个链接已经失效，找拉你的人要个新的»), which is all a stopped link says.
- **Who passed it on (§6.4).** The path a member gets carries them, `?by=<avatar>`; the page sends it back on joining, and the relay uses it only if that avatar is in the group (else the owner counts as the inviter). `?call=` carries the name the inviter calls the newcomer, offered first (§6.5).
- **Forwarding and the owner's approval (§6.1, §3 rule 28).** Both are the owner's, in the group as `link-rules-N`; forwarding off, only the owner gets the link. Approval on, a newcomer's avatar grows (so they have a name) and waits in `requests.geml` of the owner avatar; asking again is the same request; the owner answers once. Plan S turns a request into a 需要你 card (答应事情).
- **Which avatar goes in (§6.4, §3 rule 22).** An avatar of the person already in the group is answered as it is. Otherwise `as` names one of theirs; `name` (or `new: true` for a random one) makes a new one; neither, the one the inviter knows; none known, a new one with a random name. The page always asks; the default only saves a press.
- **Names offered (§6.5, §3 rule 19).** By the group's name: a parents' group offers 「__ 妈妈」「__ 爸爸」 (English and Japanese in kind) with a box for the child's name; then the inviter's name for you; then your default name with a line that your avatars may then share it. None is picked; skipping gives a random name.
- **The agent's way in (§6.3, §5 rule 2, transport §2.5).** `/i/<code>.md` says, in the request's language, to follow it only from the gemsbang relay on the plugin's allowlist and only when the person pasted the line; to take the phone and code in the plugin's own box; to ask which avatar; and how to `POST /i/<code>/join`. With no token: the number and code give the avatar's token and a device token (never the person's). With the device token: the person's answer gives the avatar's token. An avatar's token cannot join anything. Plan R's `im_join` is the plugin side.
- **Guessing a code (§6.2).** Plan P let a number try codes without end, a million guesses in ten minutes. Now five wrong codes for a number within ten minutes stop every code of that number, the right one too, until ten minutes pass (`code.locked`); with three codes to a number in ten minutes, that is fifteen guesses at most.
- **Languages (§7.6).** A refusal is `{error: <code>, params?, reason}` with the words in the query's `lang`, else the body's, else the person's, else `Accept-Language`, else Chinese. The pages carry their words for the request's language and links to the other two.
- **The group's page is every member's (§7.2, §3 rule 27).** `/g/<group>` finds the group in the person's list, shows who they are there, the thread (`分身` on an agent's line where its avatar marks), the box 「以 <分身> 说」, 把群转给别人 and 有事时提醒我 (which says reminders are not connected yet: plan S).
- **Not in this plan:** the Claude Code side (R), 需要你 cards and push (S), hosted agents (T), borrowing (U), a phone's own country rules (spec §12 item 4).

```js
  assert.equal(pickLang("ja;q=0,en;q=0.1"), "en", "a weight of 0 is a no");
  assert.equal(pickLang("fr, de"), undefined);
  assert.equal(pickLang(""), undefined);
  assert.equal(pickLang(undefined), undefined);
  const params = { group: "前端周会", owner: "John", days: 7, relay: "https://im.example", join: "https://im.example/i/abcd9abp/join" };

    assert.equal(md.includes("{"), md.includes('{"'), `${lang}: every blank filled`);
  }
});
```

```ts
// A group's link (spec §6.1): one current code per group, good for seven
// days; the owner can swap it, and the old one stops at once. Members may
// pass it on unless the owner turned that off; the owner may also ask to let
// each newcomer in by hand. A link is said as `/i/<code>`, for a person's
// browser, and `/i/<code>.md`, for an agent; the one who passed it on may
// ride along as `?by=<avatar>`, and the name they call the newcomer as
// `?call=`. Pure: the random bytes and the time are given.

export const LINK_TTL_MS = 7 * 24 * 3_600_000;
/** Letters and digits nobody misreads: no 0/o, 1/l/i. */
export const LINK_ALPHABET = "abcdefghjkmnpqrstuvwxyz23456789";
export const LINK_CODE = /^[a-hj-km-np-z2-9]{8}$/;

/** What a group's owner set about its link: whether members may pass it on, whether the owner lets each newcomer in. */
export interface LinkRules { forward: boolean; approve: boolean }
export const DEFAULT_LINK_RULES: LinkRules = { forward: true, approve: false };

/** Eight letters of the alphabet from eight random bytes. */
export function makeCode(bytes: Uint8Array): string {
  if (bytes.length < 8) throw new Error("a link's code needs eight random bytes");
  let out = "";
  for (let i = 0; i < 8; i++) out += LINK_ALPHABET[bytes[i]! % LINK_ALPHABET.length];
  return out;
}

/** When a link made at `made` stops. */
export const expiresAt = (made: string): string => new Date(Date.parse(made) + LINK_TTL_MS).toISOString().replace(/\.\d{3}Z$/, "Z");

export type LinkStatus = "ok" | "expired" | "replaced";

/** A link as it stands at `now`: swapped for another, past its day, or good. */
export function linkStatus(link: { code: string; expires: string }, current: string | undefined, now: string): LinkStatus {
  if (current !== link.code) return "replaced";
  return Date.parse(now) >= Date.parse(link.expires) ? "expired" : "ok";
}

/** Whether this member may hand the link out: the owner always, the others while forwarding is on. */
export const mayHandOut = (rules: LinkRules, isOwner: boolean): boolean => isOwner || rules.forward;

/** The rules with a change laid over them; undefined when the change is not two booleans at most. */
export function withLinkRules(base: LinkRules, change: unknown): LinkRules | undefined {
  if (typeof change !== "object" || change === null || Array.isArray(change)) return undefined;
  const out: LinkRules = { ...base };
  for (const [key, v] of Object.entries(change as Record<string, unknown>)) {
    if (key === "as") continue;
    if ((key !== "forward" && key !== "approve") || typeof v !== "boolean") return undefined;
    out[key] = v;
  }
  return out;
}

/** The page's path for a person, with who passed it on and what they call the newcomer. */
export function linkPath(code: string, o: { by?: string; call?: string } = {}): string {
  const q = new URLSearchParams();
  if (o.by !== undefined) q.set("by", o.by);
  if (o.call !== undefined && o.call.trim() !== "") q.set("call", o.call.trim());
  const s = q.toString();
  return `/i/${code}${s === "" ? "" : `?${s}`}`;
}
```

```ts
// The names offered as the last step of joining (spec §6.5): by the
// occasion, the group's name read for a parents' group or a work group; the
// name the one who passed the link on calls the newcomer, first; the
// person's default name, never picked for them, with a line that their
// avatars may then share a name. A parents' suggestion has a blank for the
// child's name. Skipping all of them gives a random name (names.ts). Pure.
import type { Lang } from "./words.js";

export type Occasion = "parents" | "work" | "other";
export interface Suggestion { text: string; kind: "call" | "parent" | "default"; blank?: boolean }

const PARENTS = /家长|班级|[一二三四五六七八九十\d]+[)）]?\s*班|幼儿园|小学|学校|parent|pta|class\s*\d|保護者|クラス|[一二三四五六\d]年[一二三四五六七八九十\d]*組/i;
const WORK = /周会|例会|项目|团队|小组|部门|公司|同事|team|project|standup|weekly|sprint|squad|チーム|プロジェクト|定例|部署/i;

export function occasionOf(group: string): Occasion {
  if (PARENTS.test(group)) return "parents";
  if (WORK.test(group)) return "work";
  return "other";
}

/** A parent's names with a blank for the child, `__` where the child's name goes. */
const PARENT_NAMES: Readonly<Record<Lang, readonly string[]>> = {
  zh: ["__ 妈妈", "__ 爸爸"],
  en: ["__'s mom", "__'s dad"],
  ja: ["__ママ", "__パパ"],
};
export const BLANK = "__";

/** The names to offer, in order: what the inviter calls you, a parent's names, your default name. None is picked. */
export function suggestions(o: { group: string; lang: Lang; call?: string; defaultName?: string }): Suggestion[] {
  const out: Suggestion[] = [];
  const add = (s: Suggestion): void => { if (s.text.trim() !== "" && !out.some((x) => x.text === s.text)) out.push(s); };
  if (o.call !== undefined) add({ text: o.call.trim(), kind: "call" });
  if (occasionOf(o.group) === "parents") for (const text of PARENT_NAMES[o.lang]) add({ text, kind: "parent", blank: true });
  if (o.defaultName !== undefined) add({ text: o.defaultName, kind: "default" });
  return out;
}

/** A suggestion with its blank filled; the blank left when the child's name is empty. */
export const fillBlank = (text: string, child: string): string => (child.trim() === "" ? text : text.replace(BLANK, child.trim()));
```

```ts
// Which avatar a person comes into a second group as (spec §6.4): the one the
// avatar who brought them knows, the person's avatar in a group they share;
// none shared, there is no default and the person picks one, or a new one.
// An avatar already in the group is the one, and nothing is asked. Pure.

export interface Placed { id: string; groups: { venue: string; members: readonly string[] }[] }

export type Pick = { kind: "in"; avatar: string } | { kind: "known"; avatar: string } | { kind: "choose" };

export function pickAvatar(mine: readonly Placed[], venue: string, inviter: string | undefined): Pick {
  const inside = mine.find((a) => a.groups.some((g) => g.venue === venue));
  if (inside !== undefined) return { kind: "in", avatar: inside.id };
  if (inviter !== undefined) {
    const known = mine.find((a) => a.id !== inviter && a.groups.some((g) => g.members.includes(inviter)));
    if (known !== undefined) return { kind: "known", avatar: known.id };
  }
  return { kind: "choose" };
}
```

```ts
  // --- links and joining (spec §6) ---

  /** The group's link rules (spec §6.1): the defaults, then each change the owner made. */
  linkRulesOf(owner: string, venue: string): LinkRules {
    let rules = DEFAULT_LINK_RULES;
    for (const b of readDoc(this.root, owner, venueDoc(venue)).blocks) {
      if (!/^link-rules-\d+$/.test(b.id)) continue;
      rules = withLinkRules(rules, { forward: b.value["forward"], approve: b.value["approve"] }) ?? rules;
    }
    return rules;
  }

  /** The group's current code: the last one made for it, kept under the relay's own `links/`. */
  private currentCode(venue: string): string | undefined {
    const codes = readDoc(this.root, RELAY_OWNER, `links/${venue}.geml`).blocks.filter((b) => /^code-\d+$/.test(b.id));
    return str(codes[codes.length - 1]?.value["code"]);
  }

  private linkOf(code: string): { code: string; owner: string; venue: string; expires: string } | undefined {
    if (!LINK_CODE.test(code)) return undefined;
    const v = readDoc(this.root, RELAY_OWNER, `links/${code}.geml`).blocks.find((b) => b.id === "link")?.value;
    const owner = str(v?.["owner"]), venue = str(v?.["venue"]), expires = str(v?.["expires"]);
    return owner === undefined || venue === undefined || expires === undefined ? undefined : { code, owner, venue, expires };
  }

  /** A new code for the group, made current; the one before it stops (spec §6.1). */
  private newLink(owner: string, venue: string, by: string): { code: string; expires: string } {
    const now = this.now(), expires = expiresAt(now);
    for (;;) {
      const code = makeCode(randomBytes(8));
      if (appendSealed(this.root, RELAY_OWNER, `links/${code}.geml`, "link", { owner, venue, by, at: now, expires }).existed) continue;
      appendBlock(this.root, RELAY_OWNER, `links/${venue}.geml`, nextId("code"), (_d, prev, id) => sealed({ id, code, at: now }, prev));
      return { code, expires };
    }
  }

  /** A group the acting avatar is in, as its owner or a member. */
  private inGroup(by: TokenRecord, owner: string, venue: string, as: unknown): { avatar: string; isOwner: boolean } | Fail {
    const s = this.venueState(owner, venue);
    if (s === undefined) return fail(404, "group.missing");
    if (s.kind !== "group") return fail(400, "link.dm");
    const a = this.acting(by, as);
    if (isFail(a)) return a;
    if (!s.members.includes(a.avatar)) return fail(403, "venue.notMember");
    return { avatar: a.avatar, isOwner: a.avatar === owner };
  }

  private linkView(code: string, expires: string, rules: LinkRules, by: string): LinkView {
    return { code, expires, path: linkPath(code, { by }), forward: rules.forward, approve: rules.approve };
  }

  /** The group's link for a member to hand out (spec §6.1): its current one, or a new one when there is none or it is past its day; the owner always, the others while forwarding is on. */
  linkFor(by: TokenRecord, owner: string, venue: string, body: unknown): Result<{ link: LinkView }> {
    const g = this.inGroup(by, owner, venue, obj(body)?.["as"]);
    if (isFail(g)) return g;
    const rules = this.linkRulesOf(owner, venue);
    if (!mayHandOut(rules, g.isOwner)) return fail(403, "link.ownerOnly");
    const current = this.linkOf(this.currentCode(venue) ?? "");
    const link = current !== undefined && linkStatus(current, current.code, this.now()) === "ok" ? current : this.newLink(owner, venue, avatarSpeaker(g.avatar));
    return { ok: true, link: this.linkView(link.code, link.expires, rules, g.avatar) };
  }

  /** A new link in place of the current one, by the owner (spec §6.1). */
  rotateLink(by: TokenRecord, owner: string, venue: string, body: unknown): Result<{ link: LinkView }> {
    const g = this.inGroup(by, owner, venue, obj(body)?.["as"]);
    if (isFail(g)) return g;
    if (!g.isOwner) return fail(403, "link.ownerRules");
    const link = this.newLink(owner, venue, avatarSpeaker(g.avatar));
    return { ok: true, link: this.linkView(link.code, link.expires, this.linkRulesOf(owner, venue), g.avatar) };
  }

  /** Forwarding on or off, the owner's approval on or off, by the owner (spec §6.1). */
  setLinkRules(by: TokenRecord, owner: string, venue: string, body: unknown): Result<{ rules: LinkRules }> {
    const g = this.inGroup(by, owner, venue, obj(body)?.["as"]);
    if (isFail(g)) return g;
    if (!g.isOwner) return fail(403, "link.ownerRules");
    const next = withLinkRules(this.linkRulesOf(owner, venue), body);
    if (next === undefined) return fail(400, "link.rules");
    const made = appendBlock(this.root, owner, venueDoc(venue), nextId("link-rules"), (_d, prev, id) => sealed({ id, forward: next.forward, approve: next.approve, by: avatarSpeaker(g.avatar), at: this.now() }, prev));
    this.emit(owner, venueDoc(venue), made.block);
    return { ok: true, rules: next };
  }

  /** The link, good: its group's owner and id; missing or stopped, the refusal (spec §7.1 of the transport: a stopped link only says so). */
  private goodLink(code: string): { code: string; owner: string; venue: string; expires: string } | Fail {
    const link = this.linkOf(code);
    if (link === undefined || this.venueState(link.owner, link.venue) === undefined) return fail(404, "link.missing");
    return linkStatus(link, this.currentCode(link.venue), this.now()) === "ok" ? link : fail(410, "link.gone");
  }

  /** The person's avatars with the groups each is in, for picking one (pick.ts). */
  private placed(person: string): { id: string; groups: { venue: string; members: string[] }[] }[] {
    return this.avatarsOf(person).map((a) => ({
      id: a.id,
      groups: this.joinedOf(a.id).map((v) => ({ venue: v.venue, members: this.venueState(v.owner, v.venue)?.members ?? [] })),
    }));
  }

  /** Who brought the newcomer: the member named in the link (`?by=`), else the group's owner. */
  private inviterOf(owner: string, venue: string, by: unknown): string {
    return typeof by === "string" && this.venueState(owner, venue)?.members.includes(by) === true ? by : owner;
  }

  /** What the link's page shows (spec §6.2 step 1): anyone sees the group's name, how many are in it, a few of them, its owner and until when; a person logged in also sees which of their avatars would go in, and every viewer the names offered (§6.5), in their language. */
  linkInfo(code: string, viewer: TokenRecord | undefined, q: { by?: string; call?: string; lang?: Lang } = {}): Result<LinkInfo> {
    const link = this.goodLink(code);
    if (isFail(link)) return link;
    const view = this.venueView(link.owner, link.venue)!;
    const person = viewer === undefined ? undefined : this.personOf(viewer);
    const lang = person !== undefined ? this.languageOf(person) : (q.lang ?? DEFAULT_LANG);
    const call = q.call !== undefined && nameFault(q.call) === undefined ? q.call.trim() : undefined;
    const defaultName = person === undefined ? undefined : this.defaultNameOf(person);
    const info: LinkInfo = {
      group: { id: view.id, name: view.name, count: view.members.length, members: view.members.slice(0, 5) },
      owner: this.card(link.owner),
      expires: link.expires,
      approve: this.linkRulesOf(link.owner, link.venue).approve,
      suggestions: suggestions({ group: view.name, lang, ...(call !== undefined ? { call } : {}), ...(defaultName !== undefined ? { defaultName } : {}) }),
    };
    if (person !== undefined) info.you = { avatars: this.avatarsOf(person), pick: pickAvatar(this.placed(person), link.venue, this.inviterOf(link.owner, link.venue, q.by)) };
    return { ok: true, ...info };
  }
```

```ts
  /**
   * In through a link (spec §6.2, §6.3), with the person's yes: their own
   * token, or the device token of the agent they attached on a machine. The
   * avatar is the one named in `as`; else a new one with the `name` given
   * (`new: true` and no name, a random one); else the one the inviter knows
   * (§6.4), else a new one with a random name. An avatar already in the group is answered as it is. With the
   * owner's approval on, the avatar waits in the owner's requests. A
   * device's answer carries the avatar's token, for the agent that is now
   * its body.
   */
  joinByLink(by: TokenRecord, code: string, body: unknown): Result<Joined> {
    const person = this.personOf(by);
    if (person === undefined) return fail(403, "join.needsPerson");
    const link = this.goodLink(code);
    if (isFail(link)) return link;
    const o = obj(body) ?? {};
    const pick = pickAvatar(this.placed(person), link.venue, this.inviterOf(link.owner, link.venue, o["by"]));
    let avatar: string;
    if (pick.kind === "in") avatar = pick.avatar;
    else if (o["as"] !== undefined) {
      const as = str(o["as"]);
      if (as === undefined || this.ownerOf(as) !== person) return fail(403, "avatar.notYours");
      avatar = as;
    } else if (o["name"] !== undefined || o["new"] === true || pick.kind === "choose") {
      const grown = this.grow(person, o["name"]);
      if (isFail(grown)) return grown;
      avatar = grown.avatar.id;
    } else avatar = pick.avatar;
    const card = this.card(avatar)!;
    const token = by.scope === "device" ? issueToken(this.root, { speaker: avatarSpeaker(avatar), scope: "avatar", by: by.id, at: this.now() }).token : undefined;
    const done = (x: Partial<Joined>): Result<Joined> => ({ ok: true, venue: this.venueView(link.owner, link.venue, avatar)!, avatar: card, already: false, ...x, ...(token !== undefined ? { token } : {}) });
    if (pick.kind === "in") return done({ already: true });
    if (this.linkRulesOf(link.owner, link.venue).approve) {
      const asked = this.requestsOf(link.owner).find((r) => r.venue === link.venue && r.avatar.id === avatar);
      if (asked !== undefined) return done({ pending: asked.id });
      const made = appendBlock(this.root, link.owner, "requests.geml", nextId("request"), (_d, prev, id) => sealed({ id, venue: link.venue, avatar: avatarSpeaker(avatar), link: code, at: this.now() }, prev));
      this.emit(link.owner, "requests.geml", made.block);
      return done({ pending: made.block.id });
    }
    this.join(link.owner, link.venue, avatar, avatarSpeaker(avatar));
    appendBlock(this.root, RELAY_OWNER, `links/${code}.geml`, nextId("use"), (_d, prev, id) => sealed({ id, at: this.now() }, prev));
    return done({});
  }

  joinWithCode(code: string, body: unknown): Result<Joined & { device: string }> {
    const link = this.goodLink(code);
    if (isFail(link)) return link;
    const p = this.checkCode(body);
    if (isFail(p)) return p;
    const device = issueToken(this.root, { speaker: `person:${p.person}`, scope: "device", by: "login", at: this.now() });
    const { phone: _p, code: _c, lang: _l, ...rest } = obj(body) ?? {};
    const joined = this.joinByLink(device.record, code, rest);
    return isFail(joined) ? joined : { ...joined, device: device.token };
  }

  requestsOf(owner: string): { id: string; venue: string; avatar: AvatarCard; at: string }[] {
    const d = readDoc(this.root, owner, "requests.geml");
    const answered = new Set(d.blocks.filter((b) => /^answer-\d+$/.test(b.id)).map((b) => b.value["request"]));

      if (card !== undefined && venue !== undefined) out.push({ id: b.id, venue, avatar: card, at: str(b.value["at"]) ?? "" });
    }

  }

    if (isFail(a)) return a;
    if (a.avatar !== owner) return fail(403, "link.ownerRules");

    if (yes && w?.kind === "avatar" && venue !== undefined && this.venueState(owner, venue)?.members.includes(w.id) === false) this.join(owner, venue, w.id, avatarSpeaker(a.avatar));
```

```ts
// request to a status and a body, so it is tested without a socket and
// served by avatar-server.ts. Every answer is JSON but an agent's join
// instructions (`/i/<code>.md`, Markdown). A refusal is
// `{"error": <code>, "params"?: …, "reason": <its words>}`, the words in the
// request's language: `?lang=`, else the person's own, else the browser's
// (`Accept-Language`), else Chinese (spec §7.6). The token names who asks;
// the body never does.
import { AVATAR_ID, parseWho } from "../core/avatar/who.js";
import { DEFAULT_LANG, isLang, pickLang, say, type Lang } from "../core/avatar/words.js";
import type { AvatarRelay, Fail, Result } from "./avatars.js";
import type { TokenRecord } from "./tokens.js";

export interface AvatarRequest {
  method: string;
  path: string;
  query: Record<string, string>;
  token?: string;
  /** The body parsed as JSON, when there was one. */
  body?: unknown;
  /** The client's network address, for the code quota. */
  ip?: string;
  /** The `Accept-Language` header. */
  languages?: string;
  /** Where the relay is reached, `https://host`, for the addresses an agent is told. */
  base?: string;
  version?: string;
}
export interface AvatarResponse { status: number; body: string; type: string }

export const JSON_TYPE = "application/json; charset=utf-8";
export const MARKDOWN_TYPE = "text/markdown; charset=utf-8";

const json = (status: number, value: unknown): AvatarResponse => ({ status, body: JSON.stringify(value), type: JSON_TYPE });
const obj = (v: unknown): Record<string, unknown> => (typeof v === "object" && v !== null && !Array.isArray(v) ? (v as Record<string, unknown>) : {});

/** A refusal in the language: its code, its parameters, its words. */
export function refusal(status: number, code: string, lang: Lang, params?: Record<string, string | number>): AvatarResponse {
  return json(status, { error: code, ...(params !== undefined ? { params } : {}), reason: say(code, lang, params) });
}

/** The language a request is answered in: asked for in the query or the body, else the person's, else the browser's. */
export function langOf(r: Pick<AvatarRequest, "query" | "languages" | "body">, person?: Lang): Lang {
  const asked = r.query["lang"] ?? obj(r.body)["lang"];
  return isLang(asked) ? asked : (person ?? pickLang(r.languages) ?? DEFAULT_LANG);
}

export function routeAvatars(r: AvatarRequest, relay: AvatarRelay): AvatarResponse {

    if (c === "name") return only("POST", () => answer(relay.rename(by, b, r.body)));
    if (c === "rules") return only("POST", () => answer(relay.setRules(by, b, r.body)));
    if (c === "token") return only("POST", () => answer(relay.issueAvatar(by, b), 201));
    return no(404, "path.missing");

    return only("GET", () => {
      if (person !== undefined && by.scope === "person") return json(200, relay.venuesOf(person));
      const w = parseWho(by.speaker);
      if (by.scope !== "avatar" || w?.kind !== "avatar") return no(403, "person.only");
      return json(200, relay.joinedOf(w.id).map((v) => relay.venueView(v.owner, v.venue, w.id)).filter((v) => v !== undefined).map((v) => ({ ...v, as: w.id })));

}
```

```ts
// `node:http` around gemsbang's relay (transport §2.5, §7.1): a browser at
// `/i/<code>`, `/g/<group>` or `/login` gets the page (avatar-pages.ts), in
// its language; everything else is the JSON of avatar-api.ts, a body of at
// most a megabyte, the token from the Authorization header or the query.
// `GET /subscribe` is upgraded to a WebSocket whose client names the
// documents it follows (`{"subscribe": "<avatar>/<doc>"}`): each block is
// pushed as it lands, as the client may read it — a venue's to its members,
// a message's `by` left out where its avatar does not mark.
import { createServer, type IncomingMessage, type ServerResponse } from "node:http";
import type { AddressInfo } from "node:net";
import { JSON_TYPE, langOf, refusal, routeAvatars, type AvatarRequest } from "./avatar-api.js";
import { groupPage, HTML_TYPE, joinPage, loginPage } from "./avatar-pages.js";
import { AvatarRelay, type AvatarRelayOptions } from "./avatars.js";
import { upgrade, type WsConnection } from "./ws.js";
import type { Lang } from "../core/avatar/words.js";

export interface AvatarServer { port: number; url: string; relay: AvatarRelay; close(): Promise<void> }

/** A request body may be this long: a message, never a file's bytes. */
export const BODY_LIMIT = 1_048_576;

/** The pages by path, for a browser (`Accept: text/html`); a script at the same path gets the JSON. */
const PAGES: readonly [RegExp, (lang: Lang) => string][] = [[/^\/i\/[a-z0-9]{1,16}$/, joinPage], [/^\/g\/[gd]-[0-9a-f]{10}$/, groupPage], [/^\/login$/, loginPage]];

function readBody(req: IncomingMessage): Promise<string | undefined> {
  return new Promise((done, failed) => {
    const chunks: Buffer[] = [];
    let size = 0;
    req.on("data", (c: Buffer) => { size += c.length; if (size <= BODY_LIMIT) chunks.push(c); });
    req.on("end", () => done(size > BODY_LIMIT ? undefined : Buffer.concat(chunks).toString("utf8")));
    req.on("error", failed);
  });
}

function tokenOf(req: IncomingMessage, url: URL): string | undefined {
  const auth = req.headers["authorization"];
  const m = typeof auth === "string" ? /^Bearer\s+(\S+)$/i.exec(auth) : null;
  return m?.[1] ?? url.searchParams.get("token") ?? undefined;
}

function reply(res: ServerResponse, status: number, body: string, type: string): void {
  res.writeHead(status, { "content-type": type, "content-length": Buffer.byteLength(body) });
  res.end(body);
}

export function startAvatarRelay(o: AvatarRelayOptions & { port?: number; host?: string; publicUrl?: string; version?: string }): Promise<AvatarServer> {
  const relay = new AvatarRelay(o);
  const host = o.host ?? "127.0.0.1";
  const subscribers = new Map<WsConnection, { token: string; docs: Set<string> }>();
  const off = relay.onAppend(({ owner, doc, block }) => {
    const key = `${owner}/${doc}`;
    for (const [conn, s] of subscribers) {
      if (!s.docs.has(key)) continue;
      const by = relay.verify(s.token);
      const read = by === undefined ? undefined : relay.read(by, owner, doc);
      const seen = read?.ok === true ? read.blocks.find((b) => b.id === block.id) : undefined;
      if (seen !== undefined) conn.send(JSON.stringify({ doc: key, block: seen }));
    }
  });

  const server = createServer((req, res) => {
    void (async () => {
      const url = new URL(req.url ?? "/", "http://relay");
      const languages = typeof req.headers["accept-language"] === "string" ? req.headers["accept-language"] : undefined;
      const query = Object.fromEntries(url.searchParams);
      try {
        const page = (req.method ?? "GET").toUpperCase() === "GET" && /text\/html/.test(String(req.headers["accept"] ?? "")) ? PAGES.find(([re]) => re.test(url.pathname)) : undefined;
        if (page !== undefined) { reply(res, 200, page[1](langOf({ query, ...(languages !== undefined ? { languages } : {}) })), HTML_TYPE); return; }
        const text = await readBody(req);
        const lang = langOf({ query, ...(languages !== undefined ? { languages } : {}) });
        if (text === undefined) { const r = refusal(413, "body.tooLarge", lang); reply(res, r.status, r.body, r.type); return; }
        let body: unknown;
        if (text !== "") {
          try { body = JSON.parse(text); } catch { const r = refusal(400, "body.notJson", lang); reply(res, r.status, r.body, r.type); return; }
        }
        const token = tokenOf(req, url);
        const base = o.publicUrl ?? `http://${req.headers["host"] ?? `${host}`}`;
        const r: AvatarRequest = { method: req.method ?? "GET", path: url.pathname, query, base, ...(o.version !== undefined ? { version: o.version } : {}), ...(languages !== undefined ? { languages } : {}), ...(req.socket.remoteAddress !== undefined ? { ip: req.socket.remoteAddress } : {}), ...(token !== undefined ? { token } : {}), ...(body !== undefined ? { body } : {}) };
        const out = routeAvatars(r, relay);
        reply(res, out.status, out.body, out.type);
      } catch (e) {
        const r = refusal(500, "server.error", langOf({ query }), { detail: e instanceof Error ? e.message : String(e) });
        reply(res, r.status, r.body, JSON_TYPE);
      }
    })();
  });

  server.on("upgrade", (req, socket, head) => {
    const url = new URL(req.url ?? "/", "http://relay");
    if (url.pathname !== "/subscribe") { socket.write("HTTP/1.1 404 Not Found\r\nConnection: close\r\n\r\n"); socket.destroy(); return; }
    const token = tokenOf(req, url);
    if (token === undefined || relay.verify(token) === undefined) { socket.write("HTTP/1.1 401 Unauthorized\r\nConnection: close\r\n\r\n"); socket.destroy(); return; }
    const conn = upgrade(req, socket, head);
    if (conn === undefined) return;
    const sub = { token, docs: new Set<string>() };
    subscribers.set(conn, sub);
    conn.onMessage((text) => {
      let msg: unknown;
      try { msg = JSON.parse(text); } catch { conn.send(JSON.stringify({ error: "body.notJson" })); return; }
      const m = typeof msg === "object" && msg !== null ? (msg as Record<string, unknown>) : {};
      if (typeof m["subscribe"] === "string") {
```
