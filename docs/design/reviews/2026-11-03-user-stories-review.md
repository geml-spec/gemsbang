## 3. 问题清单

### 阻塞

**B1 ［S21 / Q7，牵连 S14、S16、S25］第二个分身可能永远没有会话来演**

- **事实**：
  - 自动回只为这个会话所归的那个分身跑（`ops:599-613`）。
  - 任务也一样，而且要求会话归这个分身（`ops:671-673`）。
- **几个决定叠在一起的后果**：
  - S21 定了新会话默认归「最近说过话」的分身。
  - 会话不能换着演（「先不考虑」）。
  - 删减表又去掉了「让这个会话替它」。
  - 于是「Lily 爸爸」只要不是最近说话的那个，就一个会话都没有：它设了自动回的群悄悄没人回，派给它的活永远不动，S25 里它也不在任何设备上。本人没有任何办法补救。
- **违反**：E（估不出来，因为不懂规则，不是因为太大）、T，以及「端到端可演示」。
- **修改建议**：不替本人定，只把空缺留给本人填。改写成这样：
  > 作为有两个分身的人，我想每个分身的自动回和任务都有会话接，以便设了自动回的群不会悄悄没人回。
  > - Given 新开一个会话，Then 它归「最近一次以本人或 agent 身份发过消息的那个分身」（「说过话」怎么算，待本人定）；「我」里这张卡的「谁来演」多出这个会话。
  > - Given 分身 B 没有会话归它，When B 设了自动回的群里有人叫它，Then 【待本人定：(a) 本人开着的任何一个会话都接，会话归谁只决定「在这个会话里以谁说」；(b) 照常给本人出被叫到的卡，B 的卡上写「现在没有会话在演它」；(c) 接受现状，在故事里写明只有默认分身会自动回、会干活】。不允许什么都不发生。
  > - Given 同一分身有两个会话（同一台或两台电脑），When 一件事来了，Then 群里只出现一条回复，任务只在一个 worktree 里起。

**B2 ［S15 / Q12］过期时那句话和「点之前群里什么都不出现」矛盾**

- **事实**：卡一过期，服务端就以 agent 身份在群里说「这件事要本人回，我先不替答。」（`relay/avatars.ts:1201`）。
- S15 第二条验收和架构 §6.3 都要求说这句；S15 第五条、Q12 和删减表又说本人点之前，群里不出现一句没人点过头的话。两条不能同时验收通过。
- **违反**：T。
- **修改建议**：请本人二选一，再改第五条：
  - (a) 「Given 卡还没点，Then 群里什么都不出现；唯一的例外是有截止时间的卡到点，分身说一句这件事要本人回。」这和架构规格一致。
  - (b) 「过期时只在卡上标『已过期』，群里不说话。」选这个要同时改架构 §6.3（两份冲突时以它为准），并删掉 `avatars.ts:1201` 那段。

**B3 ［S14］「agent 在回…」没有结束的时候**

- 故事只写了「直到那句话出现在群里」。可是后台 agent 也可能一句话都不说就结束：
  - 碰到五种事，按 S15 第四条它只能出卡、停下等；
  - 它出错了，或者会话被关了；
  - 它判断不用回。事实：这时 `roundDone` 什么都不发就返回（`ops:621-622`）。
- 这几种情况下，那一行会一直挂着。S14 剩下要做的就是这一行，结束的样子没定就没法验收。
- **违反**：T，以及「不得编造业务规则」。
- **修改建议**：补一条验收。
  > Given 点了「交给 agent 回」，When agent 结束了、群里却没有它的话（转成了「需要你」卡 / 出错 / 会话关了 / 它判断不用回），Then 【待本人定，例如：那一行收起，被叫到的卡回来并写一句为什么；转成「需要你」时，那一行换成那张卡】。
